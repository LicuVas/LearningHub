Recapitulare: Caractere si Paragrafe

✏
Lectiile 2-3: Formatarea textului

Bold (Ctrl+B)

Text ingrosat pentru evidentierea informatiilor importante

Italic (Ctrl+I)

Text inclinat pentru titluri de carti, cuvinte straine

Underline (Ctrl+U)

Text subliniat pentru a atrage atentia

Justify (Ctrl+J)

Aliniere la ambele margini - aspect profesional

Regula de aur: SELECTEAZA textul INAINTE de a aplica formatarea!
2

Recapitulare: Liste si Tabele

📋
Lectiile 4-5: Organizarea informatiilor
Actiune Tasta/Comanda
Sublista Tab (la inceputul elementului)
Revenire nivel Shift+Tab
Iesire lista Enter + Enter
Urmatoarea celula Tab (in tabel)
Inserare tabel Insert > Table
Buline vs Numere:
- Buline: cand ordinea NU conteaza (lista cumparaturi)
- Numere: cand ordinea CONTEAZA (pasi reteta)
3

Recapitulare: Antet, Subsol, Numere Pagina

📄
Lectia 6: Documente profesionale

Antet (Header)

Zona de SUS - apare pe TOATE paginile

Subsol (Footer)

Zona de JOS - perfect pentru numere pagina

Page Number

Numere automate - se actualizeaza singure

Different First Page

Prima pagina fara numar - pentru titlu

Dublu-click magic:
- Dublu-click sus/jos = intri in antet/subsol
- Dublu-click mijloc = iesi din antet/subsol

✎ Toate shortcut-urile importante:

  • Ctrl+B = Bold (ingrosat)
  • Ctrl+I = Italic (inclinat)
  • Ctrl+U = Underline (subliniat)
  • Ctrl+L = Aliniere stanga
  • Ctrl+E = Centrare
  • Ctrl+R = Aliniere dreapta
  • Ctrl+J = Justify (ambele margini)
  • Tab = Sublista / Urmatoarea celula
  • Ctrl+S = Salveaza documentul
