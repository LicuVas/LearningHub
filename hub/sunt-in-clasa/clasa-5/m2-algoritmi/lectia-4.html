Date de intrare si iesire

Ce primeste si ce produce un algoritm

Progres lectie:
0%
🎯 Obiectivul lectiei

"Vreau sa inteleg ce informatii primeste un algoritm si ce rezultate produce!"

1

Ce sunt datele de intrare (INPUT)?

📥
INPUT = Ce primeste algoritmul
Datele de intrare (INPUT) sunt informatiile pe care le dai algoritmului pentru ca acesta sa poata rezolva problema.

Gandeste-te la un blender: ca sa faci un smoothie, trebuie sa pui fructe inauntru. Fructele sunt INPUT-ul - ceea ce dai masinii pentru a lucra.

  • Reteta de prajitura INPUT: ingredientele (faina, oua, zahar, lapte)
  • Calculator (adunare) INPUT: cele doua numere pe care vrei sa le aduni (ex: 5 si 3)
  • GPS INPUT: adresa de plecare si adresa de destinatie
💡 INPUT = ingredientele. Fara ingrediente, nu poti gati nimic!
2

Ce sunt datele de iesire (OUTPUT)?

📦
OUTPUT = Ce produce algoritmul
Datele de iesire (OUTPUT) sunt rezultatele pe care le obtii dupa ce algoritmul a procesat datele de intrare.

Continuand exemplul cu blenderul: dupa ce pui fructele si pornesti aparatul, obtii smoothie. Smoothie-ul este OUTPUT-ul!

  • Reteta de prajitura OUTPUT: prajitura gatita si gata de mancat
  • Calculator (adunare 5 + 3) OUTPUT: rezultatul 8
  • GPS OUTPUT: traseul pe care trebuie sa il urmezi
💡 OUTPUT = farfuria servita. E rezultatul final al muncii tale!
3

Legatura: INPUT → PROCES → OUTPUT

Orice algoritm urmeaza acelasi tipar: primeste date, le proceseaza, si produce un rezultat.

Input
Date initiale
→
Proces
Algoritm (pasi)
→
Output
Rezultat
Exemplu INPUT PROCES OUTPUT
Smoothie Fructe, lapte Mixare in blender Smoothie
Adunare 5 si 3 Calcul: 5+3 8
Paine prajita Felie de paine Prajire in toaster Toast crocant
Important: Acelasi algoritm (proces) cu INPUT diferit produce OUTPUT diferit! Daca pui mere in blender, obtii suc de mere. Daca pui banane, obtii suc de banane.

✎ De retinut:

  • INPUT = datele pe care le dai algoritmului (ingredientele)
  • OUTPUT = rezultatul pe care il obtii (preparatul final)
  • PROCES = pasii algoritmului care transforma INPUT in OUTPUT
  • Schimbarea INPUT-ului duce la schimbarea OUTPUT-ului
