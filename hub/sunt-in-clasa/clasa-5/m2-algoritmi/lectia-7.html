Recapitulare: Ce am invatat

In acest modul am invatat despre algoritmi - baza programarii calculatoarelor. Hai sa recapitulam!

📝 Algoritm

O serie de pasi in ordine pentru a rezolva o problema

🔢 Ordine

Pasii trebuie executati in ordinea corecta

🧠 Gandire algoritmica

Impartirea problemelor mari in pasi mici

📥 INPUT / OUTPUT

Date de intrare si rezultate de iesire

📦 Variabile

Cutii cu eticheta pentru valori care se schimba

🔒 Constante

Valori fixe care nu se modifica

Termeni cheie:
Algoritm Pas Ordine INPUT OUTPUT Variabila Constanta Schema logica Flowchart
2

Evaluare: Date de intrare si iesire

Aminteste-ti: INPUT = ce primeste algoritmul, OUTPUT = ce produce.

  • Exemplu: Calculator INPUT: numere si operatie | OUTPUT: rezultat
  • Exemplu: Blender INPUT: fructe si lapte | OUTPUT: smoothie
3

Evaluare: Variabile si Constante

Variabilele se pot schimba, constantele raman fixe.

4

Evaluare: Scheme logice

Recapituleaza simbolurile schemei logice:

  • Oval = START / STOP
  • Dreptunghi = Actiune, calcul (proces)
  • Paralelogram = Citire (INPUT) sau Afisare (OUTPUT)
  • Romb = Decizie (intrebare DA/NU)

✎ Rezumatul modulului:

  • Algoritmul = pasi in ordine pentru rezolvarea unei probleme
  • Ordinea pasilor este esentiala pentru rezultat corect
  • Gandirea algoritmica = impartirea problemelor in pasi mici
  • INPUT = date primite, OUTPUT = rezultat produs
  • Variabile = valori care se schimba, Constante = valori fixe
  • Schemele logice reprezinta vizual algoritmii cu forme si sageti
