Gestionarea fisierelor si folderelor

🎯 Obiectivul lectiei

"Vreau sa stiu cum sa organizez fisierele si folderele pe calculator - exact ca si cum as organiza caietele si cartile in dulap!"

1

Fisiere si Foldere - Bazele

  • Fisier (File) O unitate de date salvata pe calculator cu un nume si o extensie. E ca o foaie de hartie cu un titlu - contine informatii specifice.
    Exemple: referat.docx, poza_vacanta.jpg, cantec.mp3
  • Folder (Director) Un container care grupeaza fisiere si alte foldere. E ca un dosar sau un sertar - grupezi lucruri similare impreuna.
    Exemple: Tema_Romana, Poze_2026, Jocuri
💡 Gandeste-te la calculator ca la un dulap urias. Fisierele sunt lucrurile (carti, haine). Folderele sunt sertarele si rafturile care te ajuta sa organizezi.
2

Extensii - Ce tip de fisier este?

Extensia este sufixul dupa punct care indica tipul fisierului. E ca eticheta pe un borcan - iti spune ce e inauntru!
Extensie Tip de fisier Exemplu
.docx Document Word referat.docx
.jpg / .png Imagine poza.jpg
.mp3 Muzica / Audio cantec.mp3
.exe Program executabil joc.exe
.txt Text simplu notite.txt

Calea (Path) este adresa completa a unui fisier - ca adresa postala:

C:\Users\Maria\Documents\Scoala\tema.docx
3

Operatii: Copy, Cut, Paste, Delete

📁
File Explorer - Aplicatia pentru gestionarea fisierelor
Diferenta importanta:
Copy + Paste = Creezi o COPIE (originalul ramane)
Cut + Paste = MUTI fisierul (originalul dispare din locatia initiala)
Operatie Shortcut Ce face
Copy (Copiaza) Ctrl + C Copiaza fisierul in memorie
Cut (Taie) Ctrl + X Pregateste fisierul pentru mutare
Paste (Lipeste) Ctrl + V Pune fisierul in locatia noua
Delete (Sterge) Delete Trimite in Cos de gunoi

Cosul de gunoi (Recycle Bin) pastreaza temporar fisierele sterse. Poti recupera un fisier sters (click dreapta > Restore) atata timp cat nu ai golit cosul!

💡 Recycle Bin = a doua sansa! Dar atentie: "Empty Recycle Bin" sterge definitiv totul.

✎ De retinut:

  • Fisierul este o unitate de date cu nume si extensie
  • Folderul este un container care organizeaza fisierele
  • Extensia (.docx, .jpg, .mp3) indica tipul fisierului
  • Copy + Paste = creezi o copie (originalul ramane)
  • Cut + Paste = muti fisierul (originalul dispare)
  • Recycle Bin pastreaza temporar fisierele sterse pentru recuperare
