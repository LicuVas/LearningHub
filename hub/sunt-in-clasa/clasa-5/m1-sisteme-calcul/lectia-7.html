Recapitulare rapida

Inainte de evaluare, sa recapitulam conceptele cheie din fiecare lectie:

💻 Lectiile 1-2: Ergonomie si Siguranta

  • Pozitia corecta la calculator
  • Distanta 50-70 cm de ecran
  • Pauze la fiecare 45 min
  • Nu mancam/bem langa calculator

🖥 Lectiile 3-4: Hardware si Software

  • CPU = creierul calculatorului
  • RAM = memorie temporara (se sterge)
  • HDD/SSD = stocare permanenta
  • Periferice: intrare (tastatura) / iesire (monitor)

📁 Lectia 5: Interfata SO

  • Desktop, taskbar, meniu Start
  • Ferestre: minimizare, maximizare, inchidere
  • Pictograme = simboluri pentru aplicatii

📂 Lectia 6: Fisiere si Foldere

  • Fisier = document cu date
  • Folder = container organizator
  • Copy vs Cut (copiaza vs muta)
  • Extensii: .docx, .jpg, .mp3
