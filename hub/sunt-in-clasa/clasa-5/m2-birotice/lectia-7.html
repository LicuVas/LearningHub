Recapitulare: Interfata si Salvare

💾
Fundamente: Interfata + Salvare
Shortcut-uri esentiale:
- Ctrl+N = Document nou
- Ctrl+S = Salvare rapida
- Ctrl+O = Deschide document
- Ctrl+Shift+S = Save As

Elementele interfetei: Bara de titlu (numele documentului), Ribbon (butoane pe tab-uri), Zona de lucru (aici scrii), Bara de stare (informatii: pagina, cuvinte).

💡 Toate programele Office au interfata similara - inveti unul, te descurci in toate!
2

Recapitulare: Formatarea textului

Shortcut-uri de formatare:
- Ctrl+B = Bold
- Ctrl+I = Italic
- Ctrl+U = Underline
- Ctrl+E = Centrat
- Ctrl+J = Justify

Regula de aur: INTOTDEAUNA selecteaza textul INAINTE de a-l formata!

  • Font = tipul de litera (Arial, Times New Roman)
  • Font Size = marimea (12pt standard, titluri mai mari)
  • Aliniere = pozitia textului (stanga, centru, dreapta, justify)
💡 Formatarea e "decorarea" textului - nu schimba CE spui, ci CUM arata!
3

Recapitulare: Imagini si Printare

🖼 🖨
Imagini + Print = Document complet
Imagini si forme:
- Insert > Pictures = adauga imagine
- Insert > Shapes = adauga forme
- Redimensionare din COLT = pastreaza proportiile
- Text Wrapping: Square = textul curge in jurul imaginii
Printare:
- Ctrl+P = deschide Print
- INTOTDEAUNA verifica Print Preview!
- Portrait = vertical, Landscape = orizontal
- Print to PDF = salvare fara hartie
💡 Un document complet: text formatat + imagini relevante + gata de print/PDF!

✎ Cheat Sheet - Tot modulul:

  • Ctrl+N/S/O = New/Save/Open
  • Ctrl+B/I/U = Bold/Italic/Underline
  • Ctrl+E/J = Center/Justify
  • Ctrl+P = Print
  • Insert = adauga imagini, forme, tabele
  • Selecteaza inainte de formatare!
  • Redimensioneaza din COLT pentru proportii corecte!
  • Print Preview inainte de a printa!
  • PDF = format universal, arata identic oriunde
