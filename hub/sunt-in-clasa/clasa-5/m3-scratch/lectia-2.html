1

Ce este un Sprite?

Un sprite este orice personaj sau obiect din proiectul tau Scratch. Poate fi o pisica, un caine, o minge, o masina sau chiar un text!

Caracteristici importante ale sprite-urilor:

  • Pozitie - unde se afla pe scena (coordonate X si Y)
  • Costume - cum arata (poate avea mai multe costume pentru animatie)
  • Dimensiune - cat de mare sau mic este
  • Directie - incotro este orientat

Fiecare sprite poate avea propriul program (script). De exemplu, pisica poate merge in stanga, iar cainele poate sari - fiecare face altceva!

Adaugarea si Gestionarea Sprite-urilor

In Scratch poti adauga sprite-uri noi in mai multe moduri:

  1. Din biblioteca Scratch - apasa pe butonul cu pisica si "+" din zona sprite-urilor, apoi alege un sprite din biblioteca cu sute de personaje
  2. Deseneaza-ti propriul sprite - foloseste pictorul integrat pentru a crea personaje originale
  3. Incarca o imagine - poti folosi o imagine de pe calculator
  4. Sprite surpriza - lasa Scratch-ul sa aleaga aleatoriu!

Cum stergi sau duplici un sprite:

  • Click dreapta pe sprite → "Sterge" pentru a-l elimina
  • Click dreapta pe sprite → "Duplica" pentru a face o copie
  • Poti trage sprite-ul pentru a-i schimba pozitia pe scena

Scene si Fundaluri (Backdrops)

Scena (Stage) este fundalul pe care se misca toate sprite-urile. Poti schimba aspectul scenei folosind fundaluri (backdrops).

Cum schimbi fundalul:

  1. Apasa pe iconita "Scena" din zona sprite-urilor (coltul din dreapta jos)
  2. Apasa pe tab-ul "Fundaluri" (Backdrops)
  3. Alege din biblioteca, deseneaza sau incarca o imagine

Sfat important: Scena poate avea mai multe fundaluri! Poti schimba fundalul in timpul programului pentru a crea scene diferite (de exemplu: zi → noapte, camera → exterior).

Dimensiunea scenei in Scratch este de 480 x 360 pixeli. Centrul scenei are coordonatele (0, 0).
