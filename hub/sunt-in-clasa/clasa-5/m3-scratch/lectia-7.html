Recapitulare: Interfata si Sprite-uri

Interfata Scratch

Scratch are 4 zone principale: Scena (unde vezi rezultatul), Zona sprite-urilor (personajele), Paleta de blocuri (toate blocurile) si Zona de scripturi (unde programezi).

Sprite-uri si Scene

Un sprite este orice personaj sau obiect. Fiecare sprite poate avea mai multe costume si propriile scripturi. Scena poate avea mai multe fundaluri.

Care este diferenta dintre un sprite si un fundal?

Nu exista nicio diferenta
Sprite-ul este un personaj care se poate misca, fundalul este imaginea din spatele scenei
Fundalul se poate misca, sprite-ul nu
Sprite-ul este pentru sunet, fundalul pentru imagine
2

Recapitulare: Blocuri de Miscare

Blocuri de Miscare (Albastre)

  • mergi (10) pasi - Muta sprite-ul inainte
  • mergi la x: () y: () - Teleporteaza la coordonate
  • gliseaza in () secunde - Miscare lina
  • indreapta-te spre directia () - Seteaza directia
  • intoarce-te () grade - Roteste sprite-ul

Coordonate: X merge de la -240 (stanga) la 240 (dreapta). Y merge de la -180 (jos) la 180 (sus). Centrul este (0, 0).

Un sprite este la pozitia (0, 0) si are directia 90. In ce directie va merge?

Sus
Dreapta
Jos
Stanga
3

Recapitulare: Blocuri de Aspect

Blocuri de Aspect (Violet)

  • spune [] timp de () secunde - Balon de dialog
  • gandeste [] - Balon de gandire (cu buline)
  • urmatorul costum - Schimba costumul
  • seteaza dimensiunea la () % - Marimea sprite-ului
  • arata / ascunde - Vizibilitate

Cum faci o animatie de mers folosind costume?

Folosesti doar "mergi pasi"
Folosesti "urmatorul costum" in combinatie cu "asteapta" intr-un "repeta"
Schimbi fundalul
Folosesti "ascunde" si "arata"
4

Recapitulare: Scripturi si Secvente

Structura unui Script

  1. Bloc de eveniment (galben) - cand porneste scriptul
  2. Blocuri de actiune - ce face sprite-ul
  3. Executie secventiala - de sus in jos

Blocuri de Control (Portocaliu)

  • cand se apasa pe steag verde - Start program
  • asteapta () secunde - Pauza
  • repeta () - Executa de mai multe ori

Ce se intampla daca un script nu incepe cu un bloc de eveniment?

Ruleaza automat
Ruleaza cand apesi pe sprite
Nu ruleaza automat - trebuie sa apesi manual pe blocuri
Genereaza o eroare

Test Final - Intrebare Complexa

cand se apasa pe steag verde

mergi la x: (-100) y: (0)

spune [Start!] timp de (1) secunde

repeta (5)

mergi (40) pasi

urmatorul costum

asteapta (0.5) secunde

spune [Gata!]

Care va fi pozitia X a sprite-ului la final? (Sprite-ul incepe la x=-100 si merge 40 pasi de 5 ori)

x = -100 (ramane la loc)
x = 0 (centrul)
x = 100 (a mers 200 de pasi in total)
x = 200
