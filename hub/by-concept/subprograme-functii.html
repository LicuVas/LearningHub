Pe scurt

Când programul tău crește, îl spargi în bucăți mici cu nume — exact cum o echipă lucrează pe roluri clare. O funcție se scrie o singură dată și o poți chema oricând ai nevoie de ea, fără să copiezi codul. Asta înseamnă mai puține bug-uri, cod mai ușor de citit și modificări rapide în tot programul.

Ce este

Blocuri de cod cu un nume

O funcție (numită și subprogram) este un bloc de instrucțiuni grupate sub un nume ales de tine. Definiția funcției se scrie o singură dată, de obicei deasupra lui main(), iar după aceea o apelezi (chemi) de câte ori ai nevoie scriin doar numele urmat de paranteze și punct și virgulă.

Funcțiile pot fi void — execută o acțiune (afișează, modifică ceva) fără să returneze o valoare — sau pot returna un rezultat (int, float, bool etc.) pe care îl poți folosi în calcule sau îl poți afișa.

🏃 Analogie

Gândește-te la o rețetă de prăjituri. Nu o reinventezi de fiecare dată — o scrii o dată și o folosești ori de câte ori gătești. Dacă vrei să schimbi cantitatea de zahăr, modifici doar rețeta, iar efectul se vede în toate prăjiturile viitoare. Funcția din C++ funcționează exact la fel: o schimbare în funcție înseamnă o singură modificare în cod, indiferent de câte ori o apelezi.

De ce contează

Unde contează în practică

🐞 Bug reparat o singură dată Dacă același cod e copiat în 5 locuri și găsești un bug, trebuie să-l repari în 5 locuri. Cu o funcție, repari într-un singur loc și gata — principiul DRY.
📚 Cod ușor de citit Un calculeazaMedia() spune singur ce face. Nu trebuie să citești 10 linii pentru a înțelege logica.
⚙️ Reutilizare în proiect O funcție afiseazaMeniu() scrisă o dată poate fi apelată la start, după fiecare opțiune și înainte de ieșire, fără nicio copiere.

Aprofundare

Dincolo de bază: prototipuri, referințe și recursivitate

Odată ce stăpânești funcțiile de bază, următorul nivel introduce trei concepte care apar constant în programele mai mari și în subiectele de concurs:

1. Prototipul funcției

Dacă vrei să defineiti funcția după main() (util în fișiere mari), declari înainte doar semnatura ei — tipul returnat, numele și parametrii, urmat de punct și virgulă. Compilatorul „știe” deja ce să aștepte când întâlnește apelul în main().
Exemplu: int dublu(int x); — aceasta este declarația (prototipul); definiția completă vine mai jos.

2. Parametri prin referință (&)

În mod normal, C++ copiază valoarea în funcție — modificările din interior nu afectează variabila originală. Dacă vrei ca funcția să modifice direct variabila apelantului, folosești & înaintea numelui parametrului: void dubleaza(int& x) { x = x * 2; }. După apel, variabila transmisă din main() este deja dublă. Util și pentru funcții care „returnează” mai multe valori simultan.

3. Recursivitate — funcția care se autoapelează

O funcție poate să se apeleze pe ea însăși pentru a rezolva versiuni mai mici ale aceleiași probleme. Condiția de oprire (cazul de bază) este obligatorie — altfel programul rulează la infinit. Exemplu clasic — factorialul: fact(0) = 1; fact(n) = n * fact(n-1);. Recursivitatea simplifică elegant problemele cu structură autosimilară (arbori, labirinturi, șiruri Fibonacci) dar consumă mai multă memorie decât o buclă echivalentă.

Verifică-te

6 întrebări — de la simplu la avansat

  • 1. De ce e o problemă să copiezi același bloc de cod în 5 locuri diferite în loc să folosești o funcție?
    Dacă găsești un bug sau vrei să schimbi ceva, trebuie să modifici în 5 locuri în loc de unul singur. E ușor să uiți un loc, iar bug-ul rămâne ascuns. Cu o funcție, modifici o singură dată iar efectul se propagă automat oriunde e apelată funcția — principiul DRY (Don't Repeat Yourself).
  • 2. Ce înseamnă void în fața numelui unei funcții și cum diferă de o funcție cu tip returnat, de exemplu int?
    void înseamnă „nimic” — funcția execută o acțiune (afișează, modifică ceva) dar nu dă înapoi nicio valoare. O apelezi direct: afiseazaMeniu();

    O funcție cu tip returnat int calculează ceva și trimite înapoi un număr întreg prin return. Poți folosi rezultatul: int r = dublu(5); sau cout << dublu(5);
  • 3. De ce trebuie scrisă definiția funcției deasupra lui main() în C++?
    Compilatorul citește codul de sus în jos. Când întâlnește un apel de funcție în main(), trebuie să fi văzut deja fie definiția completă, fie cel puțin prototipul acelei funcții. Dacă funcția apare doar după main() fără prototip, compilatorul semnaleză eroare: „nu știu ce este această funcție”.
  • 4. 👑 Ce este un prototip de funcție și când are sens să îl folosești?
    Prototipul este declarația funcției fără corp: tip returnat, nume, lista de parametri și punctșivirgulă. De ex.: int suma(int a, int b);

    Îl folosești când definiția completă vine după main() — astfel compilatorul acceptă apelul din main() și verifică tipurile. E practica obișnuită în fișiere mari sau când funcțiile se apelează reciproc.
  • 5. 👑 Care e diferența dintre transmiterea unui parametru prin valoare și prin referință (&)? Dă un exemplu concret.
    Prin valoare: funcția primește o copie; orice modificare rămâne în interior și nu afectează variabila originală.
    Prin referință (&): funcția lucrează direct cu variabila din apelant; modificările se văd în afara funcției.

    Exemplu:
    void dubleaza(int& x) { x *= 2; }
    int n = 5; dubleaza(n); // n devine 10

    Fără &, n ar rămâne 5 după apel. Referințele sunt utile și când vrei să „returnezi” mai multe valori simultan.
  • 6. 👑 Ce este recursivitatea? Care sunt cele două componente obligatorii ale unei funcții recursive corecte?
    Recursivitatea înseamnă că o funcție se apelează pe ea însăși pentru a rezolva o versiune mai mică a problemei.

    Cele două componente obligatorii:
    • Cazul de bază (condiția de oprire) — fără el funcția s-ar apela la infinit, provocând stack overflow.
    • Pasul recursiv — apelul cu un argument mai mic/simplu, care se apropie de cazul de bază.

    Exemplu — factorial:
    int fact(int n) { if (n == 0) return 1; return n * fact(n-1); }

    n == 0 este cazul de bază; fact(n-1) este pasul recursiv.
