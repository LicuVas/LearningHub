Web Clasa a VII-a Clasa a VIII-a
Pe scurt

Pornești de la o schiță pe hârtie și ajungi la un site real, vizibil pe internet. Planifici ce pagini vei face, construiești fiecare pagină cu HTML, le dai un aspect atrăgător cu CSS, le legi printr-un meniu de navigare și, la final, le publici gratuit online cu GitHub Pages sau Netlify — așa încât oricine din lume să le poată accesa.

Acesta este proiectul care adună tot ce ai învățat despre web într-un singur produs funcțional, de la zero la live.

Notă curriculum: Conform programei OMEN 3393/2017, domeniul „Pagini web (editor dedicat)" apare la clasa a VIII-a. Lecțiile de tip proiect web (cls. VII) și publicarea pe GitHub Pages / Netlify sunt conținut extra-curricular — activitate opțională care anticipează programa. Elevii de cls. VIII lucrează în cadrul programei oficiale.
Ce este
De la idee la pagini live

Imaginează-ți că vrei să faci o revistă școlară. Nu începi să tipărești la întâmplare — mai întâi schițezi paginile, decizi câte rubrici ai, alegi culorile și fontul, abia apoi scrii conținutul și trimiți la tipar. Un site web funcționează exact la fel.

Planificarea înseamnă să decizi tema site-ului, câte pagini va avea (pagina principală index.html, „Despre mine", „Proiecte", „Contact") și ce conținut intră pe fiecare. Construirea înseamnă să scrii codul HTML pentru structură și CSS pentru aspect. Publicarea înseamnă să încarci fișierele pe un server (hosting) conectat la internet 24/7, astfel încât oricine să poată vedea site-ul tău introducând adresa în browser.

Platformele GitHub Pages și Netlify oferă hosting gratuit pentru site-uri statice — GitHub Pages îți dă o adresă de tipul username.github.io, Netlify una de tipul nume-site.netlify.app, ambele profesionale și fără niciun cost.

Verifică-te
Trei întrebări rapide
De ce este importantă planificarea înainte de a scrie cod HTML?
Planificarea te ajută să organizezi conținutul și să eviți refacerea paginilor. Fără un plan, ajungi să muți conținut, să refaci structuri și să pierzi timp. Regula de aur: 1 oră de planificare poate economisi 10 ore de muncă. Planul include: tema site-ului, câte pagini ai, ce conținut pune pe fiecare, culorile alese.
Ce înseamnă „hosting" web și cum se numesc două platforme gratuite pe care le poți folosi?
Hosting (găzduire) înseamnă să pui fișierele site-ului pe un server conectat la internet 24/7, astfel încât oricine să poată accesa site-ul. Două platforme gratuite pentru site-uri statice sunt GitHub Pages (adresă: username.github.io) și Netlify (adresă: nume-site.netlify.app).
Ce reguli trebuie respectate în denumirea fișierelor înainte de a publica site-ul online?
Pagina principală trebuie să se numească exact index.html. Folosești doar litere mici în numele fișierelor, fără spații — înlocuiești spațiile cu cratimă (despre-mine.html). Testezi site-ul local pe calculator înainte de publicare, te asiguri că toate link-urile funcționează și că imaginile se încarcă corect.
