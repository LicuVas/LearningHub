Pagini web — HTML și CSS

Web Clasa a VIII-a
Pe scurt

Construiești prima ta pagină web de la zero: înveți structura HTML care spune browserului ce să afișeze, apoi adaugi CSS care îi spune cum să arate — culori, fonturi, spațiere. La finalul modulului ai o pagină reală cu text, imagini, link-uri și tabele, pe care o poți publica online.

Ce este

HTML + CSS: scheletul și hainele paginii

HTML (HyperText Markup Language) este limbajul de marcare care structurează o pagină web. Nu este un limbaj de programare — nu face calcule, nu ia decizii. Îi spune browserului: „acesta e un titlu", „acesta e un paragraf", „aceasta e o imagine", prin etichete numite <tag-uri>.

CSS (Cascading Style Sheets) este „decorarea interioară" a acelei case pe care HTML a construit-o: culorile pereților, tipul de parchet, dimensiunea ferestrelor. Fără CSS, toate paginile ar fi text negru pe fond alb — funcționale, dar fără personalitate.

Gândește-te la o carte de bucate: HTML e lista de ingrediente și pașii rețetei (structura, conținutul), iar CSS e modul în care tipografia, culorile și fotografiile fac rețeta apetisantă (prezentarea vizuală). Browserul — Chrome, Firefox, Edge — citește ambele și afișează rezultatul final pe ecranul tău.

De ce contează

Trei situații din viața reală

  • 💻 Portofoliu personal sau proiect școlar — în loc de un document Word, creezi o pagină web pe care o trimiți ca link. Arată profesional și poate fi deschisă de oricine, de pe orice dispozitiv.
  • 🛒 Mică afacere de familie — magazin, atelier, salon. O pagină simplă cu adresă, orar, fotografii și număr de telefon îi ajută pe clienți să te găsească pe Google fără să plătești pe cineva.
  • 🎓 Baza oricărui job în IT — web design, frontend development, marketing digital. Toate pornesc de la aceleași concepte: HTML structurează, CSS stilizează. Înțelegând cum funcționează, poți colabora cu orice echipă de web.

Trei întrebări rapide

1. HTML este un limbaj de programare sau un limbaj de marcare?

HTML este un limbaj de marcare (markup), nu de programare. Nu face calcule și nu ia decizii — descrie structura unei pagini prin etichete (tag-uri). Un limbaj de programare (ex. Python, JavaScript) poate face calcule și controla fluxul unui program; HTML nu poate.

2. Care este diferența dintre <head> și <body> într-un document HTML?

<head> conține informații despre pagină care nu apar pe ecran: titlul din tab-ul browserului (<title>), setul de caractere (<meta charset="UTF-8">), legătura cu fișierul CSS (<link>) etc. <body> conține tot conținutul vizibil: texte, imagini, link-uri, tabele — ce vede utilizatorul.

3. Care sunt cele trei metode de a adăuga CSS pe o pagină HTML și care este recomandată pentru site-uri cu mai multe pagini?

Cele trei metode sunt: CSS inline (atributul style="" direct pe element), CSS intern (blocul <style> în <head>) și CSS extern (fișier separat .css legat cu <link rel="stylesheet">). Pentru site-uri cu mai multe pagini este recomandată metoda externă: un singur fișier CSS controlează designul întregului site, browserul îl salvează în cache (mai rapid), și o singură modificare se aplică pe toate paginile.
