```

PRACTICE → 3 exerciții (minim / standard / performanță)
REVIEW   → rezumat + notă + export JSON + lecția următoare
```

### Cum se scrie un chestionar (aici se greșește cel mai des)

Datele stau în atributul `data-quiz` al lui `.atom`, ca **listă JSON**:

```html
<div class="atom" id="atom-1" data-quiz='[{"question":"...","options":["a","b","c","d"],"correct":"b","hint":"..."}]'>
    <div class="atom-header">...</div>
    <div class="atom-content">
        ...continut...
        <div class="atom-quiz"></div>   <!-- OBLIGATORIU: fara el, intrebarile nu se afiseaza -->
    </div>
</div>
```

Patru capcane, toate prinse pe teren:
1. **Fără `<div class="atom-quiz"></div>` înăuntru**, motorul marchează atomul „content-only", îl **auto-completează cu scor 100** și ignoră întrebările — *fără nicio eroare în consolă*. (Azi: 416 pagini în situația asta.)
2. Ghilimelele din text se scriu `\"`, **nu** `&quot;` — browserul decodează entitatea și rupe JSON-ul.
3. Apostroful din text termină atributul: scrie `&#39;`.
4. `correct` e o **literă** (`"b"`), nu un index. Valoarea trebuie să fie o **listă** `[...]`, nu un obiect `{...}`.
