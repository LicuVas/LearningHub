# LearningHub — Agent Initialization

> **Read this FIRST before touching any file in this project.**

## What This Is

Interactive TIC (ICT) learning platform for Romanian gymnasium students (grades 5-8). 346 self-contained HTML lesson and quiz pages. No backend, no build step, no dependencies. Live at `https://learninghub-8z6.pages.dev`.

## Lesson Format: "Guided Atomic" (Format C)

All new lessons and refactored lessons use Format C:

```
FRAME   → goal + pain comparison + learning outcomes
TRY     → hands-on challenge (optional)
ATOMS   → content + embedded quiz, sequentially gated (4-8 per lesson)
PRACTICE → 3 exercises at minim/standard/performanta levels
REVIEW  → summary + grade + JSON export + next lesson
```

**Template:** See `LESSON_SPECIFICATION.md` Section 3 for copy-paste HTML template.
**Scripts (6):** atomic-learning.js, practice-simple.js, lesson-summary.js, breadcrumb.js, progress.js, user-system.js
**CSS:** `assets/css/lesson-atomic.css` only. **ZERO inline `<style>` blocks.**
**Grading:** 1 (oficiu) + 6 (quiz) + 3 (practice) = 10

## Key Rules

1. **ZERO inline CSS.** No `<style>` blocks in lesson HTML files.
2. **Use `os.path.relpath()`** for asset paths. NEVER count `../` manually.
3. **Use `Edit()` not `Write()`** on existing HTML files over 50 lines.
4. **Run `python tools/site_audit.py`** after any batch of changes.
5. **Romanian with diacritics** in content. ASCII-only in filenames and `<title>` tags.
6. **Lesson ID = `{grade}-{module}-{filename}`** (e.g., `cls7-m1-word-lectia3-tabele`).
