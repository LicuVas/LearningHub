Funcțiile IS
Se aplică la Excel pentru Microsoft 365 Excel pentru Microsoft 365 pentru Mac Excel 2024 Excel 2024 pentru Mac Excel 2021 Excel 2021 pentru Mac Excel 2019 Excel 2016 Aplicația Excel pentru Web
Descriere
Fiecare din aceste funcții, denumite generic ca funcții IS , verifică tipul argumentului valoare și returnează TRUE sau FALSE în funcție de rezultat. Spre exemplu, funcția ISBLANK întoarce valoarea logică TRUE dacă valoare este o referință la o celulă goală; altfel, returnează FALSE.
Aveți posibilitatea să utilizați o funcție IS pentru a obține informații despre o valoare înainte de a efectua un calcul sau altă acțiune cu ea. De exemplu, aveți posibilitatea să utilizați funcția ISERROR în conjuncție cu funcția IF pentru a efectua o altă acțiune dacă se produce o eroare:
=IF(ISERROR(A1); "S-a produs o eroare.", A1 * 2)
Această formulă verifică pentru a stabili dacă există o condiție de eroare în A1. Dacă da, funcția IF returnează mesajul "S-a produs o eroare". Dacă nu există nicio eroare, funcția IF efectuează operația A1*2.
Sintaxă
ISBLANK(valoare)
ISERR(valoare)
ISERROR(valoare)
ISEVEN(valoare)
ISLOGICAL(valoare)
ISNA(valoare)
ISNONTEXT(valoare)
ISNUMBER(valoare)
ISODD(valoare)
ISREF(valoare)
ISTEXT(valoare)
Sintaxa funcției IS are următorul argument:
valoare Obligatoriu. Este valoare pe care doriți să o testați. Argumentul valoare poate fi necompletat (celulă goală), eroare, valoare logică, text, număr sau valoare de referință sau un nume care face referire la oricare dintre acestea.
Funcție
Întoarce TRUE dacă
ISBLANK
Valoare se referă la o celulă goală.
ISERR
Valoare se referă la orice valoare de eroare cu excepția #N/A.
ISERROR
Valoare se referă la orice valoare de eroare (#N/A, #VALUE!, #REF!, #DIV/0!, #NUM!, #NAME? sau #NULL!).
ISEVEN
Valoare se referă la un număr par.
ISLOGICAL
Valoare se referă la o valoare logică.
ISNA
Valoare se referă la valoarea de eroare #N/A (valoarea nu este disponibilă).
ISNONTEXT
Valoare se referă la orice element care nu este text. (De reținut că această funcție întoarce TRUE dacă valoare se referă la o celulă goală).
ISNUMBER
Valoare se referă la un număr.
ISODD
Valoare se referă la un număr impar.
ISREF
Valoare se referă la o referință.
ISTEXT
Valoare se referă la text.
Observații
Argumentele de valoare ale funcției IS funcții nu sunt convertite. Toate valorile numerice care sunt încadrate între ghilimele duble sunt tratate ca text. De exemplu, în cele mai multe alte funcții unde este necesar un număr, valoarea text "19" se convertește la numărul 19. Totuși, în formula ISNUMBER("19") , "19" nu este transformat dintr-o valoare text într-o valoare numerică și funcția ISNUMBER returnează FALSE.
Funcțiile IS sunt utile în formule pentru testarea rezultatului unui calcul. Atunci când sunt combinate cu funcția IF , ele asigură o metodă de a localiza erorile din formule (vedeți exemplele următoare).
