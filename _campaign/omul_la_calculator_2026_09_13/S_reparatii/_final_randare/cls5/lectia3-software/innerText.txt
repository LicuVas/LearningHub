🎯 Provocare: Organizează fișierele ca un profesionist!

Vei crea o structură de dosare pentru temele tale și vei exersa operații de bază cu fișiere. Poți face asta pe orice calculator (Windows, Mac) sau pe tableta școlii.

Deschide managerul de fișiere

 Pe Windows: click pe iconița Explorer (File Explorer) (dosarul galben din bara de jos). Pe Mac: Finder. Pe tableta Android: Fișiere sau Files.

Mergi în folderul Documents (Documente)

 Găsește și deschide folderul Documente din bara din stânga. Aceasta e zona unde salvezi temele.

Creează un folder nou

 Click dreapta într-un spațiu gol → New → Folder (în Windows în română, comanda aflată în același loc în meniu). Numește-l cu clasa și numele tău: Clasa_Nume_Teme (de exemplu 5A_Popescu_Teme). Calculatoarele nu se șterg după oră, așa că un folder cu numele tău nu se amestecă cu al altui elev. Dacă profesorul are un folder al clasei, fă-l acolo — întreabă profesorul unde este.

Creează încă două sub-foldere

 Deschide folderul tău (de exemplu 5A_Popescu_Teme) și creează înăuntru două foldere: Matematica și Romana.

Creează un fișier de test

 În folderul tău (nu în Matematica sau Romana): click dreapta → New → Text Document (în Windows în română, comanda aflată în același loc în meniu). Numește-l nota_de_test.txt. Acesta simulează o temă.

Copiază fișierul

 Click dreapta pe nota_de_test.txt → Copiere (Copy). Deschide folderul Matematica, click dreapta → Lipire (Paste). Fișierul original rămâne, copia apare în Matematica. În Windows 11, Decupare, Copiere, Lipire, Redenumire și Ștergere sunt pictograme mici sus în meniu (numele apare când ții mouse-ul pe ele); lista veche cu cuvinte e la Afișați mai multe opțiuni (Show more options). În Windows 10 sunt cuvinte în listă. Merge oricum și cu tastatura: Ctrl+C, apoi Ctrl+V.

Copiaza

Operatii de baza cu fisiere (Windows):
 Creare folder: Click dreapta → New → Folder
 Creare fisier: Click dreapta → New → Text Document
 Copiere: Click dreapta → Copiere (Copy), apoi Lipire (Paste) (Ctrl+C, Ctrl+V)
 Mutare: Click dreapta → Decupare (Cut), apoi Lipire (Paste) (Ctrl+X, Ctrl+V)
 Redenumire: Click dreapta → Redenumire (Rename) (sau F2)
 Stergere: Click dreapta → Ștergere (Delete) (sau tasta Delete)
 In Windows 11: Copiere, Decupare, Lipire, Redenumire, Ștergere = pictograme sus in meniu.

Software vs Hardware

🧠

Software vs Hardware

Software = programe și instrucțiuni pentru calculator (nu le poți atinge).

Hardware = părțile fizice ale calculatorului (le poți atinge: monitor, tastatură, procesor).

💭 Analogie din viața ta

Gândește-te la un robot:

Hardware = corpul robotului (brațe, roți, senzori) - părțile fizice

Software = programul care îi spune ce să facă (mergi înainte, ridică obiect, evită obstacole)

Fără software, hardware-ul este doar o cutie de metal. Fără hardware, software-ul nu are unde să ruleze. Au nevoie unul de celălalt!

ℹ️ De reținut

Atunci când spui "calculatorul meu este lent", cauza poate fi la software (prea multe programe pornite singure, disc plin, programe vechi, virusuri) sau la hardware (piese vechi, RAM puțină). Verifici întâi software-ul. Dar dacă spui "programul nu funcționează", problema e la software (bug, versiune veche).

 Procesor, RAM, Hard Disk

Sistemul de Operare și Tipuri de Software

🋍

Sistem de Operare (OS)

Sistemul de operare este cel mai important software de pe calculator. El face legătura între hardware și celelalte programe. Fără sistem de operare, calculatorul nu poate funcționa!

💭 Analogie din viața ta

Sistemul de operare = Directorul școlii

Coordonează toate activitățile (ca directorul coordonează profesorii, elevii, sălile)

Alocă resurse (ca directorul alocă săli, ore, profesori)

Rezolvă conflicte (când două programe vor același lucru)

Comunică cu tine prin interfață (desktop, meniuri, iconițe)

💻 Sistem de Operare

Dispozitiv

Tipuri de Software

📦

Tipuri de Software

 Software-ul se împarte în trei categorii mari, fiecare cu un rol specific. E important să le recunoști pentru a înțelege cum funcționează calculatorul.

Straturile Software (de jos în sus)

🔧 HARDWARE

Procesor, RAM, Hard Disk, Monitor, Tastatură

⬇️

🋍 SISTEM DE OPERARE

Windows, Android, iOS, macOS, Linux

⬇️

📱 APLICAȚII + UTILITARE

Chrome, Word, Jocuri, Antivirus, Cleanup Tools

⬇️

👤 UTILIZATOR (TU!)

Interacționezi prin mouse, tastatură, ecran tactil

1️⃣ Software de Sistem

Programele care fac calculatorul să funcționeze. Cel mai important: sistemul de operare.

Windows Explorer (gestionează fișierele)

Device drivers (pentru imprimantă, placa video)

Firmware (software în hardware - BIOS)

2️⃣ Software Aplicativ (Aplicații)

Programele pe care le folosești pentru activități specifice.

Categorie

Exemple

Browsere Web

Google Chrome, Mozilla Firefox, Microsoft Edge

Editoare de text

Microsoft Word, Google Docs, Notepad

Spreadsheets

Microsoft Excel, Google Sheets

Grafică

Paint, Photoshop, Canva

Jocuri

Minecraft, Roblox, Fortnite

Social Media

WhatsApp, Instagram, TikTok (aplicații telefon)

3️⃣ Software Utilitar (Utilitare)

Programe care ajută la mentenanța și protecția calculatorului.

Antivirus - Avast, Norton, Windows Defender (protejează de virusuri)

Cleanup tools - CCleaner (șterge fișiere inutile)

Backup - Google Drive, OneDrive (copii de siguranță)

Arhivare - WinRAR, 7-Zip (comprimă fișiere)

Disc diagnostic - verificări hard disk, defragmentare

💭 Analogie din viața ta

Tipurile de software = Roluri într-o echipă de fotbal:

Sistem de operare = Antrenorul (coordonează echipa, face strategia)

Aplicații = Jucătorii (atacanți, apărători - fiecare cu rolul său)

Utilitare = Fizioterapeutul și doctorii (țin echipa sănătoasă, rezolvă probleme)

Organizarea Datelor pe Suport de Stocare

📁

Organizarea Datelor pe Suport de Stocare

 Datele (documentele, pozele, muzica) sunt salvate pe un suport de stocare (hard disk, SSD, USB, card SD). Sistemul de operare organizează aceste date în fișiere și dosare (directoare).

💭 Analogie din viața ta

Discul = un dulap de arhivă, folderele = sertarele, fișierele = foile din sertare

Dulapul (discul) conține sertare (dosare/foldere)

Fiecare sertar are o etichetă cu un nume (ex: Scoala, Poze)

În sertare se află foi (fișiere) cu informații

Poți pune sertare în sertare (sub-foldere)

Structura ierarhică a datelor

💾 Disc (C:\)

📁 Users → elev → Documents (Documente)

📁 Scoala

📄 tema_mate.docx

📄 referat.docx

📁 Familie

📷 vacanta.jpg

Ce înseamnă fiecare

💾 Discul = suportul fizic

📁 Folder = container (dosar)

📄 Fișier .docx = document text

📷 Fișier .jpg = imagine

ℹ️ Calea unui fișier

Fiecare fișier are o cale (path) care arată exact unde se află:

C:\Users\elev\Documents\Scoala\tema_mate.docx

Citim de la stânga la dreapta: discul C, folderul Users (utilizatorii), folderul contului elev, folderul Documents, sub-folderul Scoala, fișierul tema_mate.docx. În Windows în română, folderul Documents apare scris "Documente", dar în cale numele lui rămâne Documents. Pe un stick calea e mai scurtă, de exemplu E:\Scoala\tema_mate.docx.

💡 Cum să îți organizezi temele

Pe calculatorul de acasă, creează un folder Teme în Documente; la școală folosește folderul cu numele tău (de exemplu 5A_Popescu_Teme). În el, un sub-folder pe materie: Matematica, Romana, TIC. Fiecare temă într-un fișier cu data în nume: tema_mate_12_iun.docx. Vei găsi orice temă în 5 secunde!

Operații cu Fișiere și Directoare

⚙️

Operații cu Fișiere și Directoare

 Sistemul de operare îți permite să faci șase operații de bază cu fișiere și dosare. Le execuți din managerul de fișiere (File Explorer pe Windows, Finder pe Mac).

Operație

Ce face

Cum o execuți (Windows)

➕ Creare

Creează un fișier sau folder nou

Click dreapta → New → Folder / Text Document

📋 Copiere

Duplică fișierul; originalul rămâne

Ctrl+C, apoi Ctrl+V la destinație

✂️ Mutare

Mută fișierul; dispare din locul inițial

Ctrl+X, apoi Ctrl+V la destinație

🖉 Redenumire

Schimbă numele fișierului sau folderului

Click dreapta → Redenumire (Rename) (sau F2)

🗑️ Ștergere

Trimite fișierul în Coșul de reciclare

Tasta Delete sau click dreapta → Ștergere (Delete)

👀 Căutare

Găsește fișiere după nume sau conținut

Bara de căutare din Explorer (File Explorer) (sus-dreapta)

⚠️ Atenție la ștergere!

Când ștergi un fișier, el nu dispare definitiv — merge în Coșul de reciclare (Recycle Bin). Poți să îl recuperezi de acolo. Dacă golești coșul, fișierul este pierdut definitiv. Apasă Shift + Delete dacă vrei să ștergi definitiv de la început (fără recuperare).

💭 Copiere vs Mutare — analogie

Copiere = faci o xerox a unui document: ai și originalul și copia.

Mutare = iei fișierul dintr-un sertar și îl pui în alt sertar: există doar într-un singur loc.

💡 Scurtături utile de tastatură

Ctrl+C = Copiere (Copy)

Ctrl+X = Decupare (Cut), pentru mutare

Ctrl+V = Lipire (Paste)

F2 = Redenumire (Rename)

Delete = Șterge în Coș

Ctrl+Z = Anulează ultima operație (de exemplu o mutare sau o ștergere în Coș). NU te mai salvează după Shift+Delete sau după golirea Coșului.

[ASCUNS: pliat, se deschide la clic: Vezi rezolvarea]

Vezi rezolvarea

1. Clasificare:
Software de sistem: Windows 11 (sistem de operare), driver de imprimantă (face parte din software de sistem, comunică cu hardware-ul).
Software de aplicație: Google Chrome (browser web), Microsoft Word (editor de text), Paint (aplicație pentru desen).

Motiv: software-ul de sistem face calculatorul să funcționeze în general; software-ul de aplicație e folosit pentru o activitate specifică a utilizatorului; software-ul utilitar ajută la mentenanța și protecția calculatorului.

3. Mutare vs copiere: mutarea (Ctrl+X apoi Ctrl+V) șterge fișierul din locul inițial și îl pune doar la destinație; copierea (Ctrl+C apoi Ctrl+V) păstrează originalul și creează o copie. Folosești mutarea când vrei să organizezi definitiv (ex: din Desktop în Documente) și copierea când vrei o siguranță/backup, păstrând și originalul.

Ce ai învățat astăzi

Hardware vs Software: Hardware = părți fizice (atingi), Software = programe (instrucțiuni). Au nevoie unul de altul pentru a funcționa.

Sistem de Operare: Cel mai important software (Windows, Android, iOS, macOS, Linux). Coordonează calculatorul ca un director coordonează o școală.

Tipuri de Software: Sistem (OS), Aplicații (Word, Chrome, jocuri), Utilitare (antivirus, cleanup). Fiecare cu rolul său.

Organizarea datelor: Discul conține foldere (dosare), folderele conțin fișiere. Fiecare fișier are o cale unică (ex: C:\Users\elev\Documents\Scoala\tema.docx).

Operații cu fișiere: Creare, Copiere (Ctrl+C/V), Mutare (Ctrl+X/V), Redenumire (F2), Ștergere (Delete → Coș reciclare). Ctrl+Z anulează ultima operație, dar nu te salvează după Shift+Delete sau după golirea Coșului.

Vrei mai mult?

Provocare: Deschide Manager de activități (Task Manager) cu Ctrl+Shift+Esc și caută fila Aplicații cu executare în execuție la pornire (Startup apps) — fila cu lista programelor care pornesc singure; numele exact de pe ecran poate diferi puțin, după versiunea Windows. Acolo vezi programe care pornesc singure, automat, înainte să apeși tu pe orice - fără ca tu să le fi deschis manual. Notează 3 nume din listă și întreabă profesorul (sau caută) dacă sunt software de sistem, aplicații sau utilitare.
De ce: Un fișier cu extensia .docx nu poate fi deschis singur - are nevoie de programul Word ca să "înțeleagă" conținutul lui. De ce crezi că extensia unui fișier (.docx, .jpg, .mp3) decide automat ce program se deschide când faci dublu-click, în loc să te întrebe de fiecare dată?
În lumea reală: Această legătură dintre extensie și program se numește asociere de fișiere și o poți schimba chiar tu, din Setări Windows - de exemplu, poți face ca toate pozele .jpg să se deschidă automat în Paint în loc de aplicația Poze. Programatorii și designerii web lucrează zilnic cu zeci de extensii diferite (.html, .css, .py), fiecare asociată cu programul potrivit.
