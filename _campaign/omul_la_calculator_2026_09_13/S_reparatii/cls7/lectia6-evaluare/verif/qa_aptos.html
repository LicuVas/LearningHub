    Hi, I'm Diane and I'm happy to help you today.

    Aptos is the new default font so the change was automatic.

    In Outlook: Open a new document and on the Format Text tab. Click change Styles button, choose the font you want then click set as Default.

    In Word: Design tab - then select the font and set as default.

    Let me know how it goes, I'm here to help you further if needed.

    -- Diane
