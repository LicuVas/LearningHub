Windows provides several built-in ways to view CPU details, including the number of cores and logical processors. Use the following steps to determine how many cores your processor has on a Windows device. Windows 11 Windows 10 Right-click Start and select Task Manager . Tip Press Ctrl + Shift + Esc to also open Task Manager . Choose Performance from the left pane of the Task Manager window and select CPU .
