Software vs Hardware

🧠

Software vs Hardware

Software = programe si instructiuni pentru calculator (nu le poti atinge).

Hardware = partile fizice ale calculatorului (le poti atinge: monitor, tastatura, procesor).

💭 Analogie din viata ta

Gandeste-te la un robot:

Hardware = corpul robotului (brate, roti, senzori) - partile fizice

Software = programul care ii spune ce sa faca (mergi inainte, ridica obiect, evita obstacole)

Fara software, hardware-ul este doar o cutie de metal. Fara hardware, software-ul nu are unde sa ruleze. Au nevoie unul de celalalt!

ℹ️ De retinut

Atunci cand spui "calculatorul meu este lent", de obicei problema e la hardware (procesor slab, RAM putina). Dar daca spui "programul nu functioneaza", problema e la software (bug, versiune veche).

Relatia Hardware ↔ Software

 Procesor, RAM, Hard Disk

⚙️

Sistemul de Operare si Tipuri de Software

🋍

Sistem de Operare (OS)

Sistemul de operare este cel mai important software de pe calculator. El face legatura intre hardware si celelalte programe. Fara sistem de operare, calculatorul nu poate functiona!

💭 Analogie din viata ta

Sistemul de operare = Directorul scolii

Coordoneaza toate activitatile (ca directorul coordoneaza profesorii, elevii, salile)

Aloca resurse (ca directorul aloca sali, ore, profesori)

Rezolva conflicte (cand doua programe vor acelasi lucru)

Comunica cu tine prin interfata (desktop, meniuri, iconite)

💻 Sistem de Operare

Dispozitiv

Exemplu

Windows

PC, Laptop

Windows 10, Windows 11

macOS

Mac (Apple)

macOS Monterey, Ventura

Linux

PC, Servere

Ubuntu, Fedora

Android

Telefon, Tableta

iOS

iPhone, iPad

iOS 16, iPadOS 16

💡 Sfat

La scoala si acasa cel mai des folosesti Windows. Pe telefon probabil folosesti Android (Samsung, Xiaomi) sau iOS (iPhone). Toate fac acelasi lucru: coordoneaza calculatorul!

Tipuri de Software

📦

Tipuri de Software

 Software-ul se imparte in trei categorii mari, fiecare cu un rol specific. E important sa le recunosti pentru a intelege cum functioneaza calculatorul.

Straturile Software (de jos in sus)

🔧 HARDWARE

Procesor, RAM, Hard Disk, Monitor, Tastatura

⬇️

🋍 SISTEM DE OPERARE

Windows, Android, iOS, macOS, Linux

⬇️

📱 APLICATII + UTILITARE

Chrome, Word, Jocuri, Antivirus, Cleanup Tools

⬇️

👤 UTILIZATOR (TU!)

Interactionezi prin mouse, tastatura, ecran tactil

1️⃣ Software de Sistem

Programele care fac calculatorul sa functioneze. Cel mai important: sistemul de operare.

Windows Explorer (gestioneaza fisierele)

Device drivers (pentru imprimanta, placa video)

Firmware (software in hardware - BIOS)

2️⃣ Software Aplicativ (Aplicatii)

Programele pe care le folosesti pentru activitati specifice.

Categorie

Exemple

Browsere Web

Google Chrome, Mozilla Firefox, Microsoft Edge

Editoare de text

Microsoft Word, Google Docs, Notepad

Spreadsheets

Microsoft Excel, Google Sheets

Grafica

Paint, Photoshop, Canva

Jocuri

Minecraft, Roblox, Fortnite

Social Media

WhatsApp, Instagram, TikTok (aplicatii telefon)

3️⃣ Software Utilitar (Utilitare)

Programe care ajuta la mentenanta si protectia calculatorului.

Antivirus - Avast, Norton, Windows Defender (protejeaza de virusuri)

Cleanup tools - CCleaner (sterge fisiere inutile)

Backup - Google Drive, OneDrive (copii de siguranta)

Arhivare - WinRAR, 7-Zip (comprima fisiere)

Disc diagnostic - verificari hard disk, defragmentare

💭 Analogie din viata ta

Tipurile de software = Roluri intr-o echipa de fotbal:

Sistem de operare = Antrenorul (coordoneaza echipa, face strategia)

Aplicatii = Jucatorii (atacanti, aparatori - fiecare cu rolul sau)

Utilitare = Fizioterapeutul si doctorii (tin echipa sanatoasa, rezolva probleme)

Organizarea Datelor pe Suport de Stocare

📁

Organizarea Datelor pe Suport de Stocare

 Datele (documentele, pozele, muzica) sunt salvate pe un suport de stocare (hard disk, SSD, USB, card SD). Sistemul de operare organizeaza aceste date in fisiere si dosare (directoare).

💭 Analogie din viata ta

Discul = un dulap de arhiva, folderele = sertarele, fisierele = foile din sertare

Dulapul (discul) contine sertare (dosare/foldere)

Fiecare sertar are o eticheta cu un nume (ex: Scoala, Poze)

In sertare se afla foi (fisiere) cu informatii

Poti pune sertare in sertare (sub-foldere)

Structura ierarhica a datelor

💾 Disc (C:\)

📁 Documente

📁 Scoala

📄 tema_mate.docx

📄 referat.docx

📁 Familie

📷 vacanta.jpg

Ce inseamna fiecare

💾 Discul = suportul fizic

📁 Folder = container (dosar)

📄 Fisier .docx = document text

📷 Fisier .jpg = imagine

ℹ️ Calea unui fisier

Fiecare fisier are o cale (path) care arata exact unde se afla:

C:\Documente\Scoala\tema_mate.docx

Citim de la stanga la dreapta: discul C, folderul Documente, sub-folderul Scoala, fisierul tema_mate.docx.

💡 Cum sa iti organizezi temele

Creeaza un folder Teme in Documente. In el, un sub-folder pe materie: Matematica, Romana, TIC. Fiecare tema intr-un fisier cu data in nume: tema_mate_12_iun.docx. Vei gasi orice tema in 5 secunde!

Operatii cu Fisiere si Directoare

⚙️

Operatii cu Fisiere si Directoare

 Sistemul de operare iti permite sa faci sase operatii de baza cu fisiere si dosare. Le executi din managerul de fisiere (File Explorer pe Windows, Finder pe Mac).

Operatie

Ce face

Cum o executi (Windows)

➕ Creare

Creeaza un fisier sau folder nou

Click dreapta → New → Folder / Text Document

📋 Copiere

Duplica fisierul; originalul ramane

Ctrl+C, apoi Ctrl+V la destinatie

✂️ Mutare

Muta fisierul; dispare din locul initial

Ctrl+X, apoi Ctrl+V la destinatie

🖉 Redenumire

Schimba numele fisierului sau folderului

Click dreapta → Rename (sau F2)

🗑️ Stergere

Trimite fisierul in Cosul de reciclare

Tasta Delete sau click dreapta → Delete

👀 Cautare

Gaseste fisiere dupa nume sau continut

Bara de cautare din File Explorer (sus-dreapta)

⚠️ Atentie la stergere!

Cand stergi un fisier, el nu dispare definitiv — merge in Cosul de reciclare (Recycle Bin). Poti sa il recuperezi de acolo. Daca golesti cosul, fisierul este pierdut definitiv. Apasa Shift + Delete daca vrei sa stergi definitiv de la inceput (fara recuperare).

💭 Copiere vs Mutare — analogie

Copiere = faci o xerox a unui document: ai si originalul si copia.

Mutare = iei fisierul dintr-un sertar si il pui in alt sertar: exista doar intr-un singur loc.

💡 Scurtaturi utile de tastatura

Ctrl+C = Copiaza (Copy)

Ctrl+X = Taie pentru mutare (Cut)

Ctrl+V = Lipeste (Paste)

F2 = Redenumeste (Rename)

Delete = Sterge in Cos

Ctrl+Z = Anuleaza ultima operatie (Undo) — util daca ai sters gresit!

Exercitiul 1 (Nivel minim) - Recunoaste conceptele de baza

Cerinta: Raspunde la urmatoarele intrebari:

Ce inseamna software? Explica cu cuvintele tale diferenta dintre hardware si software si da cate 2 exemple pentru fiecare.

Ce este sistemul de operare? Numeste 2 sisteme de operare si spune pe ce dispozitive le gasesti.

Ce este un fisier? Ce este un folder? Care este diferenta dintre ele?

[ASCUNS: pliat, se deschide la clic: Vezi rezolvarea]

Vezi rezolvarea

1. Ce inseamna software? Software = programe si instructiuni pentru calculator, pe care NU le poti atinge (spre deosebire de hardware, partile fizice). Exemple hardware: monitor, tastatura. Exemple software: Windows, Google Chrome.
2. Sistemul de operare este cel mai important software de pe calculator - face legatura intre hardware si celelalte programe; fara el, calculatorul nu poate functiona. Exemple: Windows (pe PC/laptop), Android (pe telefon/tableta).
3. Fisier vs folder: un fisier este un document cu informatii (ex: tema_mate.docx), iar un folder (dosar) este un container in care pui fisiere legate de acelasi subiect, ca sa le gasesti usor - de exemplu folderul Scoala contine fisierul tema_mate.docx.

Exercitiul 2 (Nivel standard) - Clasificare si operatii cu fisiere

Cerinta: Analizeaza si aplica:

Clasifica urmatoarele programe in "software de sistem" sau "software de aplicatie": Windows 11, Google Chrome, driver de imprimanta, Microsoft Word, antivirus, Paint. Explica de ce le-ai pus in fiecare categorie.

Ai structura: Desktop/Proiect/date.xlsx si Desktop/Proiect/raport.docx. Vrei sa pastrezi ambele fisiere si sa le ai si intr-un folder de backup. Ce operatie faci si care vor fi pasii exacst?

Explica diferenta dintre "a muta" si "a copia" un fisier. In ce situatie ai folosi mutarea si in ce situatie copierea?

[ASCUNS: pliat, se deschide la clic: Vezi rezolvarea]

Vezi rezolvarea

1. Clasificare:
Software de sistem: Windows 11 (sistem de operare), driver de imprimanta (face parte din software de sistem, comunica cu hardware-ul), antivirus (protejeaza si intretine sistemul).
Software de aplicatie: Google Chrome (browser web), Microsoft Word (editor de text), Paint (aplicatie pentru desen).
Motiv: software-ul de sistem face calculatorul sa functioneze in general; software-ul de aplicatie e folosit pentru o activitate specifica a utilizatorului.
2. Pastrare + backup: operatia este Copiere (nu mutare), pentru ca vrei fisierele si in locul original, si in backup. Pasi: selectezi date.xlsx si raport.docx din Desktop/Proiect, Ctrl+C, deschizi folderul de backup, Ctrl+V.
3. Mutare vs copiere: mutarea (Ctrl+X apoi Ctrl+V) sterge fisierul din locul initial si il pune doar la destinatie; copierea (Ctrl+C apoi Ctrl+V) pastreaza originalul si creeaza o copie. Folosesti mutarea cand vrei sa organizezi definitiv (ex: din Desktop in Documente) si copierea cand vrei o siguranta/backup, pastrand si originalul.

Ce ai invatat astazi

Hardware vs Software: Hardware = parti fizice (atingi), Software = programe (instructiuni). Au nevoie unul de altul pentru a functiona.

Sistem de Operare: Cel mai important software (Windows, Android, iOS, macOS, Linux). Coordoneaza calculatorul ca un director coordoneaza o scoala.

Tipuri de Software: Sistem (OS), Aplicatii (Word, Chrome, jocuri), Utilitare (antivirus, cleanup). Fiecare cu rolul sau.

Organizarea datelor: Discul contine foldere (dosare), folderele contin fisiere. Fiecare fisier are o cale unica (ex: C:\Documente\Scoala\tema.docx).

Operatii cu fisiere: Creare, Copiere (Ctrl+C/V), Mutare (Ctrl+X/V), Redenumire (F2), Stergere (Delete → Cos reciclare). Ctrl+Z anuleaza orice greseala!

Vrei mai mult?

Provocare: Deschide Task Manager (Ctrl+Shift+Esc) si cauta tab-ul Startup apps. Acolo vezi programe care pornesc singure, automat, inainte sa apesi tu pe orice - fara ca tu sa le fi deschis manual. Noteaza 3 nume din lista si intreaba profesorul (sau cauta) daca sunt software de sistem, aplicatii sau utilitare.
De ce: Un fisier cu extensia .docx nu poate fi deschis singur - are nevoie de programul Word ca sa "inteleaga" continutul lui. De ce crezi ca extensia unui fisier (.docx, .jpg, .mp3) decide automat ce program se deschide cand faci dublu-click, in loc sa te intrebe de fiecare data?
In lumea reala: Aceasta legatura dintre extensie si program se numeste asociere de fisiere si o poti schimba chiar tu, din Setari Windows - de exemplu, poti face ca toate pozele .jpg sa se deschida automat in Paint in loc de aplicatia Poze. Programatorii si designerii web lucreaza zilnic cu zeci de extensii diferite (.html, .css, .py), fiecare asociata cu programul potrivit.
