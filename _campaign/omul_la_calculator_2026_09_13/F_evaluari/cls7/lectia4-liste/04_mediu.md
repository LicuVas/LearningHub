# 04 — Mediul presupus (U4) · lectia4-liste

**Ce presupune lecția:** Microsoft Word pentru Windows, interfață în **engleză** (Home, Paragraph, Bullets, Numbering, Multilevel List, Define New Bullet, Define New Number Format, Continue Numbering, Restart at 1, Set Numbering Value, Sort, Increase/Decrease Indent, View › Ruler, File › Options › Proofing › AutoCorrect Options › AutoFormat As You Type). Versiunea nu e declarată. Nicio variantă LibreOffice, nicio mențiune de limbă română a interfeței.

**Ce se știe (text brut Microsoft Support, 13.09.2026, `surse/raw/`):**
| Lecția scrie | Word în română (ro-ro) | Sursa |
|:--|:--|:--|
| Home › Bullets / Numbering | Pornire › Marcatori / Numerotare; pe pagina de definire: „Listă cu marcatori”, „Listă numerotată” | `surse/s01`, `s02` |
| Multilevel List | Listă multinivel | `define_new_ro-ro.txt` |
| Define New Bullet / Symbol / Picture / Font | Definire marcator nou / Simbol / Imagine / Font | `s02` |
| Define New Number Format | Definire format nou de numerotare (câmp „Stil număr”) | `s02` |
| Restart at 1 / Set Numbering Value | Repornire de la 1 / Setați valoarea de numerotare | `s04` |
| Continue Numbering | **nu apare** pe paginile citite (nici en-us) — NECONFIRMAT | `s04` |
| Sort | Pornire › Sortare; „listă ... cu un singur nivel” | `s05` |
| File › Options › Proofing › AutoCorrect › AutoFormat As You Type › Automatic bulleted/numbered lists | Fișier › Opțiuni › Verificare › Opțiuni AutoCorecție › AutoFormatare la tastare › Liste automat cu marcatori / Liste automat numerotate | `s06` |

Observație: chiar Microsoft numește butonul în două feluri (en-us „Bullets” pe o pagină, „Bulleted List” pe alta; ro-ro „Marcatori” vs „Listă cu marcatori”) — numele depinde de versiune. Ce vede elevul pe ecran se află doar în laborator.

**Afirmații tehnice verificate:**
- Clic pe marcator = selectează **toți** marcatorii listei / nivelului, nu un element; Ctrl+A = tot documentul (`s03`). Lecția (atomul 9) greșește.
- Crearea automată: Microsoft numește asteriscul și „1.” (`s06`); lecția scrie „1.”, „1)” și „-” și omite asteriscul. „1)” și „-”: NEVERIFICAT (nu apar pe pagină).
- Sortarea: Microsoft o descrie pentru liste cu un singur nivel; lecția nu spune.
- „9 niveluri”, „1.27 cm / 0.63 cm”: nu apar pe paginile citite — NEVERIFICAT (minor).
- Ce format primește nivelul 2 după Tab într-o listă cu I, II, III: nu e în documentație — `gasit: neclar`; se vede doar în Word-ul din laborator.

**Laborator:** Office/versiune/limbă NECUNOSCUTE (B_context_real.md §3). Office-ul de pe PC-ul lui Vasile (en-us) nu spune nimic despre laborator. LibreOffice (dacă e instalat în școală) are alte nume și alt meniu pentru liste — lecția nu îl acoperă.
