# Runda 22 — tabelul diferențelor (Windows, unghiul gest_tastatura)

## Sursele citate
- **U** = `referinte/uia_windows.json`
- **S-MS** = https://support.microsoft.com/en-us/accessibility/windows/use-a-screen-reader-to-explore-and-navigate-the-start-menu-in-windows. Citit pe 21.11.2026; nu e în `surse_microsoft.md`, care e înghețat. Citatele:
  - Secțiunea „Search (Windows 11)”:
    - „Press the Windows key to open the Start menu. You hear: "Search box, edit."”
    - „Type the search words for the action you want to perform. The list of search results is updated as you type.”
    - „The search results are automatically categorized into apps, documents, and web results.”
    - „Use the Up or Down arrow key to browse through the search results.”
    - „When you've found the result you want, press Enter to select it and to perform the action.”
  - Secțiunea „Navigate to Pinned and All apps”:
    - „press the Tab key until you hear "Pinned," followed by the name of the first pinned app. Then use the arrow keys to navigate the apps, and press Enter to open the selected app.”
  - Nota de la „Navigate other Start menu items”:
    - „To navigate the options in the Start menu's grid view, use the arrow keys.”
