📄 Proba D - Competente Digitale

🎯 Ce este Proba D?

Proba D la Bacalaureat evalueaza competentele digitale de baza. E obligatorie pentru toate profilele, inclusiv Artistic. Vestea buna: tot ce inveti aici e aplicat pe exemple din lumea ta — muzica, arta, performanta.

  • Program de concert in Word → inveti procesare text
  • Buget eveniment in Excel → inveti calcul tabelar
  • Prezentare instrument in PowerPoint → inveti prezentari
  • Afis concert in GIMP → inveti editare imagini
  • Profil SoundCloud/YouTube → inveti internet si comunicare
