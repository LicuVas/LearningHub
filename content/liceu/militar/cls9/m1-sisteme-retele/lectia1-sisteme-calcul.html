Componentele sistemului de calcul

Obiectivul lectiei

Vei intelege ce este un sistem de calcul, cum se imparte in componente hardware si software, cum functioneaza procesorul (UAL, UC, registri, cache, ciclu fetch-decode-execute), ce rol joaca placa de baza (magistrale, chipseturi, BIOS/UEFI), ce interfete de conectare exista (placa sunet, retea, video, USB), cum se organizeaza informatiile in fisiere si foldere si cum aplici aceste cunostinte in activitati de birou si evidenta specifica mediului militar.

Dupa aceasta lectie vei putea:

  • Sa identifici si sa descrii componentele hardware principale ale unui sistem de calcul: procesor (UAL, UC, registri, cache), memorie RAM, stocare (HDD/SSD), periferice
  • Sa explici ciclul fetch-decode-execute si rolul fiecarei etape in executia unui program
  • Sa descrii rolul placii de baza: magistrale, chipseturi, BIOS/UEFI
  • Sa identifici interfetele de conectare: placa sunet, placa de retea, placa video, USB
  • Sa explici rolul sursei de alimentare si al sistemului de racire
  • Sa explici diferenta dintre hardware si software si sa dai exemple din fiecare categorie
  • Sa definesti sistemul de operare si sa enumeri functiile lui esentiale
  • Sa descrii interfata grafica (GUI) si cum o folosesti pentru operatii uzuale
  • Sa organizezi fisiere si foldere respectand o structura logica de evidenta
  • Sa aplici principii de securitate digitala in gestionarea documentelor oficiale

Incearca singur!

Provocare (context militar):

Imagineaza-ti ca esti ofiterul de serviciu si trebuie sa predai tura. Pe calculatorul din birou se afla rapoarte, planuri de instructie si situatii cu personalul. Cine se ocupa ca datele sa fie salvate corect pe disc, ca imprimanta sa functioneze si ca fiecare utilizator sa aiba acces doar la dosarele lui? Noteaza ce crezi tu ca face acel strat de software care coordoneaza totul.

💡 Ai nevoie de un indiciu? ▶

Gandeste-te la un sergent-major de unitate: el nu realizeaza el insusi fiecare sarcina, dar coordoneaza resursele — cine primeste echipament, cine are acces in depozit, cine lucreaza pe ce post. In lumea calculatoarelor, acest coordonator se numeste sistem de operare.

1

1. Ce este un sistem de calcul

Un sistem de calcul este ansamblul format din componente hardware (fizice) si componente software (programe), impreuna cu datele prelucrate, care lucreaza coordonat pentru a primi, prelucra, stoca si transmite informatii.
Analogie cu mediul militar:

Un sistem de calcul seamana cu o unitate militara: hardware = personalul si echipamentul (oameni, vehicule, armament); software = regulamentele si ordinele de zi (ce face fiecare, in ce ordine, cu ce resurse). Fara regulamente, echipamentul sta neutilizat; fara echipament, regulamentele raman pe hartie.

De retinut: In liceu si in activitatea de birou militar vei folosi cel mai des calculatoare personale (desktop sau laptop) conectate in retea locala. Aceeasi structura hardware + software se regaseste insa si in servere, imprimante de retea sau sisteme de comunicatii digitale.

2

2. Componente hardware principale — CPU, placa de baza, interfete

Hardware inseamna toate componentele fizice ale calculatorului. Ele se impart in componente interne (instalate in carcasa) si periferice (conectate din exterior). Programa TIC cls. IX impune cunoasterea in detaliu a procesorului, placii de baza si a interfetelor de conectare.
Procesorul (CPU) — structura interna

CPU este format din mai multe unitati functionale care colaboreaza:

UAL — Unitatea Aritmetica si Logica: efectueaza calculele aritmetice (adunare, scadere, inmultire, impartire) si operatiile logice (AND, OR, NOT, comparatii). Este "calculatorul" propriu-zis din procesor.

UC — Unitatea de Control: "dirijorul" procesorului — citeste instructiunile din memorie, le decodifica si coordoneaza toate celelalte unitati (UAL, registre, cache, magistrale) sa execute sarcina corecta.

Registrele: memorii ultrarapide aflate chiar in interiorul CPU, de capacitate mica (biti/octeti), care pastreaza temporar datele si instructiunile in curs de executie. Accesul la registre este de mii de ori mai rapid decat la RAM.

Memoria cache: memorie tampon rapida (L1, L2, L3) situata intre CPU si RAM. Pastreaza copii ale datelor frecvent accesate, reducand numarul de accese lente la RAM. Cache L1 este cel mai mic si mai rapid (integrat direct in nucleu); L3 este mai mare, partajat intre nuclee.

Ciclul fetch-decode-execute (ciclul masina)

Fiecare instructiune este procesata in trei etape repetate continuu de UC:

1. Fetch (extragere): UC citeste instructiunea urmatoare din memoria RAM (sau cache) si o aduce in registrul de instructiuni al procesorului.

2. Decode (decodificare): UC interpreteaza codul binar al instructiunii — ce operatie trebuie efectuata si ce date sunt implicate.

3. Execute (executie): UAL sau alta unitate functionala executa operatia (calcul, comparatie, transfer de date). Rezultatul este stocat intr-un registru sau scris inapoi in memorie.

Procesoarele moderne executa miliarde de astfel de cicluri pe secunda (frecventa in GHz). Exemple de CPU: Intel Core i5/i7, AMD Ryzen.

Placa de baza — magistrale, chipseturi, BIOS/UEFI

Placa de baza (motherboard) este circuitul principal al calculatorului — pe ea se monteaza sau se conecteaza toate componentele: CPU, RAM, stocare, placi de extensie, periferice.

Magistralele (bus): cai electrice prin care circula datele intre componente. Exista magistrala de date (transporta valorile), magistrala de adrese (indica locatia din memorie) si magistrala de control (semnale de comanda). Latimea magistralei (32/64 biti) determina cate date se pot transfera simultan.

Chipseturi: circuite integrate pe placa de baza care gestioneaza comunicatia intre CPU, RAM, stocare si periferice. Chipsetul nord (northbridge) conecta CPU cu RAM si placa video; chipsetul sud (southbridge) gestioneaza stocarea si porturile externe. Pe procesoarele moderne, northbridge este integrat direct in CPU.

BIOS / UEFI: program de initializare stocat pe un cip de pe placa de baza. La pornire, BIOS/UEFI verifica hardware-ul (POST — Power-On Self Test), detecteaza componentele si incarca sistemul de operare. UEFI este varianta moderna a BIOS-ului: interfata grafica, suport discuri mari (peste 2 TB), pornire mai rapida (Secure Boot).

Interfete de conectare: placa sunet, retea, video, USB

Placa de sunet: converteste semnale digitale in sunet analog (pentru boxe/casti) si invers (pentru microfon/inregistrare). Poate fi integrata pe placa de baza sau separata (placa de extensie PCIe) pentru calitate audio superioara.

Placa de retea (NIC — Network Interface Card): permite conectarea calculatorului la reteaua locala (LAN) prin cablu Ethernet (RJ-45) sau wireless (Wi-Fi — 802.11ac/ax). Pe calculatoarele din institutii se foloseste de regula conexiunea cu fir (mai sigura, mai stabila).

Placa video (GPU — Graphics Processing Unit): proceseaza si genereaza imaginea afisata pe monitor. Poate fi integrata in CPU (Intel UHD Graphics, AMD Radeon Vega) — suficienta pentru birou — sau dedicata (placa PCIe separata) pentru grafica intensiva. Conectori de iesire: HDMI, DisplayPort, VGA (mai vechi).

USB (Universal Serial Bus): interfata universala pentru conectarea perifericelor externe: tastatura, mouse, stick USB, imprimanta, scanner, incarcator. Versiuni: USB 2.0 (480 Mb/s), USB 3.0/3.1 (5–10 Gb/s), USB-C (reversibil, poate transporta si energie si video).

Memoria RAM, stocare (HDD/SSD), periferice

RAM (Random Access Memory): memoria de lucru temporara. Pastreaza programele si datele active. Continutul se sterge la oprire. Capacitate tipica: 8–16 GB. Viteza RAM (DDR4/DDR5) influenteaza direct performanta sistemului.

HDD (Hard Disk Drive) — disc magnetic rotativ, ieftin pentru capacitati mari (1–4 TB), mai lent. SSD (Solid State Drive) — memorie flash, mult mai rapid, silentios, rezistent la socuri. Ambele stocheaza permanent datele.

Periferice de intrare: tastatura, mouse, scanner, camera web, microfon. Periferice de iesire: monitor, imprimanta, boxe. Mixte: ecran tactil, multifunctionale.

Surse de alimentare si racire

Sursa de alimentare (PSU — Power Supply Unit): converteste curentul alternativ de la priza (220V AC) in tensiuni continue necesare componentelor: 12V (pentru CPU, placa video, motoare HDD), 5V si 3.3V (pentru placi de circuit, RAM, USB). Puterea PSU se masoara in watti (W); un calculator de birou are tipic 300–500W.

Racirea procesorului: CPU produce caldura proportional cu frecventa si tensiunea de operare. Metodele principale: racire cu aer — radiator metalic cu ventilator (heatsink + fan) montat pe CPU; racire cu lichid — sistem cu pompa, radiator si tub cu lichid termic, mai eficienta pentru procesoare de inalta performanta. Temperatura normala de operare: 40–80°C sub sarcina.

Relevanta militara: Cunoasterea arhitecturii unui sistem de calcul iti permite sa diagnostichezi cauze probabile ale defectiunilor (ex: supraincalzire = verifici racirea, calculator lent la pornire = verifici BIOS/POST, port USB nefunctional = verifici driverul sau interfata), sa estimezi capacitatile reale ale echipamentelor din dotare si sa comunici eficient cu personalul de suport tehnic.

3

3. Software — tipuri si exemple

Software inseamna toate programele si datele care ruleaza pe hardware. Se clasifica in doua mari categorii:
Software de sistem

Gestioneaza resursele hardware si ofera platforma pentru celelalte programe. Cel mai important: sistemul de operare (Windows, Linux, macOS). Tot aici intra driverele (programe care fac hardware-ul sa comunice cu SO) si utilitarele de sistem (antivirus, backup).

Software de aplicatii

Programe pentru sarcini concrete: suite de birou (Microsoft Office, LibreOffice) pentru documente si prezentari, browsere web (Chrome, Firefox), aplicatii de comunicare (e-mail, videoconferinta), baze de date, aplicatii specifice de evidenta militara.

Licente software

Comercial (proprietar): cumperi dreptul de utilizare; sursa este secreta (ex: Windows, Microsoft Office). Open-source / liber: codul sursa este public, poti folosi si distribui gratuit (ex: Linux, LibreOffice). Institutiile publice, inclusiv cele militare, opteaza adesea pentru solutii open-source din ratiuni de cost si securitate.

4

4. Sistemul de operare si interfata grafica (GUI)

Sistemul de operare (SO) este primul program incarcat la pornirea calculatorului si ramane activ tot timpul. El gestioneaza resursele (procesor, RAM, disc, periferice) si ofera o interfata prin care tu si aplicatiile puteti folosi acele resurse.
Analogie cu structura de comanda militara

SO este ca un stat-major: aplicatiile (unitatile subordonate) trimit cereri — "am nevoie de resurse de calcul", "vreau sa salvez un fisier", "tipareste acest document". Statul-major (SO) aloca resursele corect, impiedica conflictele si tine evidenta cine ce a primit.

Interfata grafica (GUI — Graphical User Interface)

Modul vizual de interactiune cu SO: ferestre, pictograme (icoane), meniuri si butoane, controlate cu mouse-ul si tastatura. Exemple: desktopul Windows cu bara de activitati (taskbar) si butonul Start, Finder pe macOS, GNOME pe Linux. GUI este intuitiv si potrivit pentru utilizatorii care nu sunt specialisti IT.

Operatii uzuale prin GUI

Prin interfata grafica poti: lansa aplicatii cu dublu-clic pe pictograma, crea si sterge fisiere si foldere, copia si muta documente prin drag-and-drop sau copy-paste, schimba setarile sistemului din Setari / Panou de control, verifica spatiul liber pe disc, conecta si deconecta dispozitive USB.

Procedura standard in birou militar: La preluarea postului, verifica prin GUI spatiul liber pe disc (click dreapta pe unitate → Proprietati), confirma ca documentele din ziua precedenta sunt salvate si inchide sesiunea utilizatorului anterior inainte de a te loga cu propriul cont.

5

5. Organizarea fisierelor si folderelor

SO organizeaza datele intr-o structura arborescenta de foldere (directoare) si fisiere. Un folder poate contine subfoldere si fisiere la orice adancime. Fiecare fisier are un nume si o extensie care indica tipul sau.
Extensii frecvente si tipul de continut

.docx — document Word (text formatat, tabele, imagini)
.xlsx — foaie de calcul Excel (date tabelate, formule, grafice)
.pptx — prezentare PowerPoint (slide-uri)
.pdf — document portabil, aspect fix, sigur pentru distribuire
.jpg / .png — imagini fotografice / imagini cu transparenta
.txt — text simplu fara formatare

Structura de foldere recomandata pentru evidenta militara

O organizare logica reduce timpul de cautare si previne pierderea documentelor:

Unitate_Militara_2026\
  Rapoarte_Zilnice\
    raport_zilnic_2026-06-01.docx
    raport_zilnic_2026-06-02.docx
  Planuri_Instructie\
    plan_instructie_S25_2026.docx
  Evidenta_Personal\
    situatie_personal_iun2026.xlsx
  Arhiva_2025\
Reguli de denumire (bune practici)

Foloseste data in format AAAA-LL-ZZ pentru sortare cronologica automata.
Evita spatii — foloseste linie de subliniere ( _ ) sau linie scurta ( - ).
Evita caractere speciale: / \ : * ? " < > | — sunt interzise in numele de fisiere pe Windows.
Pastreaza versiunile: raport_v1.docx, raport_v2.docx — nu suprascrie varianta precedenta pana la aprobare finala.
Arhiveaza documentele mai vechi de un an intr-un subfolder Arhiva_AAAA\.

Calea fisierului: Localizarea exacta a unui fisier se exprima prin calea completa, de exemplu: C:\Unitate_Militara_2026\Rapoarte_Zilnice\raport_zilnic_2026-06-15.docx. Litera C: indica unitatea de disc, iar \ separa nivelurile de foldere.

6

6. Securitatea informatiei la calculator

Documentele digitale necesita aceleasi masuri de protectie ca documentele pe hartie. SO ofera mai multe mecanisme de securitate pe care utilizatorul trebuie sa le cunoasca si sa le aplice.
Conturi de utilizator si permisiuni

Fiecare persoana are un cont propriu protejat prin parola sau PIN. Exista doua niveluri: cont standard (acces la propriile fisiere, nu poate instala programe sau schimba setari de sistem) si cont de administrator (control complet). In mediul institutional, utilizatorii obisnuiti au conturi standard — limiteaza pagubele in caz de eroare sau atac.

Blocarea sesiunii la parasirea postului

Combinatia Windows + L blocheaza imediat ecranul fara a inchide programele. Este echivalentul incuierii biroului: datele sunt in siguranta, dar aplicatiile raman deschise pentru cand te intorci. Regula de serviciu: orice operator paraseste calculatorul cu sesiunea blocata, indiferent de durata absentei.

Antivirus si actualizari de securitate

Antivirusul detecteaza si blocheaza programele malitioase (virusi, ransomware, troieni) care pot fura, cripta sau distruge fisiere. Actualizarile SO corecteaza vulnerabilitati cunoscute. Ambele trebuie mentinute la zi — un calculator neprotejat sau neactualizat este un risc pentru intreaga retea a unitatii.

Parole puternice

O parola puternica are minim 12 caractere, combina litere mari/mici, cifre si caractere speciale si nu contine date personale (nume, data nasterii). Institutiile impun de regula schimbarea parolei periodic (la 30–90 de zile). Nu impartasi parola cu nimeni, nici cu colegii de tura.

Atentie: Un stick USB necunoscut gasit sau primit de la o sursa nesigura NU se conecteaza niciodata la calculatoarele din dotare — poate contine programe malitioase care se lanseaza automat la conectare (atac tip "USB drop").

7

7. Recapitulare — Sistemul de calcul in contextul activitatii militare

Ai parcurs componentele esentiale ale unui sistem de calcul. Mai jos este o sinteza a conexiunilor dintre notiunile invatate, ilustrata prin activitati reale de birou militar.
Flux de lucru: redactarea si arhivarea unui raport zilnic

1. Pornesti calculatorul → sistemul de operare (software de sistem) se incarca, initializeaza procesorul si RAM-ul, detecteaza perifericele.

2. Te autentifici cu contul propriu (cont standard) → SO verifica parola si incarca profilul tau.

3. Deschizi aplicatia (ex: Microsoft Word) cu dublu-clic prin interfata grafica (GUI) → SO aloca memorie RAM aplicatiei.

4. Redactezi raportul → datele exista temporar in RAM; daca se intrerupe curentul fara salvare, se pierd.

5. Salvezi fisierul (Ctrl+S) cu denumirea raport_zilnic_2026-06-20.docx in folderul Rapoarte_Zilnice\ → SO scrie datele pe HDD/SSD (stocare permanenta).

6. Blochezi sesiunea (Win+L) la parasirea postului → securitate.

7. La sfarsitul lunii, muti fisierele in Arhiva_2026\Iunie\ → organizare ierarhica de foldere.

Termen cheie de retinut: diferenta dintre stocare temporara (RAM — se sterge la oprire) si stocare permanenta (HDD/SSD — datele persista). Pierderea de date nesalvate este cel mai frecvent incident in birouri — salveaza frecvent si foloseste backup.

Exercitii practice

Exercitiul 1 (Nivel minim) — Clasificare componente

Clasifica urmatoarele elemente in doua coloane: Hardware si Software. Elemente: procesor Intel Core i5, Windows 11, tastatura, Microsoft Word, SSD de 512 GB, driver de imprimanta, monitor, antivirus. Noteaza pentru fiecare componenta hardware daca este componenta interna sau periferic.

Vezi rezolvarea

Hardware (componente fizice):

  1. procesor Intel Core i5 - componenta interna
  2. SSD de 512 GB - componenta interna (stocare)
  3. tastatura - periferic
  4. monitor - periferic

Software (programe):

  1. Windows 11 - software de sistem (sistemul de operare)
  2. driver de imprimanta - software de sistem (face hardware-ul sa comunice cu SO)
  3. antivirus - software de sistem (utilitar)
  4. Microsoft Word - software de aplicatii

Regula de clasificare: daca se atinge fizic, e hardware; daca e cod care ruleaza, e software. Componenta interna = instalata in carcasa; periferic = conectat din exterior.

Exercitiul 2 (Nivel standard) — Structura de foldere pentru evidenta unitatii

Esti numit responsabil cu arhiva digitala a clasei. Propune o structura de foldere (cu cel putin 3 niveluri) pentru urmatoarele tipuri de documente: planuri de instructie saptamanale, rapoarte de absente, situatii cu note la examene, fotografii de la activitati. Justifica denumirile alese si formatul datei utilizat.

Vezi rezolvarea

Structura propusa (4 niveluri), dupa modelul din lectie:

Clasa_IX_2026-2027\

  1. Planuri_Instructie\plan_instructie_S03_2026-09-15.docx
  2. Rapoarte_Absente\raport_absente_2026-09.docx
  3. Situatii_Note\situatie_note_examen_2026-06.xlsx
  4. Fotografii_Activitati\2026-10-20_ziua_sportului\foto_001.jpg

Justificare denumiri: fiecare tip de document are folderul lui, ca sa nu se amestece cautarile. Formatul datei este AAAA-LL-ZZ (ex: 2026-09-15) - asezat asa, Windows sorteaza fisierele automat in ordine cronologica, spre deosebire de formatul 15 septembrie care s-ar amesteca alfabetic cu alte luni. Denumirile nu au spatii sau diacritice, pentru compatibilitate intre sisteme.

Exercitiul 3 (Nivel performanta) — Plan de securitate digitala pentru biroul de serviciu

Elaboreaza un plan scris de securitate digitala pentru un birou militar cu 3 calculatoare in retea. Planul trebuie sa includa: politica de parole (lungime minima, complexitate, frecventa schimbarii), procedura la parasirea postului, reguli privind dispozitivele USB externe, frecventa actualizarilor antivirus. Justifica fiecare masura prin riscul concret pe care il previne.

Vezi rezolvarea

Schita de rezolvare (nu raspunsul complet):

  1. Politica de parole - porneste de la ce s-a predat: minimum 12 caractere, litere mari/mici, cifre, simboluri (ex: Liceu_Mil#2026!); stabileste TU frecventa schimbarii si motiveaza-o prin riscul de compromitere in timp.
  2. Procedura la parasirea postului - foloseste Win+L (predat la Securitatea informatiei); leaga-o de riscul concret: sesiune deschisa = acces neautorizat la documente.
  3. Dispozitive USB externe - lectia NU acopera reguli specifice pentru USB; spune asta explicit si propune o regula rezonabila (ex: doar dispozitive verificate/autorizate), motivand riscul (malware, scurgere de date).
  4. Actualizari antivirus - lectia mentioneaza antivirusul ca utilitar de sistem, dar nu o frecventa exacta; documenteaza-te sau propune o valoare justificata (ex: automat, zilnic).

Criterii de evaluare: fiecare masura are un risc concret asociat; planul e specific (cifre, nu vorbe generale); recunosti clar ce depaseste lectia.

Ce ai invatat astazi

  • Sistemul de calcul = hardware (componente fizice) + software (programe), care lucreaza impreuna
  • CPU (procesor): UAL executa calculele, UC coordoneaza executia, registrele tin datele temporar, cache-ul (L1/L2/L3) accelereaza accesul la date
  • Ciclul masina (fetch-decode-execute): UC extrage instructiunea din memorie, o decodifica, UAL o executa — repetat de miliarde de ori pe secunda
  • Placa de baza: magistrale (date/adrese/control) conecteaza componentele; chipseturi gestioneaza comunicatia; BIOS/UEFI initializeaza hardware-ul la pornire
  • Interfete: placa sunet (audio), placa de retea (Ethernet/Wi-Fi), placa video (GPU, conectori HDMI/DisplayPort), USB (periferic universal, versiuni 2.0/3.0/C)
  • Sursa de alimentare (PSU): converteste 220V AC in 12V/5V/3.3V DC; racirea (heatsink+fan sau lichid) mentine CPU la temperatura sigura
  • RAM: memorie de lucru temporara; HDD/SSD: stocare permanenta; perifericele: intrare, iesire sau mixte
  • Software de sistem (SO, drivere) vs. software de aplicatii (Office, browser, e-mail)
  • Sistemul de operare coordoneaza resursele si ofera interfata grafica (GUI) cu ferestre, pictograme si meniuri
  • Organizarea fisierelor: structura arborescenta de foldere, extensii (.docx, .xlsx, .pdf, .jpg), denumiri clare cu data AAAA-LL-ZZ
  • Securitate digitala: conturi cu permisiuni, blocarea sesiunii (Win+L), antivirus actualizat, parole puternice, prudenta cu USB-uri externe
  • Fluxul complet: BIOS/UEFI porneste → SO se incarca → te autentifici → lucrezi in RAM → salvezi pe disc → blochezi sesiunea
