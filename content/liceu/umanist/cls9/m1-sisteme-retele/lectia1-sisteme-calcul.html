Componentele sistemului de calcul

Progres lectie:
0%
🎯

Obiectivul lectiei

Vei intelege din ce este alcatuit un calculator — ce componente fizice il formeaza, ce programe il fac sa functioneze, cum iti prezinta informatiile pe ecran si cum isi organizeaza documentele, referatele si fisierele tale.

Dupa aceasta lectie vei putea:

  • Sa identifici si sa descrii componentele hardware principale ale unui calculator (procesor, memorie, stocare, periferice)
  • Sa explici diferenta dintre hardware si software si sa dai exemple pentru fiecare
  • Sa definesti sistemul de operare si sa enumeri functiile lui principale
  • Sa descrii interfata grafica (GUI) si sa navighezi in ea eficient
  • Sa creezi o structura de foldere logica pentru proiectele tale scolare

Incearca singur!

Provocare:

Imaginati-va ca scrieti un referat despre Mihai Eminescu. Deschideti un document Word, scrieti cateva randuri, salvati fisierul si il imprimati. Ce s-a intamplat la fiecare pas? Ce componente ale calculatorului au intrat in actiune? Ganditi-va la tastatura, ecran, memoria calculatorului, disc si imprimanta — si notati ce credeti ca face fiecare.

💡 Ai nevoie de un indiciu?

Tastatura este un dispozitiv de intrare — trimite litere catre calculator. Ecranul este un dispozitiv de iesire — afiseaza rezultatul. Memoria RAM tine textul cat timp lucrezi. Discul (sau SSD-ul) pastreaza fisierul dupa ce salvezi. Imprimanta este tot dispozitiv de iesire — produce o copie pe hartie.

Toate aceste componente fizice formeaza impreuna hardware-ul. Programul Word care le coordoneaza este software.

1

Hardware si software — cele doua fete ale calculatorului

Un sistem de calcul este alcatuit din doua categorii inseparabile:
  • Hardware — totalitatea componentelor fizice, tangibile: procesor, memorie, disc, ecran, tastatura, imprimanta. Le poti vedea si atinge.
  • Software — totalitatea programelor si datelor: sistemul de operare, Word, Chrome, fisierele tale. Nu le poti atinge — exista ca instructiuni si informatii stocate numeric.
Analogie din lumea cartilor:

O carte are o parte fizica (hartia, coperti, cerneala) — acesta este hardware-ul ei. Textul, ideile, povestea scrisa pe pagini — acesta este software-ul. Poti tine cartea in mana, dar nu poti tine in mana povestea lui Hamlet — o poti citi, dar ea exista ca informatie, nu ca obiect material.

Exemple concrete pentru un licean umanist:

Hardware: tastatura pe care scrii eseul, ecranul pe care il citesti, imprimanta care il tipareste, stick-ul USB pe care il salvezi.
Software: Microsoft Word (procesorul de text), dictionarul online, motorul de cautare, sistemul de operare care face totul sa functioneze impreuna.

2

Componentele hardware — ce face fiecare

Calculatorul este construit dupa o arhitectura cu unitati functionale clare. Fiecare are un rol distinct:
Procesorul (CPU — Central Processing Unit)

Creierul calculatorului. Executa instructiunile programelor: calculeaza, compara, decide. Viteza lui se masoara in GHz (gigahertz) — de exemplu, un CPU de 3,5 GHz executa 3,5 miliarde de operatii elementare pe secunda. Cu cat e mai rapid, cu atat editezi si textele mai fluiditate, fara intarzieri.

Memoria RAM (Random Access Memory)

Memoria de lucru — temporara. Tine deschis documentul la care lucrezi, taburile din browser, aplicatiile active. Se goleste la inchidere, de aceea trebuie sa salvezi! O memorie RAM mai mare inseamna mai multe aplicatii deschise simultan fara a incetini calculatorul. Marimea tipica: 8–16 GB.

Stocarea pe termen lung: HDD si SSD

Hard disk-ul (HDD) si SSD-ul (Solid State Drive) pastreaza datele permanent — sistemul de operare, programele, documentele, fotografiile, muzica. Spre deosebire de RAM, datele raman si dupa inchiderea calculatorului. SSD-ul este mai rapid si mai silent decat HDD-ul (nu are piese mobile). Capacitate tipica: 256 GB – 2 TB.

Dispozitive de intrare si iesire

Intrare (Input): tastatura, mouse, microfon, camera web, scaner — trimit informatii catre calculator.
Iesire (Output): ecranul (monitor), difuzoarele, imprimanta — primesc informatii de la calculator si le prezinta utilizatorului.
Intrare+Iesire: ecranul tactil (touchscreen) — trimite si primeste informatii.

3

Sistemul de operare — administratorul calculatorului

Sistemul de operare (SO) este programul de baza care porneste primul si care gestioneaza toate componentele hardware si toate celelalte programe. Fara SO, calculatorul ar fi o masa de componente fara viata.
Analogie: bibliotecarul dintr-o biblioteca publica

Intr-o biblioteca, bibliotecarul stie unde se afla fiecare carte, imparte spatiul cititorilor, gestioneaza imprumuturile si asigura ca nimeni nu perturba pe altii. Sistemul de operare face exact acelasi lucru pentru calculator: stie unde se afla fiecare fisier, distribuie memoria si procesorul intre aplicatii si asigura ca un program nu ii strica pe ceilalti.

Functiile principale ale sistemului de operare:

• Gestionarea fisierelor — organizeaza documentele, imaginile, muzica in foldere pe disc
• Gestionarea programelor — permite deschiderea, rularea si inchiderea aplicatiilor
• Gestionarea memoriei — aloca RAM fiecarei aplicatii deschise
• Gestionarea dispozitivelor — comunica cu tastatura, imprimanta, stick-ul USB
• Securitatea — parole, conturi de utilizatori, protectie date

Exemple de sisteme de operare:

Windows (Microsoft) — cel mai raspandit pe calculatoare personale si in scoli
macOS (Apple) — folosit pe calculatoarele Mac
Linux (Ubuntu, Fedora etc.) — gratuit, popular pe servere si la informaticieni
Android / iOS — sistemele de operare de pe telefoanele mobile

4

Interfata grafica (GUI) — cum comunici cu calculatorul

GUI (Graphical User Interface — Interfata Grafica pentru Utilizator) este modul vizual prin care interactionezi cu sistemul de operare. In loc sa scrii comenzi text, folosesti ferestre, pictograme, meniuri si butoane — pe care dai clic cu mouse-ul sau atingi pe ecran tactil.
Elementele interfetei grafice Windows — o harta rapida:

Desktop — suprafata principala, ca biroul tau fizic; poti pune pe el scurtaturi la fisierele si programele des folosite
Bara de activitati (Taskbar) — bara de jos cu butonul Start, programele deschise si ceasul
Pictograme (Icoane) — imagini mici care reprezinta programe, fisiere sau foldere
Ferestre — zone dreptunghiulare in care ruleaza fiecare program; pot fi reduse, marite sau inchise cu butoanele din coltul dreapta sus (― □ ✕)
Meniuri — liste de optiuni care apar la clic (ex: Fisier → Salvare)
File Explorer (Windows Explorer) — programul cu care navighezi prin foldere si fisiere

De ce conteaza pentru tine ca elev umanist?

Cand lucrezi la un eseu despre Revolutia Franceza, GUI-ul te ajuta sa deschizi simultan mai multe ferestre: Word cu eseul, browser-ul cu surse, un PDF cu textul original. Poti comuta rapid intre ele cu Alt+Tab (Windows) sau le poti aranja pe ecran cu functia Snap.

5

Organizarea fisierelor si folderelor — biblioteca ta digitala

Sistemul de operare organizeaza toate datele intr-o structura ierarhica de foldere (directoare) si fisiere. Folderele sunt containere care pot contine alte foldere sau fisiere — exact ca dulapurile si dosarele dintr-un secretariat scolar.
Tipuri de fisiere pe care le vei folosi:

.docx / .odt — documente text (Word, LibreOffice Writer) — eseuri, referate, fise
.pdf — document portabil, recomandat pentru trimiterea referatelor (se vede identic pe orice calculator)
.pptx / .odp — prezentari (PowerPoint, LibreOffice Impress) — dezbateri, proiecte orale
.jpg / .png — imagini — fotografii, harti, ilustratii
.mp3 / .mp4 — audio / video — inregistrari, documentare

O structura de foldere recomandata pentru un elev umanist:

Gandeste-ti calculatorul ca pe o biblioteca. Propune aceasta structura:

Scoala/
    Clasa_IX/
        Romana/ → Eseu_Enigma.docx, Analiza_Haiku.pdf
        Istorie/ → Referat_Renastere.docx, Harta_Europa_1648.jpg
        Engleza/ → Prezentare_Shakespeare.pptx
        TIC/ → Lectia1_notite.docx

Principii: nume clare (nu "document1", ci "Eseu_Eminescu_cls9"), fara diacritice in nume de fisiere (pentru compatibilitate maxima), backup regulat pe un stick USB sau in cloud (Google Drive).

Operatii de baza cu fisiere (fara a scrie cod):

In File Explorer (Windows) sau Finder (macOS) poti:
• Crea un folder nou: clic-dreapta → Folder nou
• Redenumi: clic-dreapta → Redenumire (sau F2)
• Copia: Ctrl+C → navighezi in destinatie → Ctrl+V
• Muta: Ctrl+X → Ctrl+V (sau trage cu mouse-ul)
• Sterge: tasta Delete (merge in Cos de gunoi; definitiv cu Shift+Delete)

6

Recapitulare — Sistemul de calcul in 5 idei-cheie

Aceasta lectie in rezumat:
1. Hardware vs Software

Hardware = componente fizice (CPU, RAM, disc, tastatura, ecran). Software = programe si date (sistemul de operare, Word, fisierele tale). Ambele sunt necesare — una fara cealalta nu functioneaza.

2. Componentele cheie

CPU (procesor — creierul) → RAM (memorie temporara de lucru) → HDD/SSD (stocare permanenta) → periferice intrare (tastatura, mouse) → periferice iesire (ecran, imprimanta).

3. Sistemul de operare

Primul program incarcat la pornire; gestioneaza hardware-ul, programele, memoria, fisierele si securitatea. Exemple: Windows, macOS, Linux, Android, iOS.

4. Interfata grafica (GUI)

Modul vizual de comunicare cu calculatorul: desktop, pictograme, ferestre, meniuri. Alt+Tab comuta intre ferestre deschise.

5. Organizarea fisierelor

Ierarhie: foldere (general → particular) si fisiere cu extensii clare (.docx, .pdf, .pptx, .jpg). Nume descriptive, backup pe stick/cloud. Operatii: Ctrl+C/X/V, F2, Delete.

Exercitii practice

Exercitiul 1 (Nivel minim) — Clasifica componentele

Sorteaza urmatoarele componente in coloanele Hardware si Software: tastatura, sistem de operare Windows, procesor Intel Core i5, Microsoft Word, ecran LCD, RAM 8 GB, Google Chrome, stick USB 32 GB, LibreOffice Impress, imprimanta. Scrie lista in caietul de TIC sau intr-un document Word.

Exercitiul 2 (Nivel standard) — Planifica-ti biblioteca digitala

Creaza pe calculatorul tau o structura de foldere pentru anul scolar, cu minimum 4 materii umaniste (de ex. Romana, Istorie, Engleza, Logica). In fiecare folder de materie creeaza cel putin un sub-folder (ex: Referate, Eseuri, Prezentari) si un fisier text gol cu un nume descriptiv. Fa o captura de ecran (PrintScreen + lipire in Paint sau Word) cu structura si salveaz-o in folderul TIC.

Exercitiul 3 (Nivel performanta) — Investigheaza si argumenteaza

Un coleg sustine ca "daca ai RAM mai multa, nu mai ai nevoie de un disc (SSD/HDD) mare". Explica in scris (minim 10 randuri) de ce afirmatia este gresita, descriind rolul distinct al RAM (memorie temporara) si al SSD/HDD (stocare permanenta), cu exemple concrete din activitatea ta scolara (referate, prezentari, fotografii). Prezinta textul ca un argument structurat: teza — argumente — concluzie.

Ce ai invatat astazi

  • Hardware = componente fizice; Software = programe si date — ambele indispensabile
  • CPU = creierul; RAM = memorie de lucru temporara; HDD/SSD = stocare permanenta
  • Periferice de intrare (tastatura, mouse) vs iesire (ecran, imprimanta)
  • Sistemul de operare gestioneaza totul: programe, memorie, fisiere, dispozitive, securitate
  • GUI = interfata grafica: desktop, pictograme, ferestre, meniuri — navigare cu mouse
  • Organizarea fisierelor: ierarhie logica de foldere, extensii, nume descriptive, backup
