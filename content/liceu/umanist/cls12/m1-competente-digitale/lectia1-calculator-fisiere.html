Sistemul de calcul si gestionarea fisierelor

Progres lectie:
0%

Obiectivul lectiei

Aceasta lectie acopera fundamente de competente digitale necesare pentru Proba D (Competente Digitale) — examen national separat de disciplina TIC din programa cls XII. Programa TIC cls XII umanist (OMECI 5099/2009) prevede tehnoredactare asistata de calculator (Filologie) sau tehnici de documentare (Stiinte Sociale); cunostintele despre sistemul de calcul si gestionarea fisierelor sunt verificate explicit la Proba D si constituie baza pe care se construiesc lectiile urmatoare despre tehnoredactare si documentare digitala.

Dupa aceasta lectie vei putea (competente evaluate la Proba D):

  • Sa identifici componentele principale ale unui sistem de calcul (hardware si software) — subiect frecvent in grila Proba D
  • Sa explici rolul sistemului de operare si al interfetei grafice (desktop, File Explorer)
  • Sa navighezi ierarhia de foldere si sa localizezi fisiere in Windows Explorer — operatie ceruta la sectiunea practica
  • Sa efectuezi operatii esentiale: copiere, mutare, redenumire, stergere, creare folder, arhivare ZIP
  • Sa recunosti formatele de fisier uzuale si extensiile lor (.docx, .xlsx, .pdf, .jpg, .zip)
  • Sa aplici o strategie de organizare a fisierelor pentru un proiect de tip referat sau portofoliu digital

Nota curriculara: Continutul acestei lectii corespunde programei TIC cls IX (OMECI 5099/2009, componente hardware/software, sistemul de operare Windows). Este inclus ca recapitulare necesara pentru Proba D, nu ca materie noua de cls XII.

Incearca singur!

Provocare (inainte de lectie):

Imagineaza-ti ca trebuie sa predai maine un referat despre un scriitor roman, o fotografie scanata a unui manuscris si o prezentare PowerPoint. Ai toate fisierele imprastiate pe desktop, in Descarcari si intr-un stick USB. Cum le-ai organiza rapid ca sa nu pierzi nimic si sa le trimiti usor pe email? Descrie in cateva randuri ce pasi ai face.

💡 Ai nevoie de un indiciu?

Gandeste-te la o biblioteca: cartile nu stau aruncate pe jos -- sunt asezate pe rafturi, pe sectiuni. Pe calculator, folderele sunt rafturile, iar fisierele sunt cartile. Un folder Referat_Eminescu cu subfoldere Text, Imagini si Prezentare iti ofera aceeasi ordine.

Dupa aceasta lectie vei sti exact cum se face acest lucru -- pas cu pas, pentru proba D!

1

1. Componentele unui sistem de calcul

Un sistem de calcul (calculator, laptop, tableta) este format din doua mari categorii de componente:
  • Hardware -- tot ce este fizic, palpabil: procesorul (CPU), memoria RAM, unitatea de stocare (HDD sau SSD), ecranul, tastatura, mouse-ul, imprimanta.
  • Software -- programele si datele: sistemul de operare (Windows, macOS), aplicatiile (Word, browser, Excel), fisierele tale (documente, fotografii).
Analogie cu biblioteca scolara:

Hardware-ul este cladirea bibliotecii, rafturile, mesele si lampile -- tot ce exista fizic. Software-ul sunt cartile, catalogul si regulamentul de imprumut -- informatia si regulile care dau sens spatiului. Fara carti, cladirea e goala; fara cladire, cartile n-au unde sta.

Exemple concrete pentru proba D:

La proba practica lucrezi pe un calculator de laborator cu tastatura, mouse si ecran (hardware) si cu Windows + Microsoft Office instalat (software). Fisierele pe care le creezi (documente Word, foi Excel, prezentari PowerPoint) sunt tot software -- date salvate pe disc.

2

2. Sistemul de operare si interfata grafica

Sistemul de operare (SO) este programul fundamental care porneste primul si ramane activ tot timpul. El:
  • Gestioneaza memoria, procesorul si dispozitivele de stocare
  • Iti ofera interfata grafica (GUI): desktop, ferestre, meniuri, taskbar
  • Permite aplicatiilor (Word, browser, Excel) sa ruleze impreuna fara conflicte
  • Asigura securitatea prin conturi de utilizator si parole
Cel mai folosit SO pe calculatoarele de laborator din Romania este Windows (Microsoft).
Elementele desktopului Windows pe care le vei folosi la proba D:

Desktop -- suprafata principala, unde poti plasa scurtaturi la fisiere si foldere.

Taskbar -- bara de jos cu butonul Start, aplicatiile deschise si ceasul.

File Explorer -- aplicatia pentru gestionarea fisierelor si folderelor. Se deschide cu tasta Win + E.

Meniu contextual (clic dreapta) -- lista de optiuni la clic dreapta pe un fisier sau folder: Copiere, Lipire, Redenumire, Stergere, Proprietati.

Context umanist -- analogie cu arhiva unui istoric:

Un arhivar care lucreaza cu documente istorice are nevoie de un sistem de clasificare: dosare, rafturi, etichete. Sistemul de operare face acelasi lucru pentru fisierele tale digitale -- iti ofera instrumentele de organizare, ca sa gasesti rapid eseul despre Renastere sau fotografiile de la vizita la muzeu.

3

3. Fisiere, foldere si ierarhia de directoare

Fisierul este unitatea de baza de stocare a informatiei: un document Word, o fotografie, un PDF, o prezentare. Fiecare fisier are:
  • Nume -- ales de tine (ex: referat_eminescu)
  • Extensie -- adaugata automat de program, indica tipul fisierului (ex: .docx, .pdf, .jpg)
  • Dimensiune -- cantitatea de spatiu ocupata pe disc (kB, MB, GB)
  • Data modificarii -- cand a fost salvat ultima oara
Folderul (directorul) este un container care grupeaza fisiere si alte foldere -- echivalentul unui dosar fizic.
Ierarhia de directoare -- structura arborescenta:

Fisierele sunt organizate ca un arbore: radacina (C:\) contine foldere, fiecare folder poate contine subfoldere si fisiere, si asa mai departe.

Exemplu de structura pentru un elev de profil umanist:

C:\
  Documente\
    Scoala_ClasaXII\
      Romana\
        referat_ion_creanga.docx
        bibliografie.docx
      Istorie\
        eseu_primul_razboi.docx
        harta_europa_1914.jpg
      Limbi_Straine\
        compunere_franceza.docx

Calea completa a unui fisier arata asa: C:\Documente\Scoala_ClasaXII\Romana\referat_ion_creanga.docx

Reguli de denumire recomandate:

Evita spatii si caractere speciale (?, *, :, /) in numele fisierelor -- pot crea probleme la trimiterea pe email sau la salvarea pe stick USB. Foloseste liniuta de jos (_) in loc de spatiu. Exemplu bun: referat_eminescu_v2.docx

4

4. Formate de fisiere si extensii uzuale

Extensia (ex: .docx, .pdf) este sufixul de dupa ultimul punct din numele fisierului si indica programul care l-a creat si formatul de stocare. Windows poate ascunde extensiile implicit -- recomandat sa le afisezi (File Explorer: View > Show > File name extensions).
Formate frecvente la proba D -- Competente Digitale:

Documente text:

  • .docx -- Microsoft Word 2007 si versiunile ulterioare; format implicit, cu formatare bogata
  • .doc -- Microsoft Word 97-2003; format mai vechi
  • .pdf -- Portable Document Format; aspect fix, recomandat pentru trimitere si tiparire; nu se editeaza usor
  • .txt -- text simplu, fara formatare, compatibil cu orice program

Foi de calcul:

  • .xlsx -- Microsoft Excel 2007 si versiunile ulterioare; foi de calcul cu formule si grafice

Prezentari:

  • .pptx -- Microsoft PowerPoint 2007 si versiunile ulterioare; prezentari cu diapozitive

Imagini:

  • .jpg / .jpeg -- fotografie comprimata cu pierderi de calitate; fisiere mici, ideal pentru fotografii
  • .png -- imagine cu compresie fara pierderi, suporta transparenta; ideal pentru capturi de ecran si grafice
  • .bmp -- bitmap necomprimat, fisiere mari; mai rar folosit astazi

Arhive:

  • .zip -- arhiva comprimata standard, nativa in Windows; grupeaza mai multe fisiere intr-unul singur
  • .rar -- arhiva comprimata; necesita WinRAR sau 7-Zip pentru deschidere
Context umanist -- cand conteaza formatul?

Cand trimiti un referat profesorului prin email, formatul .pdf garanteaza ca arata identic indiferent de calculatorul destinatarului -- fonturile, marginile si imaginile nu se deplaseaza. Formatul .docx este mai bun daca profesorul trebuie sa faca comentarii sau corectii. Intreaba intotdeauna ce format este cerut!

5

5. Operatii esentiale cu fisiere si foldere

Proba D cere sa efectuezi rapid operatii standard cu fisiere. Toate se pot face in File Explorer, fie prin meniu contextual (clic dreapta), fie prin scurtaturi de tastatura.
Operatii de baza -- metode si scurtaturi:

Selectare:

  • Un singur fisier: clic stanga pe el
  • Mai multe fisiere neadiacente: Ctrl + clic stanga pe fiecare
  • O plaja de fisiere consecutive: clic pe primul, apoi Shift + clic pe ultimul
  • Toate fisierele dintr-un folder: Ctrl + A

Copiere: Selecteaza > Ctrl + C > naviga la destinatie > Ctrl + V

Mutare: Selecteaza > Ctrl + X > naviga la destinatie > Ctrl + V

Stergere: Selecteaza > tasta Delete (merge in Cos de reciclare) sau Shift + Delete (stergere definitiva, fara Cos)

Redenumire: Selecteaza > tasta F2 > scrie noul nume > Enter

Creare folder nou: In File Explorer, in locul dorit: Ctrl + Shift + N sau clic dreapta > New > Folder

Proprietati fisier (dimensiune, data, tip): clic dreapta > Properties

Anulare ultima actiune: Ctrl + Z (functioneaza si in File Explorer!)

Arhivare ZIP -- pas cu pas in Windows (fara programe suplimentare):

1. Selecteaza fisierele sau folderul pe care vrei sa le arhivezi

2. Clic dreapta pe selectie

3. In Windows 11: alege Compress to ZIP file. In Windows 10: Send to > Compressed (zipped) folder

4. Tasteaza numele arhivei si apasa Enter

Rezultatul este un fisier .zip care contine tot ce ai selectat. Pentru a extrage: clic dreapta pe fisierul .zip > Extract All.

Context umanist -- organizarea unui portofoliu de dezbateri:

Clasa ta organizeaza o dezbatere despre impactul Revolutiei Franceze. Fiecare echipa trebuie sa predea un dosar digital. Structura recomandata:

Dezbatere_Revolutia_Franceza\
  Echipa_Pro\
    argument_principal.docx
    surse_bibliografice.docx
    grafic_cronologie.png
  Echipa_Contra\
    argument_principal.docx
    surse_bibliografice.docx
  Prezentare_finala.pptx

La final, selectezi folderul Dezbatere_Revolutia_Franceza, il comprimi in ZIP si il trimiti pe email. Un singur fisier, totul inclus.

6

6. Navigare in File Explorer si locatii importante

File Explorer este aplicatia Windows pentru gestionarea fisierelor. Se deschide cu Win + E. In panoul din stanga (panoul de navigare) gasesti locatiile principale ale utilizatorului.
Locatii esentiale in Windows:
  • Desktop -- suprafata vizibila; accesibil si din File Explorer
  • Documents (Documente) -- locul recomandat pentru fisierele de lucru; calea: C:\Users\[NumeUtilizator]\Documents
  • Downloads (Descarcari) -- unde ajung implicit fisierele descarcate din browser
  • Pictures (Imagini) -- loc implicit pentru fotografii
  • This PC (Acest PC) -- afiseaza toate unitatile de disc (C:, D:) si dispozitivele conectate (stick USB, card SD)
Bara de adrese si cautarea in File Explorer:

Bara de adrese (sus, in File Explorer) afiseaza calea completa a folderului curent. Poti da clic pe ea, tasta o cale direct (ex: C:\Documente) si apasa Enter pentru a naviga rapid.

Cautare: In coltul dreapta-sus al File Explorer exista o caseta de cautare. Daca tastezi referat, Windows va gasi toate fisierele cu acel cuvant in nume, in folderul curent si subfolderele sale.

Afisare extensii fisiere: File Explorer > View (Vizualizare) > Show (Afisare) > bifezi File name extensions. Astfel vei vedea daca un fisier este raport.docx sau raport.pdf -- esential la proba D!

Stick USB la proba D -- atentie la copiere vs mutare:

La proba practica vei primi uneori fisiere pe un stick USB (apare ca unitate D: sau E: in This PC). Copiaza fisierele pe calculatorul local (in Documents sau pe Desktop) inainte de a lucra cu ele. Motivul: stick-ul poate fi mai lent si risca sa se deconecteze accidental. Dupa terminarea lucrarii, copiaza rezultatul inapoi pe stick sau salveaza in locul indicat de supraveghetor.

7. Recapitulare -- Fundamente Proba D (sistem de calcul si fisiere)

Un rezumat al lucrurilor esentiale din aceasta lectie, cu focus pe Proba D. Aminteste-ti: aceasta materie (hardware/SO/fisiere) este specifica programei TIC cls IX si este reluata aici strict ca pregatire pentru examenul national Proba D, nu ca disciplina noua de cls XII. Lectiile urmatoare trec la continuturile reale ale clasei a XII-a: tehnoredactare, layout pagina, editare PDF, documentare web si multimedia.
Checklist proba D -- Sistem de calcul si fisiere:
  • ✓ Stiu sa deschid File Explorer (Win + E)
  • ✓ Stiu sa creez un folder nou (Ctrl + Shift + N)
  • ✓ Stiu sa copiez fisiere (Ctrl + C urmat de Ctrl + V)
  • ✓ Stiu sa mut fisiere (Ctrl + X urmat de Ctrl + V)
  • ✓ Stiu sa redenumesc un fisier (F2)
  • ✓ Stiu sa sterg un fisier (Delete) si sa recuperez din Cosul de reciclare
  • ✓ Stiu sa arhivez in ZIP (clic dreapta > Compress to ZIP file)
  • ✓ Recunosc extensiile: .docx, .xlsx, .pptx, .pdf, .jpg, .png, .zip
  • ✓ Stiu sa afisez extensiile fisierelor in File Explorer
  • ✓ Stiu sa navighez ierarhia de foldere si sa gasesc fisiere cu cautarea
Greseli frecvente la proba D si cum sa le eviti:

Problema: Salvezi fisierul cu numele gresit sau in locul gresit si nu il mai gasesti.

Solutie: Imediat ce creezi un fisier nou, salveaza-l (Ctrl + S) cu numele corect, in folderul indicat de sarcina. Verifica calea din bara de adrese a ferestrei de salvare. Salveaza din nou din cateva in cateva minute.

Problema: Stergi din greseala un fisier.

Solutie: Ctrl + Z anuleaza stergerea imediat. Alternativ, deschide Cosul de reciclare de pe desktop, gaseste fisierul si da clic dreapta > Restore.

Problema: Confunzi Copiere cu Mutare si pierzi fisierul sursa.

Solutie: Dupa Ctrl + X + Ctrl + V, fisierul dispare din locul initial. Daca ai nevoie sa ramana si acolo, foloseste intotdeauna Ctrl + C (Copiere).

Exercitii practice

Exercitiul 1 (Nivel minim) -- Identificare si organizare

Pe desktop-ul calculatorului ai urmatoarele fisiere: tema.docx, fotografie.jpg, calcule.xlsx, prezentare.pptx, raport_final.pdf. Creeaza pe desktop un folder numit Sarcini_TIC si muta toate aceste fisiere in el. Dupa mutare, scrie extensia fiecarui fisier si tipul sau (ex: .docx = document Word cu formatare, .jpg = imagine fotografica comprimata cu pierderi).

Vezi rezolvarea

Pasi:

  1. Clic dreapta pe desktop > New > Folder (sau Ctrl+Shift+N), apoi scrie numele Sarcini_TIC si Enter.
  2. Selecteaza toate cele 5 fisiere: clic pe primul, apoi Ctrl+clic pe fiecare dintre celelalte patru (fisiere neadiacente).
  3. Muta-le (nu copiere, pentru ca cerinta zice "muta"): Ctrl+X, apoi intra in folderul Sarcini_TIC si Ctrl+V.

Extensii si tip:

  1. .docx = document Word cu formatare (text, stiluri)
  2. .jpg = imagine fotografica, comprimata cu pierderi
  3. .xlsx = foaie de calcul Excel, cu formule si grafice
  4. .pptx = prezentare PowerPoint, cu diapozitive
  5. .pdf = document cu aspect fix, potrivit pentru tiparire/trimitere, nu se editeaza usor

Exercitiul 2 (Nivel standard) -- Structura de proiect literar

Trebuie sa predai un proiect pentru ora de Limba Romana despre opera lui Mihai Eminescu. Creeaza in folderul Documente urmatoarea structura: Proiect_Eminescu cu trei subfoldere: Text, Imagini si Bibliografie. In folderul Text creeaza un document Word gol numit eseu_eminescu.docx. In folderul Bibliografie creeaza un fisier text gol numit surse.txt. La final, selecteaza folderul Proiect_Eminescu si creeaza o arhiva ZIP numita Proiect_Eminescu.zip. Noteaza calea completa a fisierului eseu si dimensiunea arhivei ZIP.

Vezi rezolvarea

Structura de foldere (in Documente, Ctrl+Shift+N de fiecare data cand creezi un folder):

  1. Proiect_Eminescu (folder principal)
  2. in interior: Text, Imagini, Bibliografie

Fisiere goale: in Text, clic dreapta > New > Microsoft Word Document, redenumeste (F2) in eseu_eminescu.docx. In Bibliografie, clic dreapta > New > Text Document, redenumeste in surse.txt (extensiile trebuie afisate: View > Show > File name extensions).

Arhivare: selecteaza folderul Proiect_Eminescu, clic dreapta > Compress to ZIP file (sau Send to > Compressed folder), redenumeste in Proiect_Eminescu.zip.

Cale completa a eseului: C:\Users\[NumeUtilizator]\Documents\Proiect_Eminescu\Text\eseu_eminescu.docx. Dimensiunea arhivei ZIP se vede prin clic dreapta pe fisier > Properties > Size -- depinde de continutul real al fisierelor (goale, e de ordinul catorva KB).

Exercitiul 3 (Nivel performanta) -- Scenariu complet proba D

Simuleaza un scenariu de proba practica: (1) Primesti pe stick USB (unitate E:) un folder Materiale_Proba cu 3 fisiere: text_sursa.docx, date_statistice.xlsx, imagine_harta.png. (2) Copiaza folderul pe calculatorul local, in Documente -- nu il muta! (3) Redenumeste text_sursa.docx in referat_final.docx. (4) Creeaza in Materiale_Proba un subfolder Versiuni_anterioare si plaseaza acolo o copie a fisierului original (copiaza inainte de a redenumi). (5) Creeaza arhiva ZIP a intregului folder si numeste-o Predare_ProbaD.zip. Descrie fiecare pas efectuat si combinatiile de taste folosite.

Vezi rezolvarea

Schita de rezolvare (nivel performanta -- nu produsul gata, ci ordinea corecta a pasilor):

  1. Deschide This PC > unitatea E:, localizeaza Materiale_Proba.
  2. Copiaza (nu muta) folderul: selecteaza-l, Ctrl+C, navigheaza in Documents, Ctrl+V. Capcana: daca folosesti Ctrl+X in loc de Ctrl+C, stergi originalul de pe stick.
  3. In interiorul copiei, creeaza subfolderul Versiuni_anterioare (Ctrl+Shift+N).
  4. Ordinea conteaza: mai intai copiaza text_sursa.docx in Versiuni_anterioare (pastreaza originalul acolo), abia apoi redenumeste fisierul ramas afara in referat_final.docx (F2) -- daca redenumesti intai, nu mai ai de unde copia originalul cu numele vechi.
  5. Selecteaza tot folderul Materiale_Proba si arhiveaza-l ca Predare_ProbaD.zip.

Criterii de evaluare: respectarea ordinii copiere-inainte-de-redenumire, folosirea corecta a Ctrl+C vs Ctrl+X, existenta ambelor versiuni (originala si redenumita) in structura finala, numele exacte cerute pentru foldere/arhiva.

Ce ai invatat astazi

  • Hardware = componente fizice; Software = programe si date
  • Sistemul de operare (Windows) gestioneaza resursele si ofera interfata grafica (GUI)
  • Fisierele au: nume + extensie + dimensiune + data modificarii
  • Folderele organizeaza fisierele in ierarhie arborescenta (C:\ > folder > subfolder > fisier)
  • Extensii uzuale: .docx, .xlsx, .pptx, .pdf, .jpg, .png, .zip
  • Operatii esentiale: Ctrl+C (copiere), Ctrl+X (decupare), Ctrl+V (lipire), F2 (redenumire), Delete (stergere), Ctrl+Z (anulare)
  • Arhivare ZIP nativa in Windows: clic dreapta > Compress to ZIP file
  • Afiseaza extensiile fisierelor: File Explorer > View > Show > File name extensions

Vrei mai mult?

Provocare: ia folderul Sarcini_TIC creat la exercitiul 1 (sau orice folder cu mai multe fisiere mici). Clic dreapta pe el si deschide Properties: compara valoarea Size cu valoarea Size on disk. Repeta pentru un singur fisier foarte mic (un .txt de o litera) si pentru unul mare (o fotografie).

De ce te gandesti: de ce un fisier .txt de 1 octet arata pe disc 4 KB sau 8 KB in loc de 1 octet? Discul nu aloca spatiu octet cu octet - cauta indiciul in cuvantul unitate de alocare (cluster).

Unde se foloseste: arhivistii digitali (biblioteci, arhive nationale) si administratorii de retea calculeaza zilnic spatiul real ocupat pe servere, nu doar dimensiunea utila a fisierelor - diferenta conteaza cand ai mii de fisiere mici.
