Componenta software a unui sistem de calcul

Progres lectie:
0%
🎯

Obiectivul lectiei

Vei intelege ce este software-ul unui sistem de calcul, cum se clasifica, care sunt functiile sistemului de operare si cum se securizeaza un calculator prin instrumente software: firewall, antivirus, conturi de utilizator si actualizari de sistem.

Dupa aceasta lectie vei putea:

  • Sa clasifici tipurile de software: sistem de operare, aplicatii, utilitare
  • Sa descrii principalele functii ale sistemului de operare
  • Sa explici rolul firewall-ului, al conturilor de utilizator si al permisiunilor in securizarea SO
  • Sa descrii ce este malware-ul si cum il previne un antivirus actualizat
  • Sa deosebesti tipurile de licente software: freeware, open-source, comercial

Incearca singur!

Provocare:

Gandeste-te la calculatorul sau tableta pe care lucrezi. Enumera trei categorii de software pe care le folosesti si incadreaza fiecare in una dintre categoriile: sistem de operare, aplicatie sau utilitar.

💡 Ai nevoie de un indiciu?

Sistemul de operare gestioneaza resursele calculatorului (ex.: Windows, macOS, Linux). Aplicatiile sunt programe cu care lucreaza utilizatorul direct (ex.: browser, Word, Excel, aplicatii de biologie). Utilitarele sunt programe de intretinere si optimizare (ex.: antivirus, arhivator, defragmentator).

1

1. Clasificarea software-ului

Software-ul reprezinta totalitatea programelor si datelor care ruleaza pe un sistem de calcul. Se imparte in trei mari categorii: software de sistem (sistemul de operare), software aplicativ (aplicatii) si software utilitar.
Categorii principale de software:
  • Sistem de operare (SO) — gestioneaza resursele hardware si ofera o interfata intre utilizator si calculator; exemple: Windows 11, macOS, Linux Ubuntu
  • Software aplicativ — programe destinate utilizatorului final pentru sarcini specifice; exemple: Microsoft Word (documente), Google Chrome (browser), GeoGebra (matematica), Mendeley (gestiunea surselor bibliografice)
  • Software utilitar — programe de intretinere si optimizare a sistemului; exemple: antivirus, arhivator (WinRAR, 7-Zip), defragmentator, backup automat
Exemplu din stiinte ale naturii:

Un elev de biologie foloseste in acelasi timp: Windows 11 (SO), ImageJ (aplicatie de analiza imagini microscopice), Zotero (aplicatie de gestiune surse bibliografice) si Windows Defender (utilitar antivirus). Toate ruleaza pe acelasi calculator dar apartin categoriilor diferite.

De retinut: fara sistemul de operare, nicio aplicatie si niciun utilitar nu pot rula. SO este stratul fundamental al software-ului oricarui sistem de calcul.

2

2. Functiile sistemului de operare

Sistemul de operare este software-ul care controleaza hardware-ul calculatorului si intermediaza toate interactiunile dintre utilizator, aplicatii si echipamentele fizice. Fara SO, un calculator nu poate porni si nu poate rula niciun program.
Functiile principale ale sistemului de operare:
  • Gestionarea proceselor — porneste, opreste si prioritizeaza programele care ruleaza simultan; asigura ca fiecare aplicatie primeste timp de procesor
  • Gestionarea memoriei — aloca si elibereaza spatiu in RAM pentru fiecare program; previne conflictele intre programe
  • Gestionarea fisierelor si a stocarii — organizeaza datele in fisiere si foldere pe disc, controleaza accesul la ele
  • Gestionarea dispozitivelor de intrare/iesire — comunica cu tastatura, mouse-ul, imprimanta, camerele prin drivere
  • Gestionarea utilizatorilor si a securitatii — autentificare, conturi, permisiuni, criptare
  • Interfata cu utilizatorul — interfata grafica (GUI) sau in linie de comanda (CLI)
Exemple concrete:

Cand deschizi simultan Word, Chrome si ImageJ, sistemul de operare imparte timpul procesorului intre cele trei programe, aloca RAM fiecaruia si asigura ca fisierele de pe disc sunt accesate in ordine fara conflicte. Cand conectezi un microscop USB, SO incarca driverul corespunzator automat.

3

3. Securizarea sistemului de operare

Un sistem de operare modern include mai multe straturi de securitate software. Configurat corect, SO protejeaza datele utilizatorului impotriva accesului neautorizat, atacurilor din retea si software-ului malitios.
Instrumente de securitate ale SO:
  • Firewall — filtreaza traficul de retea; permite sau blocheaza conexiunile dupa reguli configurabile; Windows Firewall este activat implicit in Windows
  • Conturi de utilizator — fiecare persoana are propriul cont cu parola; contul Administrator are drepturi complete, contul Standard are drepturi limitate (nu poate instala programe fara aprobare)
  • Permisiuni pe fisiere si foldere — SO controleaza cine poate citi, modifica sau sterge fiecare fisier; previne accesul neautorizat la date sensibile
  • Criptarea datelor — BitLocker (Windows) sau FileVault (macOS) cripteaza intregul disc; daca dispozitivul e furat, datele raman ilizibile fara parola corecta
  • Actualizarile de securitate (Windows Update) — corecteaza vulnerabilitatile descoperite in SO si previn exploatarea lor de catre atacatori
Buna practica in laboratorul de informatica:

Calculatoarele dintr-un laborator scolar au de obicei conturi Standard pentru elevi (nu pot instala programe, nu pot modifica configuratia sistemului) si un cont Administrator folosit doar de profesor. Astfel, un elev nu poate afecta accidental sau intentionat configuratia celorlalti utilizatori.

4

4. Antivirus si malware — protectia software

Malware (prescurtare din malicious software) este orice program creat cu intentie daunatoare: fura date, deterioreaza sistemul sau blocheaza accesul la fisiere. Antivirusul este utilitarul software care detecteaza si elimina malware-ul.
Tipuri principale de malware:
  • Virus — se ataseaza la fisiere legitime si se copiaza singur la executare
  • Troian (Trojan horse) — pare o aplicatie utila dar ascunde functionalitati daunatoare
  • Ransomware — cripteaza fisierele utilizatorului si cere o suma de bani (rascumparare) pentru deblocare; extrem de periculos pentru date stiintifice nesalvate
  • Spyware — monitorizeaza activitatea utilizatorului si trimite datele atacatorului
  • Adware — afiseaza reclame nedorite; de obicei instalat alaturi de programe gratuite din surse nesigure
Masuri de protectie software:
  • Antivirus actualizat — scanare in timp real; Windows Defender (integrat, gratuit), Avast Free, Bitdefender Free; actualizarea bazei de date de semnaturi e esentiala pentru recunoasterea amenintarilor noi
  • Actualizari de sistem (Windows Update) — corecteaza vulnerabilitatile cunoscute din SO si aplicatii exploatate de malware
  • Backup regulat al datelor — daca fisierele sunt criptate de ransomware, le recuperezi din backup fara a plati
  • Prudenta la descarcare — verifica sursa; nu descarca programe piratate (crack-uri) sau fisiere din surse necunoscute
5

5. Licente software

Licenta software este contractul legal care specifica cum poate fi folosit, copiat, modificat si distribuit un program. Folosirea unui program fara licenta valida constituie piraterie software si este ilegala.
Tipuri principale de licente:
  • Comercial (proprietar) — trebuie cumparat; codul sursa nu e accesibil; exemple: Microsoft Office, Adobe Photoshop, SPSS
  • Freeware — gratuit pentru utilizare, dar codul sursa ramane proprietatea companiei; nu poate fi modificat; exemple: Adobe Acrobat Reader, Skype, VLC Media Player
  • Open-source — codul sursa este public; poate fi studiat, modificat si redistribuit in conditiile licentei; exemple: Linux, LibreOffice, Python, R (folosit in biologie si chimie computationala)
  • Shareware — versiune de incercare gratuita (trial), cu functionalitati limitate sau timp limitat; cumpararea deblocheaza versiunea completa
  • Creative Commons — licente pentru continut digital (text, imagini, date), nu pentru software executabil; frecvente in publicatiile stiintifice open-access
Relevanta in stiinte ale naturii:

Instrumentele stiintifice open-source sunt preferate in cercetare: R si Python (analiza statistica a datelor experimentale), ImageJ/Fiji (analiza imagini microscopice), GIMP (procesare imagini). Toate sunt legale, gratuite si pot fi instalate pe calculatoarele scolii fara costuri de licenta.

Pirateria software — riscuri dincolo de ilegalitate:

Programele piratate (crack-uri, keygen-uri) sunt un vector major de infectie cu malware: fisierele executabile modificate contin frecvent troieni sau ransomware. Un calculator infectat dintr-un crack poate compromite intreaga retea a laboratorului.

6

6. Recapitulare — Ce ai invatat

Rezumatul conceptelor esentiale ale acestei lectii:
Clasificarea software-ului

Sistem de operare (gestioneaza resursele hardware), aplicatii (sarcini specifice ale utilizatorului), utilitare (intretinere si optimizare). Fara SO, niciun alt program nu poate rula.

Functiile sistemului de operare

Gestionarea proceselor, memoriei, fisierelor, dispozitivelor I/O, utilizatorilor si securitatii; ofera interfata grafica sau in linie de comanda.

Securizarea SO

Firewall (filtreaza traficul de retea), conturi cu permisiuni diferentiate (Administrator vs. Standard), criptarea discului (BitLocker/FileVault), actualizari de securitate regulate.

Antivirus si malware

Tipuri de malware: virus, troian, ransomware, spyware, adware. Protectie: antivirus actualizat, update-uri SO, backup regulat, prudenta la descarcari.

Licente software

Comercial (platit, cod inchis), freeware (gratuit, cod inchis), open-source (gratuit, cod public, modificabil). Pirateria = ilegala + risc major de malware.

Exercitii practice

Exercitiul 1 (Nivel minim) - Clasificare software

Clasifica urmatoarele programe in sistem de operare, aplicatie sau utilitar: macOS Ventura, Microsoft Excel, Bitdefender Antivirus, Google Chrome, Linux Mint, WinRAR, ImageJ, Windows Defender. Justifica fiecare alegere intr-o propozitie.

Vezi rezolvarea

Clasificare si justificare:

  1. macOS Ventura - sistem de operare (gestioneaza hardware-ul unui Mac si ofera platforma pentru celelalte programe)
  2. Microsoft Excel - aplicatie (program pentru o sarcina specifica: calcul tabelar)
  3. Bitdefender Antivirus - utilitar (protejeaza si intretine sistemul, nu produce un rezultat pentru utilizator)
  4. Google Chrome - aplicatie (program pentru navigare web)
  5. Linux Mint - sistem de operare (gestioneaza hardware-ul, alternativa la Windows/macOS)
  6. WinRAR - utilitar (arhivare/dezarhivare de fisiere)
  7. ImageJ - aplicatie (sarcina specifica: procesare si analiza de imagini)
  8. Windows Defender - utilitar (antivirus integrat, intretinere/protectie)

Exercitiul 2 (Nivel standard) - Analiza configuratiei de securitate

Un coleg iti spune ca pe calculatorul sau: (1) lucreaza cu contul de Administrator in fiecare zi, (2) a dezactivat Windows Update ca sa nu mai primeasca notificari, (3) a instalat un program de vizualizare PDF de pe un site necunoscut, (4) nu are backup. Identifica cele 4 riscuri de securitate, explica fiecare si propune solutia corecta.

Vezi rezolvarea

Cele 4 riscuri si solutiile corecte:

  1. Cont de Administrator zilnic - risc: orice program, inclusiv un malware, ruleaza cu drepturi depline si poate modifica sistemul nestingherit. Solutie: foloseste un cont Standard pentru activitatea zilnica si treci pe Administrator doar cand instalezi ceva anume.
  2. Windows Update dezactivat - risc: raman active vulnerabilitati cunoscute, exact cele exploatate de malware. Solutie: reactiveaza actualizarile automate de securitate.
  3. Program PDF de pe site necunoscut - risc: poate fi un troian deghizat in aplicatie utila. Solutie: descarca doar de pe site-ul oficial al producatorului si scaneaza fisierul cu antivirusul inainte de instalare.
  4. Fara backup - risc: un ransomware sau o defectiune hardware duce la pierderea totala si ireversibila a datelor. Solutie: copii de siguranta regulate, pe un suport separat sau in cloud.

Exercitiul 3 (Nivel performanta) - Plan de instalare software pentru laboratorul de biologie

Esti ales responsabil IT al grupei pentru proiectul de ecologie. Trebuie sa instalati pe calculatoarele laboratorului: un program de analiza statistica a datelor, un program de procesare imagini microscopice si un program de gestiune surse bibliografice. Redacteaza un plan care include: (1) propuneri de programe cu licenta adecvata pentru mediul scolar (freeware sau open-source), (2) verificarea licentei inainte de instalare, (3) masuri de securitate la descarcare si instalare, (4) tipul de cont (Administrator sau Standard) cu care se realizeaza instalarea si de ce, (5) cum verificati ca instalarea nu a introdus malware.

Vezi rezolvarea

Schita de plan (structura, nu produsul gata facut):

  1. Pentru fiecare categorie (statistica, procesare imagini, bibliografie) alege programe freeware sau open-source (ex: instrumente gen R/GeoGebra pentru statistica, ImageJ pentru imagini, Mendeley pentru bibliografie, aparute in lectie) si justifica alegerea prin costul zero si licenta permisa in scoala.
  2. Verifica licenta INAINTE de instalare: de pe ce site oficial se descarca, ce tip de licenta are (nu presupune ca gratuit inseamna fara reguli).
  3. Masuri de securitate: descarcare doar din sursa oficiala, scanare antivirus a fisierului inainte de rulare.
  4. Tip de cont: instalarea cere cont Administrator (scrie in sistem), dar folosirea zilnica ramane pe cont Standard.
  5. Verificare post-instalare: scanare completa cu antivirusul si verificarea ca nu au aparut procese neasteptate.

Criterii de evaluare: licenta corecta pentru fiecare program, justificarea contului de instalare, mentionarea explicita a verificarii inainte si dupa instalare - lipsa unui pas scade punctajul.

Ce ai invatat astazi

  • Software = SO + aplicatii + utilitare; fiecare categorie are rol distinct
  • Sistemul de operare gestioneaza procesele, memoria, fisierele, dispozitivele si securitatea
  • Securizarea SO: firewall, conturi cu permisiuni diferentiate, criptare disc, actualizari regulate
  • Malware: virus, troian, ransomware, spyware — prevenire prin antivirus actualizat, update-uri, backup
  • Licente: comercial, freeware, open-source; pirateria = ilegala si risc de malware
