Componenta software: sisteme de operare si aplicatii

Progres lectie:
0%
🎯

Obiectivul lectiei

Vei intelege ce este software-ul, care este diferenta dintre software de sistem si software aplicativ, cum functioneaza un sistem de operare, cum organizezi fisierele si folderele pe calculator si cum alegi aplicatia potrivita pentru sarcinile tale din stiinte.

Dupa aceasta lectie vei putea:

  • Sa definesti software-ul si sa il distingi de hardware
  • Sa explici rolul sistemului de operare si sa dai exemple (Windows, Linux, macOS)
  • Sa descrii diferenta dintre software de sistem si software aplicativ
  • Sa organizezi fisiere si foldere respectand o structura logica
  • Sa identifici tipuri de fisiere dupa extensie si sa asociezi extensia cu aplicatia corecta
  • Sa enumeri aplicatii specifice domeniului stiintific (calcul tabelar, grafica, baze de date)
  • Sa aplici operatiile de baza cu fisiere: creare, copiere, mutare, stergere, redenumire

Incearca singur!

Provocare (profil Stiinte ale naturii):

Imaginati-va ca ai inregistrat timp de o luna masuratori ale temperaturii si umiditatii aerului in doua locuri diferite din orasul tau. Ai acum zeci de fisiere cu date. Fara o organizare clara, nu vei mai gasi nimic peste o saptamana. Scrie mai jos cum ai organiza aceste fisiere pe calculator: ce foldere ai crea si cum le-ai numi, ca sa gasesti orice masuratori in sub 10 secunde. Nu exista un raspuns unic corect — important e sa ai un sistem.

💡 Ai nevoie de un indiciu?

Gandeste ierarhic: mai intai dupa proiect, apoi dupa data sau tip de masuratori. De exemplu: Meteo_2024 > Temperatura > Loc1 si Meteo_2024 > Temperatura > Loc2. Foloseste date in denumiri (ex: 2024-03-15_temp_parc.csv) ca sistemul de operare sa le sorteze automat cronologic.

Exact asa lucreaza cercetatorii: o structura de foldere clara este primul instrument de stiinta — fara ea, cele mai bune date devin inutilizabile.

1

1. Ce este software-ul

Software-ul reprezinta totalitatea programelor, instructiunilor si datelor care controleaza si coordoneaza functionarea unui sistem de calcul. Spre deosebire de hardware (componentele fizice pe care le-ai studiat in Lectia 1), software-ul este nematerial — exista ca informatie stocata pe suporturi de memorie.
Analogie sigura — reteta si ustensile de laborator:

Ustensilele de laborator (eprubete, biurete, spectrofotometru) reprezinta hardware-ul: le poti atinge si vedea. Protocolul de experiment — succesiunea de pasi, temperaturi, cantitati — reprezinta software-ul: este o instructiune, nu un obiect. Fara ustensile nu poti lucra, dar fara protocol nu stii CE sa faci cu ele.

De ce conteaza in stiinte? Calculatorul hardware este identic pentru un fizician si pentru un editor video. Ceea ce le permite sa faca lucruri complet diferite este software-ul: programul de simulare moleculara, foaia de calcul cu date experimentale, aplicatia de grafica stiintifica. Software-ul transforma hardware-ul generic intr-un instrument specializat.
2

2. Software de sistem vs. software aplicativ

Software-ul se imparte in doua mari categorii dupa rolul sau:
Software de sistem

Gestioneaza resursele hardware si ofera un mediu in care pot rula celelalte programe. Include:
Sistemul de operare (SO) — Windows, Linux, macOS, Android, iOS. Controleaza procesorul, memoria, dispozitivele de stocare, ecranul, tastatura.
Drivere — programe mici care permit SO sa comunice cu dispozitive specifice (imprimanta, placa video, mouse).
Utilitare de sistem — programe de backup, defragmentare, antivirus, gestionarea actualizarilor.

Software aplicativ

Programe create pentru a rezolva sarcini specifice ale utilizatorului. Ruleaza DEASUPRA sistemului de operare si depind de el. Exemple:
Productivitate: Microsoft Word, LibreOffice Writer (documente), Excel/Calc (tabele), PowerPoint/Impress (prezentari).
Stiintific: MATLAB, R, Python cu biblioteci NumPy/Pandas (analiza date), GeoGebra (matematica), Stellarium (astronomie).
Comunicare: browser (Chrome, Firefox), client e-mail (Outlook, Thunderbird).
Multimedia: VLC (video), Audacity (audio), GIMP (imagini).

Relatie ierarhica: Hardware → Software de sistem (SO) → Software aplicativ → Utilizator. Fiecare nivel depinde de nivelul de sub el.
3

3. Sistemul de operare — roluri si exemple

Sistemul de operare (SO) este cel mai important software de sistem. El porneste primul cand aprinzi calculatorul si ruleaza tot timpul. Rolurile sale principale:
  1. Gestionarea procesului (CPU): aloca timp de procesor fiecarei aplicatii deschise, comutand rapid intre ele — de aceea poti asculta muzica si redacta un document simultan.
  2. Gestionarea memoriei (RAM): decide cat memorie primeste fiecare program; cand memoria se umple, foloseste temporar spatiu pe disc (memorie virtuala).
  3. Gestionarea fisierelor: organizeaza datele in sisteme de fisiere (NTFS, FAT32, ext4), permite crearea, citirea, scrierea si stergerea fisierelor.
  4. Gestionarea dispozitivelor: comunica cu tastatura, mouse-ul, imprimanta, camera web prin drivere.
  5. Interfata utilizator: grafica (GUI — ferestre, icoane, meniuri) sau text (CLI — linie de comanda).
  6. Securitate si drepturi: gestioneaza conturi de utilizator, parole, permisiuni de acces la fisiere.
Sisteme de operare majore

Windows (Microsoft) — cel mai raspandit pe PC-uri si laptopuri de uz general si in scoli; familiar, suporta aproape orice aplicatie.
macOS (Apple) — specific calculatoarelor Mac; popular in design si productie audio-video.
Linux (open-source, multe distributii: Ubuntu, Fedora, Debian) — preferat in cercetare, servere si medii stiintifice; gratuit, stabil, programabil; majoritatea supercomputerelor din lume ruleaza Linux.
Android / iOS — sisteme de operare pentru dispozitive mobile (telefoane, tablete).

Relevanta stiintifica — Linux in cercetare:

Cele mai puternice calculatoare stiintifice (clustere HPC folosite pentru simularea climei, analiza genomica, fizica particulelor) ruleaza Linux. Daca vei lucra intr-un laborator de cercetare, vei intalni cu siguranta comenzi Linux pentru a rula simulari sau a procesa seturi mari de date.

4

4. Fisiere si extensii — tipuri uzuale

Un fisier este o colectie de date stocata pe un suport de memorie sub un nume. Fiecare fisier are o extensie (sufixul dupa punct) care indica tipul sau si aplicatia asociata pentru deschidere.
Extensii frecvente si aplicatia asociata

Documente text: .docx (Word), .odt (LibreOffice Writer), .pdf (Adobe Reader, browser)
Calcul tabelar: .xlsx (Excel), .ods (LibreOffice Calc), .csv (orice editor text sau Excel — format universal pentru date stiintifice)
Prezentari: .pptx (PowerPoint), .odp (LibreOffice Impress)
Imagini: .jpg/.jpeg (foto comprimate), .png (grafica cu transparenta), .svg (vectorial scalabil)
Video: .mp4, .avi, .mkv
Programe/scripturi: .py (Python), .exe (executabil Windows), .sh (script Linux)
Date stiintifice: .csv, .json, .xml (formate text structurate, universale), .mat (MATLAB)
Arhive: .zip, .rar, .7z (mai multe fisiere comprimate intr-unul singur)

Fisiere cu extensii ascunse: Windows poate ascunde extensiile cunoscute. Este recomandat sa activezi afisarea lor (Folder Options → View → debifezi "Hide extensions for known file types") pentru a vedea exact cu ce tip de fisier lucrezi — esential in munca stiintifica, unde un .csv si un .xlsx arata similar ca pictograma dar se comporta diferit.
5

5. Operatii cu fisiere si foldere

Folderul (directorul) este un container logic care grupeaza fisiere si alte foldere. Structura ierarhica de foldere formeaza un arbore de directoare: radacina (C:\ pe Windows sau / pe Linux) contine foldere, care contin alte foldere si fisiere.
Operatii esentiale cu fisiere

Creare: clic-dreapta in folder → New → alegi tipul (folder, document, etc.) — sau Ctrl+N in multe aplicatii.
Redenumire: clic-dreapta pe fisier/folder → Rename (sau F2) → tastezi noul nume → Enter.
Copiere: Select → Ctrl+C → navighezi la destinatie → Ctrl+V. Fisierul ramane si in locul original.
Mutare: Select → Ctrl+X → navighezi la destinatie → Ctrl+V. Fisierul dispare din locul original.
Stergere: Select → Delete (sau tasta Del) → fisierul merge in Cos de reciclare; Shift+Delete = stergere permanenta, fara Cos.
Proprietati: clic-dreapta → Properties — arata dimensiunea, data crearii/modificarii, extensia, locatia.

Structura recomandata pentru proiecte stiintifice

O organizare clara a fisierelor este o competenta stiintifica esentiala. Exemplu pentru un proiect de biologie:

ProiectEcologie_2024/
  date_brute/          ← fisierele CSV originale, nemodificate
  date_prelucrate/    ← fisierele dupa curatare si calcule
  grafice/            ← grafice exportate (.png, .svg)
  rapoarte/           ← documentele Word/PDF cu concluzii
  README.txt          ← explicatii despre proiect si ce contine fiecare folder

Cai absolute vs. relative: O cale absoluta descrie locatia completa de la radacina (ex: C:\Utilizatori\Ana\ProiectEcologie_2024\date_brute\masuratori.csv). O cale relativa o descrie fata de folderul curent (ex: date_brute\masuratori.csv daca esti deja in ProiectEcologie_2024). Caile relative fac proiectele portabile — functioneaza pe orice calculator, indiferent de unde e salvat proiectul.
6

6. Aplicatii pentru lucrul stiintific

In stiinte, alegerea aplicatiei potrivite pentru fiecare sarcina afecteaza direct calitatea si eficienta muncii. Iata categoriile principale:
Calcul tabelar si analiza date — cel mai folosit in stiinte la liceu

Microsoft Excel / LibreOffice Calc: calcule, formule, grafice, tabele pivot. Esential pentru prelucrarea datelor experimentale: medii, deviatii standard, corelatii, reprezentari grafice X-Y.
Google Sheets: similar cu Excel, dar in browser, colaborativ in timp real — util pentru proiecte de grup.
Formatul universal de date: .csv — fisier text cu valori separate prin virgula, compatibil cu orice program de analiza.

Redactare si documentare

Microsoft Word / LibreOffice Writer: rapoarte de laborator, referate, lucrari. Invata sa folosesti Stiluri (Heading 1, Heading 2) in loc de formatare manuala — genereaza automat cuprins si structureaza documentul.
PDF: formatul standard de arhivare si distribuire a documentelor finalizate — aspect identic pe orice dispozitiv.

Prezentari

Microsoft PowerPoint / LibreOffice Impress / Google Slides: prezentarea rezultatelor experimentale, proiectelor stiintifice. Regula de baza: o idee principala per slide, graficele mari si clare, text minim.

Aplicatii specializate accesibile la liceu

GeoGebra (matematica, fizica) — grafice de functii, geometrie, calcul, statistica; gratuit online.
Stellarium (astronomie) — simulator de cer in timp real.
Avogadro (chimie) — editor de molecule 3D, calcule de geometrie moleculara.
Audacity (fizica sunetului) — analiza forme de unda, frecvente, spectru sonor.

7

7. Gestionarea stocarii si siguranta datelor

Pierderea datelor experimentale este una dintre cele mai costisitoare greseli in munca stiintifica. Cateva practici esentiale:
Cosul de reciclare si recuperarea fisierelor

Cand stergi un fisier cu tasta Delete, acesta nu dispare imediat — este mutat in Cosul de reciclare (Recycle Bin). Il poti restaura oricand pana cand golesti Cosul (Empty Recycle Bin) sau pana cand sistemul il elimina automat cand se umple spatiul alocat. Shift+Delete sterge permanent, ocolind Cosul — foloseste cu atentie.

Backup — regula 3-2-1

Datele importante trebuie sa existe in 3 copii, pe 2 suporturi diferite (ex: hard disk intern + stick USB), din care 1 la o locatie diferita (ex: cloud sau acasa). In practica stiintifica la liceu: copie pe calculator + copie pe stick/cloud (Google Drive, OneDrive). O singura copie inseamna risc total.

Denumirea corecta a fisierelor — conventii stiintifice

Evita spatii si caractere speciale in denumirile de fisiere (problemele apar la partajare si programare). Foloseste: litere, cifre, liniute (-) sau underscore (_). Include data in format AAAA-MM-ZZ la inceput ca fisierele sa se sorteze cronologic automat. Exemple bune: 2024-03-15_masuratori_temperatura_parc.csv, 2024-03-22_raport_biologie_grup3.docx.

Relevanta stiintifica: Pierderea datelor de laborator (accident, defect hardware, stergere accidentala) poate insemna luni de munca pierduta. Orice cercetator serios face backup automat. Google Drive si OneDrive ofera backup gratuit in cloud si pot fi setate sa se sincronizeze automat — cel mai simplu sistem de protectie.
8

8. Recapitulare — harta conceptuala

In aceasta lectie ai parcurs intregul nivel software al unui sistem de calcul, de la definitii fundamentale pana la practici zilnice de organizare si protectie a datelor. Iata sinteza:
Niveluri software — de la baza la utilizator

1. Software de sistem → Sistemul de operare (Windows / Linux / macOS) gestioneaza hardware-ul si ofera mediu de executie
2. Drivere → permit SO sa comunice cu dispozitivele specifice (imprimanta, placa video, mouse)
3. Software aplicativ → programe pentru sarcini specifice: productivitate, stiintific, comunicare, multimedia
4. Fisiere si extensii → tipul fisierului e dat de extensie; .csv = date universale; .docx/.xlsx/.pdf = suite de birou
5. Structura foldere → ierarhie logica; cale absoluta vs. relativa; structura recomandata pentru proiecte
6. Operatii cu fisiere → creare, redenumire (F2), copiere (Ctrl+C+V), mutare (Ctrl+X+V), stergere (Del / Shift+Del)
7. Backup si siguranta datelor → regula 3-2-1; Cos de reciclare vs. stergere permanenta; denumiri cu data ISO

Contextul stiintific — de ce conteaza tot ce ai invatat:

Un biolog care analizeaza ADN, un fizician care proceseaza date de la senzori, un chimist care calculeaza randamentul unor reactii — toti lucreaza cu fisiere, aplicatii si sisteme de operare in fiecare zi de laborator. Competenta software nu e "materie de calculator" — e infrastructura invizibila a stiintei moderne. Fara o organizare corecta a fisierelor si fara backup, cel mai bun experiment poate deveni imposibil de valorificat.

Exercitii practice

Exercitiul 1 (Nivel minim) — Clasificare software

Clasifica urmatoarele programe in software de sistem sau software aplicativ si justifica alegerea:
a) Ubuntu Linux (distributie open-source de sistem de operare)
b) Microsoft Excel (calcul tabelar)
c) Driver pentru imprimanta HP LaserJet
d) GeoGebra (matematica si grafica de functii)
e) Windows Defender (antivirus integrat in Windows)

Vezi rezolvarea

Clasificare software de sistem vs. aplicativ:

  1. a) Ubuntu Linux - software de sistem: este un sistem de operare, gestioneaza direct resursele hardware.
  2. b) Microsoft Excel - software aplicativ: ruleaza deasupra sistemului de operare pentru o sarcina specifica (calcul tabelar).
  3. c) Driver pentru imprimanta HP LaserJet - software de sistem: permite sistemului de operare sa comunice cu un dispozitiv hardware specific.
  4. d) GeoGebra - software aplicativ: rezolva o sarcina specifica utilizatorului (matematica si grafica de functii).
  5. e) Windows Defender - software de sistem: utilitar de sistem (antivirus) integrat in sistemul de operare, protejeaza resursele calculatorului.

Exercitiul 2 (Nivel standard) — Organizarea datelor unui proiect

Esti intr-un proiect de chimie in care ai masurat pH-ul a 5 solutii in 3 zile diferite. Ai produs: fisiere CSV cu datele brute (15 fisiere), grafice PNG ale variatiei pH-ului, un raport Word cu concluziile si o prezentare PowerPoint pentru clasa.
a) Propune o structura de foldere completa pentru acest proiect.
b) Alege doua denumiri de fisiere concrete, respectand conventia cu data ISO si fara spatii.
c) Unde ai face backup si de ce ai alege acel loc?

Vezi rezolvarea

a) Structura de foldere pentru proiect:

  1. Proiect_pH/Date_brute/ - cele 15 fisiere CSV cu masuratori
  2. Proiect_pH/Grafice/ - graficele PNG ale variatiei pH-ului
  3. Proiect_pH/Raport/ - raportul Word cu concluziile
  4. Proiect_pH/Prezentare/ - prezentarea PowerPoint

b) Doua denumiri corecte (data ISO, fara spatii): ph_solutie1_2026-03-12.csv si grafic_ph_variatie_2026-03-14.png.

c) Backup: o copie pe cloud (Google Drive sau OneDrive) si o copie pe un stick USB separat de calculator - respecta regula 3-2-1 din lectie (3 copii, 2 suporturi, 1 in alta locatie) si protejeaza datele daca se defecteaza discul sau se pierde calculatorul.

Exercitiul 3 (Nivel performanta) — Alegerea instrumentelor software

Echipa ta de biologie trebuie sa analizeze datele de crestere a 3 plante masurate zilnic timp de 30 de zile (temperatura, inaltime, numar frunze), sa creeze grafice comparative si sa redacteze un raport care va fi prezentat la un concurs national.
a) Ce aplicatii ai folosi pentru fiecare etapa (stocare date brute, analiza si grafice, redactare raport, prezentare)? Justifica alegerea fiecareia.
b) Ce format de fisier ai folosi pentru a partaja datele cu profesorul indrumator care foloseste Linux si nu are Excel instalat?
c) Descrie in 4 pasi concret CUM ai exporta un grafic din Excel in format PNG pentru a-l insera in raportul Word, fara a pierde calitatea.

Vezi rezolvarea

Schita de rezolvare (structura + criterii, nu raspunsul complet):

  1. a) Aplicatii pe etape: stocare date brute: fisiere .csv (universal, usor de importat oriunde); analiza si grafice: Excel/LibreOffice Calc sau Google Sheets (formule, medii, grafice X-Y); redactare raport: Word/LibreOffice Writer cu Stiluri pentru cuprins automat; prezentare: PowerPoint/Impress. Justificarea trebuie sa lege fiecare alegere de o functie concreta predata in lectie.
  2. b) Format pentru profesorul cu Linux, fara Excel: .csv - text simplu, citit de orice program, inclusiv LibreOffice Calc de pe Linux.
  3. c) Export grafic din Excel in PNG, in 4 pasi: 1) click pe grafic pentru a-l selecta; 2) clic-dreapta pe grafic; 3) alege 'Save as Picture' si formatul PNG; 4) salveaza la rezolutia originala (nu prin captura de ecran, care pierde calitate).

Criterii: justificare tehnica corecta per aplicatie, alegerea formatului universal la punctul b, pasii de export in ordine si executabili, fara ambiguitati.

Ce ai invatat astazi

  • Software = totalitatea programelor si instructiunilor; nematerial, spre deosebire de hardware
  • Software de sistem (SO, drivere, utilitare) vs. software aplicativ (productivitate, stiintific, multimedia)
  • Sisteme de operare majore: Windows (scoli, uz general), Linux (cercetare, servere), macOS, Android/iOS
  • Rolurile SO: gestionare CPU, memorie, fisiere, dispozitive, interfata utilizator, securitate
  • Extensii de fisiere: .csv (date universale), .xlsx (Excel), .docx (Word), .pdf (portabil), .py (Python)
  • Operatii cu fisiere: creare, redenumire (F2), copiere (Ctrl+C+V), mutare (Ctrl+X+V), stergere (Del / Shift+Del)
  • Cos de reciclare = stergere reversibila; Shift+Delete = stergere permanenta
  • Backup 3-2-1: 3 copii, 2 suporturi, 1 locatie externa; denumiri cu data ISO fara spatii

Vrei mai mult?

Provocare: Deschide File Explorer, gaseste un folder cu fisiere de mai multe tipuri (poze, documente, foi de calcul). In caseta de cautare din dreapta sus scrie *.csv, apoi *.jpg, si observa cum extensia filtreaza instant rezultatele. Apoi creeaza un folder nou numit dupa conventia invatata (data ISO, fara spatii, ex: 2026-09-05_experiment) si muta in el 3 fisiere legate de acelasi subiect.

De ce? Sistemul de operare are nevoie de un driver diferit pentru aproape fiecare model de imprimanta sau placa video, in loc sa stie din start cum sa comunice cu orice dispozitiv. De ce nu exista un singur driver universal? Ce s-ar intampla daca un producator de hardware nou nu ar scrie niciodata un driver pentru Windows?

In lumea reala: Regula 3-2-1 de backup nu e doar teorie de ora: e standardul folosit de biblioteci nationale, spitale si laboratoare de cercetare, unde pierderea unui singur fisier poate insemna pierderea ireversibila a unui rezultat masurat luni de zile. Multe universitati si laboratoare aleg Linux tocmai pentru ca sistemul de operare e deschis si poate fi adaptat pentru echipamente stiintifice speciale, precum telescoape sau secventiatoare ADN.
