Sistemul de operare Windows si gestionarea fisierelor

Progres lectie:
0%
🎯

Obiectivul lectiei

Vei intelege ce este sistemul de operare Windows, cum interactionezi cu el prin interfata grafica si cum iti organizezi fisierele si folderele pentru a lucra eficient ca viitor cadru didactic — de la pregatirea lectiei pana la arhivarea documentelor scolare.

Dupa aceasta lectie vei putea:

  • Sa explici ce este un sistem de calcul si sa distingi hardware-ul de software la nivel de utilizator
  • Sa descrii rolul sistemului de operare (Windows) si sa identifici elementele interfetei grafice (GUI)
  • Sa navighezi in Windows Explorer si sa folosesti meniul Start, bara de sarcini si Desktop-ul
  • Sa organizezi fisiere si foldere intr-o structura logica pentru activitatea scolara
  • Sa aplici operatii de baza cu fisiere: creare, copiere, mutare, redenumire, stergere

Incearca singur!

Provocare:

Esti in prima zi de practica pedagogica. Trebuie sa pregatesti o fisa de lucru pentru clasa a 3-a. Deschizi calculatorul, se incarca Windows-ul, dai dublu-clic pe Word, scrii fisa si o salvezi in folderul Practica\Cls3A\. Gandeste-te: ce a facut Windows in toata aceasta secventa? Ce ai interactionat (cu ochii sau cu mouse-ul) pe ecran?

💡 Ai nevoie de un indiciu?

Urmareste secventa: pornire (Windows se incarca), navigare (Desktop, dublu-clic, fereastra), lucru (Word deschis, tastatura), salvare (Ctrl+S, alegerea folderului).

Elementele vizuale cu care interactionezi (pictograme, ferestre, bara de jos, butoanele din Word) formeaza interfata grafica (GUI). Windows le gestioneaza pe toate — e sistemul de operare.

1

1. Ce este un sistem de calcul — privire de ansamblu

Un sistem de calcul (calculator) este format din doua parti inseparabile: hardware (componentele fizice — tot ce poti atinge) si software (programele — instructiunile care spun hardware-ului ce sa faca). Ca educator digital, nu trebuie sa cunosti interiorul tehnic al calculatorului, ci sa stii sa il folosesti eficient.
Hardware — ce vezi si atingi

Elementele fizice cu care interactionezi zilnic: monitorul (ecranul), tastatura, mouse-ul, imprimanta, videoproiectorul din sala de clasa, tableta interactiva. In interiorul carcasei se afla componente care proceseaza si stocheaza datele — nu trebuie sa le cunosti detaliat, dar e bine sa stii ca ele exista si ca viteza calculatorului depinde de ele.

Software — ce ruleaza pe hardware

Programele care fac hardware-ul util. Cel mai important este sistemul de operare (Windows, macOS) — porneste primul si gestioneaza tot. Peste el rulezi aplicatiile: Word, PowerPoint, browser, Kahoot. Fara software, hardware-ul este inert — la fel cum un videoproiector fara semnal afiseaza un ecran negru.

Analogie pentru sala de clasa

Gandul-te la calculator ca la sala de clasa: hardware = mobilierul, tabla, videoproiectorul (obiecte fizice). Software = programa, planul de lectie, metodele de predare (instructiuni). Fara mobilier nu poti tine ora; fara programa, mobiliarul nu serveste niciunui scop. La fel, hardware si software sunt complementare.

2

2. Sistemul de operare si aplicatiile pentru educator

Sistemul de operare (SO) este programul care porneste primul si gestioneaza tot: ecranul, tastatura, fisierele, aplicatiile. In scolile romanesti se foloseste cel mai des Windows (10 sau 11). Peste el rulezi aplicatii — programele concrete cu care lucrezi.
Aplicatii esentiale pentru practica pedagogica

Ca viitor cadru didactic, vei folosi zilnic:

  • Microsoft Word / Google Docs — fise de lucru, planuri de lectie, teste scrise
  • Microsoft PowerPoint / Canva — prezentari vizuale pentru ore
  • Microsoft Excel / Google Sheets — situatii de note, cataloage, statistici
  • Google Forms / Microsoft Forms — evaluari si chestionare online
  • Kahoot / Wordwall — activitati interactive si gamificate cu elevii
  • Browser web (Chrome, Edge) — resurse educationale, platforme scolare

Windows gestioneaza toate aceste aplicatii: le porneste, le aloca memorie, le salveaza fisierele si le afiseaza pe ecran — totul printr-o interfata grafica pe care o explorezi in atomul urmator.

3

3. Sistemul de operare si interfata grafica

Sistemul de operare (SO) este programul fundamental care porneste primul la deschiderea calculatorului, gestioneaza toate resursele (procesor, RAM, stocare, periferice) si ofera platforma pe care ruleaza aplicatiile. Fara SO, calculatorul nu poate fi folosit.
Functiile principale ale sistemului de operare
  • Gestionarea proceselor — permite rularea simultana a mai multor aplicatii (Word + browser + Kahoot in acelasi timp)
  • Gestionarea memoriei — aloca RAM fiecarei aplicatii si impiedica conflictele dintre programe
  • Gestionarea fisierelor — organizeaza datele in fisiere si foldere pe disc
  • Gestionarea dispozitivelor — comunica cu imprimanta, proiectorul, tableta interactiva prin drivere
  • Interfata cu utilizatorul — ofera mediul vizual sau text prin care dai comenzi
Interfata grafica (GUI) — ce vezi pe ecran

GUI (Graphical User Interface) inseamna ca interactionezi cu SO prin elemente vizuale: ferestre, pictograme (iconite), meniuri, butoane si bara de sarcini. Nu trebuie sa memorezi comenzi text.

In Windows: Desktop cu pictograme → dublu-clic deschide aplicatia; bara de sarcini (jos) arata aplicatiile deschise; meniul Start (butonul Windows, stanga jos) listeaza toate programele instalate; File Explorer (pictograma dosar galben) gestioneaza fisierele.

Sisteme de operare intalnite in scoli
  • Windows 10 / Windows 11 — cel mai raspandit in scolile romanesti; laboratorele de informatica si calculatoarele secretariate folosesc Windows
  • macOS (Apple) — folosit in unele licee cu dotare Apple
  • Linux (Ubuntu, Fedora) — alternativa gratuita, intalnita in unele laboratoare
  • Android / iOS — pe tabletele folosite la activitati cu elevii
4

4. Organizarea fisierelor si folderelor

Un fisier este o colectie de date stocata pe disc cu un nume si o extensie (ex: Plan_lectie.docx, Catalog_cls5A.xlsx). Un folder (director) este un container care grupeaza fisiere si alte foldere. Ierarhia de foldere formeaza o structura arborescenta.
Structura recomandata pentru un educator

O organizare logica economiseste timp si evita pierderea documentelor:

📁 Documente_Scoala\
  📁 Planuri_lectii\
      📁 Semestrul_1\
      📁 Semestrul_2\
  📁 Fise_de_lucru\
      📁 Clasa_5A\
      📁 Clasa_5B\
  📁 Evaluari\
      📁 Teze\
      📁 Teste_curente\
  📁 Comunicare_parinti\
Extensii de fisiere esentiale

Extensia (sufixul dupa punct) indica tipul fisierului si ce program il deschide:

  • .docx — document Word (plan de lectie, fisa, test scris)
  • .xlsx — foaie de calcul Excel (catalog, statistici note)
  • .pptx — prezentare PowerPoint (suport vizual pentru ora)
  • .pdf — document portabil, recomandat pentru trimitere si tiparire (nu se modifica accidental)
  • .jpg / .png — imagini (fotografii activitati, diagrame, ilustratii)
  • .mp4 — video (materiale didactice, inregistrari activitati)
Operatii de baza cu fisiere in Windows File Explorer

Creare folder: clic-dreapta in zona goala → New → Folder → tastezi numele.
Redenumire: clic-dreapta pe fisier/folder → Rename (sau selectezi si apesi F2) → tastezi numele nou.
Copiere: selectezi → Ctrl+C → mergi in destinatie → Ctrl+V. Originalul ramane la locul lui.
Mutare: selectezi → Ctrl+X → mergi in destinatie → Ctrl+V. Originalul dispare din locul vechi.
Stergere: selectezi → tasta Delete → fisierul merge in Cos de gunoi (Recycle Bin); pentru stergere definitiva: Shift+Delete.
Recuperare: daca ai sters accidental, deschizi Recycle Bin de pe Desktop → clic-dreapta pe fisier → Restore.

5

5. Gestionarea fisierelor — operatii de lucru zilnic

Dincolo de creare si copiere, un educator digital lucreaza zilnic cu cautare, stocare externa si backup. Iata cele mai utile tehnici in Windows:
Cautarea rapida a unui fisier

In Windows 11: apasa tasta Win (logo Windows) → incepe sa tastezi numele fisierului → Windows il gaseste automat in cateva secunde. Alternativ: in File Explorer, bara de cautare din dreapta sus — cauta in folderul curent si subfolderele lui.
Sfat: foloseste conventii de denumire clare — Fisa_Lectura_cls4A_oct2025.docx e mult mai usor de gasit decat Document1.docx.

Stocare externa si cloud

Stick USB — portabil, capacitate 8–128 GB; util pentru transfer de fisiere intre calculator acasa si calculator la scoala. Formatat de obicei in FAT32 (compatibil universal) sau exFAT (suporta fisiere mai mari de 4 GB, potrivit pentru videoclipuri didactice).
Google Drive / OneDrive — stocare in cloud (pe internet); fisierele sunt accesibile de pe orice calculator sau telefon; permiti colaborarea cu colegii pe acelasi document in timp real.

Backup — copierea de siguranta

Un educator care pierde dosarul cu planurile de lectie chiar inainte de inspectie intelege pe viu valoarea backup-ului. Regula 3-2-1: pastreaza 3 copii ale datelor importante, pe 2 suporturi diferite (ex: calculator + cloud), cu 1 copie intr-o locatie diferita (acasa si la scoala).
In practica simpla: salveaza documentele importante si pe Google Drive sau trimite-ti-le pe e-mail — astfel ai mereu o copie accesibila.

Proprietatile unui fisier

Clic-dreapta pe fisier → Properties (Proprietati): afla marimea (ex: 245 KB pentru o fisa de lucru, 5 MB pentru o prezentare cu imagini), data crearii, data ultimei modificari, tipul (extensia) si locatia completa (calea pe disc, ex: C:\Users\Profesor\Documents\Fise_de_lucru\Clasa_5A\).

6

6. Recapitulare — Windows si fisierele din perspectiva unui educator

Privit din perspectiva unui viitor cadru didactic, sistemul de calcul este instrumentul prin care pregatesti lectii, comunici cu elevii si parintii, evaluezi si stochezi documente oficiale. Competenta digitala de baza nu inseamna sa cunosti tehnica interna, ci sa lucrezi eficient cu Windows si sa iti organizezi informatia.
Harta rapida a conceptelor invatate

Sistem de calcul: hardware (componente fizice — monitor, tastatura, mouse, periferice) + software (programe).
Sistemul de operare Windows: gestioneaza tot — aplicatii, fisiere, periferice; se incarca primul la pornire.
Interfata grafica (GUI): Desktop, pictograme, ferestre, bara de sarcini, meniu Start, File Explorer.
Aplicatii pentru educator: Word, Excel, PowerPoint, Google Workspace, Canva, Kahoot, browser.
Fisiere si foldere: structura ierarhica; extensii (.docx .xlsx .pdf .jpg .mp4); operatii (creare, copiere Ctrl+C, mutare Ctrl+X, stergere Delete, recuperare din Recycle Bin).
Stocare: locala (disc), externa (stick USB), cloud (Google Drive / OneDrive) + regula backup 3-2-1.

Sfat pentru practica pedagogica

Creeaza din prima zi de practica un folder structurat cu subfolderele: Planuri_lectii, Fise_lucru, Evaluari, Comunicare_parinti. Salveaza fisierele cu nume descriptive care includ clasa, tema si data (ex: Plan_Matematica_Cls3_Fractii_2026-09-15.docx). Sincronizeaza cu Google Drive — vei putea accesa totul de pe orice dispozitiv si nu vei pierde munca la o pana de curent.

Exercitii practice

Exercitiul 1 (Nivel minim) — Hardware, software si interfata grafica

Ai pe masa: un monitor, o tastatura, un mouse, o imprimanta, aplicatia Microsoft Word, sistemul de operare Windows 11 si un stick USB. Clasifica fiecare element in: hardware sau software. Apoi descrie trei elemente ale interfetei grafice (GUI) pe care le gasesti pe ecranul unui calculator cu Windows: ce sunt, unde se afla si cum le folosesti.

Vezi rezolvarea

Clasificare hardware/software:

  1. Monitor - hardware
  2. Tastatura - hardware
  3. Mouse - hardware
  4. Imprimanta - hardware
  5. Microsoft Word - software (aplicatie)
  6. Windows 11 - software (sistem de operare)
  7. Stick USB - hardware

Trei elemente GUI:

  1. Desktop cu pictograme - ecranul principal cu iconite; dublu-clic pe o pictograma deschide aplicatia sau fisierul.
  2. Bara de sarcini - se afla jos, pe toata latimea ecranului; arata aplicatiile deschise, ceasul si iconitele de sistem; dai clic pe o aplicatie de acolo ca sa comuti intre ferestre.
  3. Meniul Start - butonul Windows din stanga jos; clic pe el listeaza toate programele instalate, de unde le poti porni.

Exercitiul 2 (Nivel standard) — Structura de foldere pentru practica pedagogica

Esti in practica pedagogica la o scoala. Trebuie sa creezi pe calculator o structura de foldere pentru intregul semestru. Ai de gestionat: planuri de lectii pentru doua clase (cls. 3A si 4B), fise de lucru, teste si fotografii de la activitati. Deseneaza (pe hartie sau descrie in text) structura completa de foldere, respectand regulile de denumire corecta. Explica de ce ai ales aceasta organizare.

Vezi rezolvarea

Structura de foldere (Documente_Scoala este folderul principal):

  • Documente_Scoala
    • Planuri_lectii (Clasa_3A, Clasa_4B)
    • Fise_de_lucru (Clasa_3A, Clasa_4B)
    • Evaluari (Teste_curente)
    • Fotografii_activitati

Nume de fisier, dupa conventia din lectie (clasa + tema + data): Plan_Matematica_Cls3A_Fractii_2026-09-15.docx, Fisa_Lucru_Cls4B_oct2025.docx.

De ce aceasta organizare: separarea pe tip de document (planuri, fise, evaluari, fotografii) si apoi pe clasa face fisierele usor de gasit rapid cu cautarea Windows (tasta Win + nume), evita amestecarea materialelor celor doua clase si respecta regula de denumire clara aratata in lectie (nume descriptiv, nu "Document1.docx").

Exercitiul 3 (Nivel performanta) — Scenariu de recuperare si backup

Colega ta de practica iti spune: "Am sters accidental toate fisierele cu planurile de lectie! Nu mai am nimic!" Descrie pas cu pas ce ii recomanzi sa faca: (a) recuperarea din Recycle Bin, (b) verificarea daca exista o copie in cloud (Google Drive / OneDrive), (c) ce masuri de backup ii recomanzi sa adopte DE ACUM INAINTE pentru a evita aceasta situatie. Justifica fiecare recomandare.

Vezi rezolvarea

Schita de rezolvare (nu solutie completa - elevul detaliaza):

  1. Recycle Bin: deschide Cos de gunoi de pe Desktop, cauta fisierele sterse, clic-dreapta, apoi Restore. Functioneaza doar daca nu au fost sterse definitiv (Shift+Delete) si Cosul nu a fost golit.
  2. Copie in cloud: verifica in Google Drive / OneDrive daca fisierele au fost sincronizate anterior; daca da, le descarca de acolo.
  3. Masuri de backup de ACUM inainte: aplica regula 3-2-1 din lectie (3 copii, pe 2 suporturi diferite, cu 1 copie intr-o locatie diferita) - de exemplu: calculator + stick USB + Google Drive.

Capcane de evitat: confuzia intre stergere (Delete, merge in Recycle Bin) si stergere definitiva (Shift+Delete, ireversibila); presupunerea gresita ca orice fisier are automat o copie in cloud daca nu a fost activata sincronizarea.

Criterii de evaluare: raspunsul acopera corect toate cele trei subpuncte (a, b, c); foloseste corect notiunile din lectie (Recycle Bin, cloud, regula 3-2-1); justifica fiecare recomandare cu un motiv concret, nu doar o enumerare.

Ce ai invatat astazi

  • Sistem de calcul = hardware (componente fizice: monitor, tastatura, mouse, periferice) + software (programe)
  • Sistemul de operare Windows porneste primul si gestioneaza tot: aplicatii, fisiere, periferice
  • Interfata grafica (GUI): Desktop, pictograme, ferestre, bara de sarcini (jos), meniu Start, File Explorer
  • Aplicatii pentru educator: Word, Excel, PowerPoint, Google Workspace, Canva, Kahoot, browser
  • Fisiere si foldere: structura ierarhica, extensii (.docx .xlsx .pdf .jpg .mp4), operatii (Ctrl+C copiere, Ctrl+X mutare, Ctrl+V lipire, Delete stergere, Recycle Bin recuperare)
  • Stocare: locala (disc intern), externa (stick USB), cloud (Google Drive, OneDrive)
  • Backup regula 3-2-1: 3 copii, 2 suporturi, 1 locatie externa

Vrei mai mult?

Provocare: Deschide File Explorer pe calculatorul tau si activeaza afisarea extensiilor de fisiere (tab View -> Show -> bifeaza File name extensions; in Windows 11 e in ... -> Options -> tab View). Creeaza pe Desktop un folder Test_Extensii cu un fisier text nou (click-dreapta -> New -> Text Document). Redenumeste-l schimband extensia din .txt in .pdf si observa avertismentul Windows si ce icoana primeste fisierul dupa schimbare.

De ce? Windows ascunde implicit extensiile fisierelor cunoscute, desi lectia arata cat de importante sunt ele pentru a identifica tipul unui fisier. De ce crezi ca sistemul de operare face asta, si ce risc apare cand cineva primeste un fisier numit, de exemplu, Poza_vacanta.jpg.exe?

Deschidere: Redenumirea extensiei nu schimba continutul fisierului, doar eticheta lui — de aceea programele malitioase se ascund uneori sub o dubla extensie de tipul Factura.pdf.exe, ca sa para un document, cand de fapt sunt un program executabil. Administratorii IT dintr-o scoala activeaza mereu afisarea extensiilor pe calculatoarele elevilor, tocmai ca sa reduca acest risc.
