Sistemul de calcul si gestionarea fisierelor

Progres lectie:
0%
🎯

Obiectivul lectiei

Prima sarcina a probei practice de competente digitale (proba D) se da pe calculator, nu pe hartie: creezi o structura de foldere, pui fisierele exact unde ti se cere, le redenumesti si le arhivezi. Aceasta lectie iti reface, in ordine de lucru, tot ce ai nevoie: componentele calculatorului, rolul sistemului de operare, fisierele si caile lor, operatiile din File Explorer, arhivarea ZIP si setarile de sistem cerute la proba.

Dupa aceasta lectie vei putea:

  • Sa numesti componentele hardware ale unui sistem de calcul si sa spui ce face fiecare (procesor, memorie RAM, HDD/SSD, periferice)
  • Sa explici rolul sistemului de operare si sa te misti sigur pe desktopul Windows si in File Explorer
  • Sa construiesti o structura de foldere exact dupa o cerinta data si sa scrii calea completa a unui fisier
  • Sa executi corect operatiile cerute la proba D: copiere, mutare, redenumire, stergere, selectie multipla
  • Sa creezi si sa dezarhivezi o arhiva ZIP, sa cauti un fisier si sa ii citesti proprietatile
  • Sa reglezi setarile de baza ale sistemului (data si ora, rezolutia ecranului, scoaterea in siguranta a stickului USB)

Pornire de la ce stii deja!

Provocare (2 minute):

Esti la practica pedagogica si primesti cerinta: „Creeaza pe Desktop folderul PORTOFOLIU_PRACTICA, cu subfolderele Planuri_de_lectie si Fise_de_lucru. Copiaza fisierul model_plan.docx in ambele si redenumeste copia din Fise_de_lucru in model_fisa.docx." Scrie mai jos ordinea exacta a pasilor, fara sa atingi inca tastatura.

💡 Ai nevoie de un indiciu?

Intreaba-te ce nu poate exista inainte de altceva: nu poti copia un fisier intr-un folder care nu a fost inca creat. Deci intai folderul parinte, apoi subfolderele, abia apoi operatiile cu fisiere (copiere, redenumire).

Este exact ordinea in care iti aranjezi si portofoliul pe hartie: intai biblioraftul si despartitoarele, apoi fisele in ele.

1

1. Componentele sistemului de calcul

Porneste de la ce vezi in laborator

Pe masa din laboratorul scolii ai: o carcasa, un monitor, o tastatura, un mouse si o boxa. In carcasa se afla piesele care fac de fapt treaba: procesorul, memoria RAM si discul. Cand deschizi o prezentare, discul o da mai departe in RAM, procesorul o prelucreaza, iar monitorul ti-o arata. Cinci obiecte, un singur lant.

Un sistem de calcul este ansamblul de componente hardware (piesele fizice) si software (programele) care lucreaza impreuna pentru a prelucra informatia. Hardware-ul este ceea ce poti atinge; software-ul este ceea ce poti doar rula.
Procesorul (CPU — unitatea centrala de prelucrare)

Executa instructiunile programelor: calcule, comparatii, decizii. Viteza se masoara in GHz (gigahertzi). Un procesor actual are mai multe nuclee (cores) care lucreaza in paralel — de exemplu un Intel Core i5 sau un AMD Ryzen 5. Mai multe nuclee inseamna ca poti tine deschise simultan Word, browserul si aplicatia de prezentari, fara ca ele sa se astepte una pe alta.

Memoria RAM — masa de lucru

Pastreaza temporar datele si programele deschise chiar acum. Este volatila: la oprirea calculatorului continutul se pierde complet. Capacitatea se masoara in GB (valori obisnuite azi: 8 GB sau 16 GB). De aici vine regula de aur la proba practica: salveaza des (Ctrl+S), pentru ca ce e doar in RAM nu exista inca pe disc.

Stocarea — HDD si SSD

HDD (Hard Disk Drive) este un disc magnetic care se invarte: capacitate mare (uzual 500 GB – 4 TB), pret mic, viteza mai mica. SSD (Solid State Drive) este memorie de tip flash, fara piese in miscare: mult mai rapid, mai rezistent la lovituri, capacitati uzuale 256 GB – 1 TB. Ambele sunt nevolatile: pastreaza datele si dupa oprirea calculatorului.

Perifericele — ce intra si ce iese

De intrare: tastatura, mouse, scanner, microfon, camera web. De iesire: monitor, videoproiector, imprimanta, boxe. Si intrare, si iesire: ecran tactil, stick USB, placa de retea. Rezolutia monitorului (de exemplu 1920x1080 pixeli, numita Full HD) arata din cati pixeli e format ecranul si cat de clara este imaginea.

O analogie din sala de clasa

Procesorul = invatatorul care conduce activitatea si ia deciziile; memoria RAM = catedra pe care stau fisele zilei de azi (seara se strange, masa ramane goala); HDD/SSD = dulapul cu portofoliile tuturor claselor, care ramane plin de la un an la altul; perifericele = tabla, videoproiectorul si imprimanta, adica felul in care informatia intra si iese din sala.

2. Sistemul de operare si desktopul Windows

Ce se intampla in primele secunde

Apesi butonul de pornire. Nu se deschide Word, nu se deschide browserul — apare intai desktopul: fundalul, pictogramele, bara de jos cu butonul Start si ceasul. Abia dupa ce acest strat este pornit poti da dublu clic pe o aplicatie. Stratul acela se numeste sistem de operare.

Sistemul de operare (SO) este programul de baza incarcat la pornirea calculatorului. El administreaza toate resursele hardware si ofera mediul in care pot rula aplicatiile. Fara sistem de operare, nicio aplicatie nu porneste.
Ce face concret sistemul de operare
  • Gestioneaza programele — decide care program primeste procesorul si cand
  • Gestioneaza memoria — da fiecarei aplicatii bucata ei de RAM si le tine separate
  • Gestioneaza fisierele — organizeaza datele in foldere si fisiere pe disc
  • Gestioneaza dispozitivele — vorbeste cu tastatura, imprimanta sau stickul USB prin drivere
  • Asigura securitatea — conturi de utilizator, drepturi de acces, parola de logare
Sisteme de operare pe care le vei intalni

Windows 10 / Windows 11 — cel mai raspandit pe calculatoarele din scoli si din laboratoarele de examen; la proba practica D se lucreaza de regula pe Windows. Linux (Ubuntu, Debian) — frecvent pe servere. macOS — pe calculatoarele Apple. Android si iOS — pe telefoane si tablete, inclusiv pe tabletele folosite la clasa.

Elementele desktopului de care ai nevoie la proba
  • Desktop — suprafata de lucru; multe cerinte incep cu „creati pe Desktop folderul..."
  • Bara de activitati (taskbar) — banda de jos, cu butonul Start, aplicatiile deschise si ceasul
  • File Explorer — aplicatia cu care umbli prin foldere; se deschide cu Windows+E
  • Cosul de reciclare (Recycle Bin) — unde ajung fisierele sterse cu tasta Delete
Aplicatie sau sistem de operare?

Word, Excel, browserul si antivirusul sunt aplicatii: programe instalate peste sistemul de operare, care ii cer servicii (deschide-mi fisierul acesta, tipareste pagina aceasta). Sistemul de operare este infrastructura; aplicatia este cea care o foloseste. Daca inchizi Word, Windows merge mai departe; daca se opreste Windows, se opreste tot.

3. Fisiere, foldere, cai si extensii

Un portofoliu de practica, asa cum arata pe disc
C:\
  Users\
    Elev\
      Documents\
        PORTOFOLIU_PRACTICA\
          Planuri_de_lectie\
            plan_comunicare_cls1.docx
          Fise_de_lucru\
            fisa_adunare_cls2.docx
          Fotografii\
            serbare_iarna.jpg

Fiecare nume cu \ dupa el este un folder; ultimul nume din fiecare ramura, cel cu punct si extensie, este un fisier.

Un fisier este o colectie de date salvata pe disc sub un nume. Un folder (director) este un recipient care contine fisiere si alte foldere. Sistemul de operare le organizeaza intr-o ierarhie care porneste de la o radacina: pe Windows, litera unitatii de disc (C:\, D:\, iar stickul USB primeste de obicei E:\ sau F:\).
Calea absoluta si calea relativa

O cale absoluta spune unde se afla fisierul pornind de la radacina: C:\Users\Elev\Documents\PORTOFOLIU_PRACTICA\Fise_de_lucru\fisa_adunare_cls2.docx. O cale relativa se socoteste fata de folderul in care esti deja: daca esti in PORTOFOLIU_PRACTICA, calea relativa a aceluiasi fisier este Fise_de_lucru\fisa_adunare_cls2.docx. La proba, calea completa se citeste in bara de adrese din File Explorer.

Numele fisierului: partea dinainte si partea de dupa punct

La fisa_adunare_cls2.docx, partea fisa_adunare_cls2 este numele (il alegi tu), iar .docx este extensia — ea spune ce tip de fisier este si cu ce aplicatie il deschide Windows. Ca sa vezi extensiile in File Explorer: View → Show → File name extensions (Windows 11) sau fila View → casuta File name extensions (Windows 10). Fa asta la inceputul probei: altfel redenumesti pe orb.

Extensii care apar la proba D
  • .docx — document Word (plan de lectie, referat, fisa de lucru)
  • .xlsx — foaie de calcul Excel (situatia notelor, prezenta)
  • .pptx — prezentare PowerPoint (materialul proiectat la lectie)
  • .pdf — document cu aspect fix, bun de tiparit sau de trimis
  • .jpg — imagine comprimata cu pierderi; fisier mic, potrivit pentru fotografii
  • .png — imagine comprimata fara pierderi; buna pentru desene si capturi de ecran
  • .txt — text simplu, fara nicio formatare
  • .zip — arhiva comprimata care contine mai multe fisiere
Reguli de denumire in Windows
  • Caractere interzise in nume: \ / : * ? " < > |
  • Windows nu face deosebire intre litere mari si mici: Fisa.docx si fisa.docx sunt acelasi nume in acelasi folder
  • Doua fisiere cu acelasi nume si aceeasi extensie nu pot sta in acelasi folder
  • Foloseste liniuta de subliniere in loc de spatiu si scrie datele ca 2027-03-12, ca fisierele sa se sorteze singure in ordine cronologica

4. Operatii cu fisiere si foldere in File Explorer

Aceeasi treaba, in doua feluri

Vrei sa duci fisa_adunare_cls2.docx din Fise_de_lucru in Planuri_de_lectie. Poti da clic dreapta pe fisier, Cut, apoi clic dreapta in folderul destinatie, Paste. Sau poti apasa Ctrl+X si apoi Ctrl+V. Rezultatul este identic; a doua varianta e de cateva ori mai rapida, si asta conteaza cand ai un timp fix de lucru.

File Explorer este aplicatia cu care faci toate operatiile cu fisiere si foldere in Windows. Se deschide cu Windows+E. Fiecare operatie are un traseu prin meniu (clic dreapta) si o scurtatura de tastatura — le folosesti pe amandoua, dupa cum e mai comod.
Creare de folder

Clic dreapta in spatiu gol → New → Folder, apoi scrii numele si apesi Enter. Scurtatura: Ctrl+Shift+N creeaza direct un folder nou in locul unde te afli. Daca ai apasat Enter prea repede si folderul a ramas cu numele implicit (New folder), il redenumesti cu F2.

Copiere si mutare — deosebirea care se puncteaza
  • Copiere: selectezi → Ctrl+C → mergi in destinatie → Ctrl+V. Originalul ramane unde era; ai doua exemplare.
  • Mutare: selectezi → Ctrl+X → mergi in destinatie → Ctrl+V. Originalul dispare din locul initial; ai un singur exemplar.
  • Cand tragi cu mausul: intre doua unitati diferite (de pe stickul E: pe C:) Windows copiaza; in interiorul aceleiasi unitati muta. Daca cerinta zice explicit „copiaza", nu te baza pe tragere — foloseste Ctrl+C.
Redenumire

Selectezi fisierul → tasta F2 (sau clic dreapta → Rename) → scrii noul nume → Enter. Atentie: daca extensiile sunt afisate, Windows selecteaza doar partea dinaintea punctului — nu sterge .docx, altfel fisierul nu se mai deschide cu aplicatia potrivita.

Stergere si Cosul de reciclare

Tasta Delete trimite fisierul in Cosul de reciclare (Recycle Bin), de unde poate fi adus inapoi cu clic dreapta → Restore. Combinatia Shift+Delete il sterge definitiv, fara sa mai treaca prin cos. Daca ai gresit chiar acum o mutare sau o stergere, apasa Ctrl+Z — File Explorer anuleaza ultima operatie.

Selectie multipla — cand ai de mutat zece fise deodata
  • Ctrl+clic — adaugi in selectie fisiere risipite prin lista
  • Shift+clic — selectezi tot intervalul dintre primul si ultimul fisier pe care dai clic
  • Ctrl+A — selectezi tot ce se afla in folderul curent

5. Arhivare ZIP, cautare si proprietatile fisierelor

De ce se cere arhiva la final

Trebuie sa trimiti mentorului de practica un folder cu 14 fisiere. Atasezi 14 fisiere pe rand la e-mail sau atasezi unul singur, care le contine pe toate si ocupa mai putin spatiu? Fisierul acela unic se numeste arhiva, iar la proba D cerinta suna aproape mereu la fel: „arhivati folderul si denumiti arhiva...".

O arhiva este un fisier care contine, comprimate, mai multe fisiere si foldere. Formatul ZIP este recunoscut direct de Windows, fara program suplimentar. Arhivarea nu atinge fisierele originale: ele raman la locul lor, iar arhiva apare ca fisier nou.
Cum creezi si cum deschizi o arhiva ZIP

Creare: selectezi fisierele sau folderul → clic dreapta → Compress to ZIP file (Windows 11) sau Send to → Compressed (zipped) folder (Windows 10). Apare un fisier .zip in acelasi loc, caruia ii poti schimba numele cu F2.

Deschidere: dublu clic pe arhiva iti arata continutul, dar fisierele sunt inca inauntru. Ca sa le scoti cu adevarat: clic dreapta pe arhiva → Extract All → alegi folderul destinatie → Extract. Greseala clasica la proba: lucrezi direct in fereastra arhivei si crezi ca ai salvat, cand de fapt n-ai extras nimic.

Cautarea unui fisier

In File Explorer, campul de cautare se afla in dreapta sus; cu File Explorer deschis, Ctrl+F te duce direct in el. Cauti dupa o parte din nume (fisa), dupa inceput cu asterisc pentru rest (plan*) sau dupa tip (*.docx gaseste toate documentele Word din folderul curent si din subfolderele lui). Pentru cautare in tot calculatorul: Windows+S deschide cautarea din bara de activitati.

Proprietatile unui fisier

Clic dreapta pe fisier → Properties. Acolo citesti: Type of file (tipul), Size (dimensiunea reala), Size on disk (cat spatiu ocupa efectiv), Created si Modified (data crearii si a ultimei modificari) si atributele Read-only (doar citire) si Hidden (ascuns). Cand cerinta zice „precizati dimensiunea fisierului", de aici o iei.

6

6. Setari de sistem si verificarea finala inainte de predare

Doua minute care salveaza toata lucrarea

Ai terminat sarcina si mai ai cinci minute. Deschizi File Explorer, te uiti la structura ta de foldere si compari nume cu nume cu cerinta de pe foaie. Gasesti Fise_de_lucru scris Fise_de_Lucru si o arhiva ramasa pe Desktop in loc sa fie in folderul cerut. Le repari. Aceasta verificare finala face diferenta intre punctaj complet si puncte pierdute din neatentie.

Pe langa lucrul cu fisierele, proba practica poate cere setari de baza ale sistemului: data si ora, rezolutia ecranului, informatii despre contul de utilizator, folosirea corecta a unui stick USB. Toate se fac din interfata Windows, fara cunostinte de administrare.
Data si ora sistemului

Clic dreapta pe ceasul din bara de activitati → Adjust date/time. Poti lasa sincronizarea automata din internet sau poti seta manual. Conteaza: data sistemului este cea care se scrie in proprietatile fisierelor tale (Created, Modified) si cea care apare in documente cand inserezi data curenta.

Rezolutia ecranului

Clic dreapta pe Desktop → Display settings → Display resolution. Alege valoarea marcata Recommended — este rezolutia proprie a monitorului (frecvent 1920x1080). O rezolutie mai mica face totul mai mare, dar mai neclar; una nepotrivita poate ascunde butoane sub marginea ecranului.

Contul de utilizator

Start → Settings → Accounts iti arata cu ce cont esti conectat si ce tip are. In laboratorul scolii lucrezi de obicei cu un cont Standard, nu de administrator: poti crea, salva si sterge fisiere in folderele tale, dar nu poti instala programe sau schimba setari care afecteaza tot calculatorul.

Stickul USB, corect

Dupa ce il conectezi, asteapta cateva secunde sa apara in File Explorer, la This PC, cu propria litera de unitate. Cand ai terminat: clic pe pictograma USB din bara de activitati → Eject (Scoatere in siguranta), apoi il scoti. Daca il tragi din calculator in timp ce inca se copiaza, fisierul copiat poate ramane incomplet.

Lista de verificare inainte de predare
  • Numele folderelor si al fisierelor sunt scrise exact ca in cerinta (litera cu litera, cu aceleasi liniute)
  • Ierarhia este cea ceruta: fiecare subfolder in folderul parinte corect
  • Fisierele si-au pastrat extensiile dupa redenumire
  • Arhiva exista, are numele cerut si contine ce trebuie (deschide-o si uita-te inauntru)
  • Nu ai lasat foldere goale de proba, fisiere „New folder" sau copii nedorite
  • Ai salvat cu Ctrl+S in fiecare aplicatie ramasa deschisa

Exercitii practice

Exercitiul 1 (Nivel minim) — Structura portofoliului de practica

Activeaza intai afisarea extensiilor in File Explorer. Creeaza pe Desktop folderul PORTOFOLIU_PRACTICA si, in interiorul lui, trei subfoldere: Planuri_de_lectie, Fise_de_lucru si Fotografii. In Fise_de_lucru creeaza un fisier text nou numit jurnal_practica.txt. Scrie apoi pe caiet calea absoluta completa a acestui fisier.

Vezi rezolvarea

Pasii, in ordine:

  1. Deschide File Explorer cu Windows+E si activeaza extensiile: View » Show » File name extensions (Windows 11) sau fila View si casuta File name extensions (Windows 10).
  2. Pe Desktop, clic dreapta in spatiu gol » New » Folder (sau Ctrl+Shift+N) si scrie numele PORTOFOLIU_PRACTICA, apoi Enter.
  3. Intra in folder (dublu clic) si repeta operatia de trei ori, pentru Planuri_de_lectie, Fise_de_lucru si Fotografii.
  4. Intra in Fise_de_lucru » clic dreapta » New » Text Document » apasa F2 si scrie jurnal_practica.txt. Pastreaza extensia .txt.
  5. Calea absoluta se citeste in bara de adrese, dand clic in ea. Are forma: C:\Users\[NumeUtilizator]\Desktop\PORTOFOLIU_PRACTICA\Fise_de_lucru\jurnal_practica.txt, unde [NumeUtilizator] este numele contului cu care esti logat.

Rezultat asteptat: pe Desktop un folder cu trei subfoldere, dintre care Fise_de_lucru contine un singur fisier .txt.

Exercitiul 2 (Nivel standard) — Copiere, mutare, redenumire, arhivare

Porneste de la structura creata la Exercitiul 1. (a) Copiaza jurnal_practica.txt din Fise_de_lucru in Planuri_de_lectie. (b) Redenumeste copia din Planuri_de_lectie in plan_saptamana1.txt. (c) Muta plan_saptamana1.txt in Fotografii si spune ce s-a intamplat cu el in Planuri_de_lectie. (d) Arhiveaza intregul folder PORTOFOLIU_PRACTICA intr-un fisier ZIP. (e) Deschide Properties pe folder si pe arhiva, noteaza cele doua dimensiuni si explica de ce difera.

Vezi rezolvarea

(a) In Fise_de_lucru, selecteaza jurnal_practica.txt » Ctrl+C » intra in Planuri_de_lectie » Ctrl+V. Originalul ramane in Fise_de_lucru, pentru ca este copiere, nu mutare.

(b) In Planuri_de_lectie, selecteaza copia » F2 » scrie plan_saptamana1.txt » Enter. Pastreaza extensia .txt; daca ai sters-o, Windows nu mai stie cu ce program sa deschida fisierul.

(c) Selecteaza plan_saptamana1.txt » Ctrl+X » intra in Fotografii » Ctrl+V. In Planuri_de_lectie fisierul nu mai exista: mutarea lasa un singur exemplar, in destinatie.

(d) Iesi pe Desktop, clic dreapta pe PORTOFOLIU_PRACTICA » Compress to ZIP file (Windows 11) sau Send to » Compressed (zipped) folder (Windows 10). Arhiva apare langa folder, care ramane neatins.

(e) Clic dreapta » Properties pe fiecare. Arhiva este de obicei mai mica: fisierele text se comprima foarte bine, iar in folder fiecare fisier ocupa pe disc un numar intreg de unitati de alocare (de aceea Size on disk este mai mare decat Size), pe cand in arhiva ele sunt asezate unul dupa altul intr-un singur fisier.

Exercitiul 3 (Nivel performanta) — Simulare completa de proba practica

Lucreaza contra cronometru, 15 minute. (a) Creeaza pe Desktop folderul PRACTICA_[DATA_DE_AZI], cu data reala in formatul AAAA-LL-ZZ, si in el subfolderele Documente, Versiuni si Arhiva. (b) In Documente creeaza trei fisiere text: fisa1.txt, fisa2.txt, fisa3.txt, fiecare cu cel putin un rand de text scris si salvat. (c) Pastreaza o copie a lui fisa1.txt in Versiuni, apoi redenumeste fisierul ramas in Documente in fisa1_revizuita.txt. Atentie la ordinea celor doua operatii. (d) Selecteaza cele trei fisiere din Documente si arhiveaza-le sub numele fise_practica.zip; muta arhiva in Arhiva. (e) Verifica: cauta *.txt in folderul principal si spune cate rezultate ar trebui sa gasesti si de ce; deschide arhiva si confirma ca are exact trei fisiere.

Vezi rezolvarea

Nu primesti produsul gata, ci ordinea de lucru si capcanele.

  1. Structura: Ctrl+Shift+N pe Desktop, nume PRACTICA_2027-03-12 (pune data reala a zilei, in format an-luna-zi), apoi inauntru inca trei foldere: Documente, Versiuni, Arhiva.
  2. Fisierele: in Documente, de trei ori clic dreapta » New » Text Document, redenumite cu F2 in fisa1.txt, fisa2.txt, fisa3.txt. Deschide fiecare, scrie un rand, Ctrl+S, inchide. Fara text salvat, fisierele au 0 octeti si arhiva nu dovedeste nimic.
  3. Capcana de la (c): intai Ctrl+C pe fisa1.txt si Ctrl+V in Versiuni, abia apoi F2 pe cel din Documente si redenumire in fisa1_revizuita.txt. Daca redenumesti mai intai, nu mai ai de unde copia varianta cu numele vechi.
  4. Arhivarea: in Documente, selecteaza cele trei fisiere cu Ctrl+A (sau Ctrl+clic pe fiecare) » clic dreapta » Compress to ZIP file » F2 si scrie fise_practica.zip » Ctrl+X pe arhiva » intra in Arhiva » Ctrl+V. Fisierele originale raman in Documente: arhivarea nu le sterge.
  5. Verificarea de la (e): cautarea *.txt pornita din folderul principal se face si in subfoldere, deci gaseste 4 rezultate: cele trei din Documente (fisa1_revizuita.txt, fisa2.txt, fisa3.txt) plus copia fisa1.txt din Versiuni. Arhiva nu se numara la aceste rezultate: extensia ei este .zip, deci nu se potriveste cu tiparul *.txt. Deschizi apoi arhiva cu dublu clic si numeri: exact trei fisiere.

Criterii de evaluare: numele si ierarhia exacte (inclusiv formatul datei), copierea facuta inaintea redenumirii, arhiva cu numele cerut si cu trei fisiere inauntru, aflata in Arhiva, si explicatia corecta a numarului de rezultate la cautare.

Ce ai invatat astazi

  • Hardware: procesorul executa instructiunile, memoria RAM tine datele active si este volatila, HDD/SSD pastreaza datele si dupa oprire, perifericele aduc informatia inauntru si o scot afara
  • Sistemul de operare porneste primul si administreaza programele, memoria, fisierele si dispozitivele; Word sau browserul sunt aplicatii care ruleaza peste el
  • Fisierele stau intr-o ierarhie de foldere pornita de la radacina (C:\); calea absoluta o citesti in bara de adrese din File Explorer
  • Extensia spune tipul fisierului si aplicatia care il deschide — afiseaza extensiile la inceputul probei (View → Show → File name extensions) si nu le sterge la redenumire
  • Copiere = Ctrl+C / Ctrl+V (originalul ramane); Mutare = Ctrl+X / Ctrl+V (originalul dispare); Redenumire = F2; Anulare = Ctrl+Z
  • Delete duce fisierul in Cosul de reciclare, de unde poate fi adus inapoi; Shift+Delete il sterge definitiv
  • Arhivare ZIP: clic dreapta → Compress to ZIP file (W11) sau Send to → Compressed (zipped) folder (W10); fisierele originale raman intacte, iar scoaterea lor se face cu Extract All
  • Inainte de predare: nume scrise exact ca in cerinta, ierarhie corecta, extensii pastrate, arhiva verificata pe dinauntru, Ctrl+S peste tot

Vrei mai mult?

Provocare: Fa doua arhive. Prima: pune intr-un folder cinci fisiere .txt in care ai lipit fiecare cate o pagina de text, si arhiveaza-l. A doua: pune intr-un alt folder cinci fotografii .jpg si arhiveaza-l si pe acesta. Compara, prin Properties, dimensiunea fiecarui folder cu dimensiunea arhivei lui.

De ce: arhiva cu text se micsoreaza mult, uneori la mai putin de un sfert, in timp ce arhiva cu fotografii ramane aproape cat folderul initial. De ce reuseste comprimarea la un fel de fisiere si nu si la celalalt? Uita-te la ce scrie in lectie despre .jpg.

Mai departe: comprimarea castiga spatiu acolo unde datele se repeta — intr-un text, aceleasi cuvinte si litere revin mereu. Formatul .jpg este insa deja comprimat, cu pierderi, chiar in momentul in care se face fotografia, asa ca ZIP-ul nu mai gaseste mare lucru de scos. De aici si practica din scoli: dosarele de documente se trimit arhivate, iar pozele de la serbari se micsoreaza inainte de trimitere prin redimensionare, nu prin arhivare.
