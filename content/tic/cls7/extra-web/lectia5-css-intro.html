📚 INVATA

CSS - Cascading Style Sheets

Ce este CSS si de ce il folosim?

CSS (Cascading Style Sheets = "Foi de Stil in Cascada") este limbajul care controleaza aspectul vizual al paginilor web. Daca HTML-ul construieste structura (peretii, usile, ferestrele), CSS-ul este vopseaua, tapetul, mobilierul si iluminatul.

Fara CSS, toate paginile web ar arata la fel: text negru pe fundal alb, cu font Times New Roman. Cu CSS, poti controla absolut totul: culori, fonturi, dimensiuni, spatiere, animatii, layout si mult mai mult.

🏠 Analogie: Casa

Imagineaza-ti o casa. HTML = constructia casei (peretii, acoperisul, usile, ferestrele). CSS = decorarea casei (culoarea peretilor, modelul parchetului, tipul de mobila, cortinele). Acelasi plan de casa poate arata complet diferit cu decorari diferite!

La fel si o pagina web: acelasi HTML poate arata profesional sau amator, modern sau invechit - totul depinde de CSS.

🔨 Sintaxa CSS: Anatomia unei reguli

Cum scriem o regula CSS?

Fiecare regula CSS are 3 parti: un selector (ce element vrei sa stilizezi), o proprietate (ce vrei sa schimbi) si o valoare (cum vrei sa arate).

Formula generala
selector { proprietate: valoare; }
Anatomia unei reguli CSS
h1 {
color : purple ;
font-size : 2rem ;
}
Selector
Proprietate
Valoare
Punct si virgula (obligatoriu!)
Exemple practice
/* Toate paragrafele devin albastre */ p { color: blue; } /* Titlul h1 devine mare si centrat */ h1 { font-size: 3rem; text-align: center; } /* Body-ul primeste fundal inchis */ body { background-color: #1a1a2e; color: white; font-family: Arial, sans-serif; }
💡 Regula de aur: punct si virgula

Fiecare linie din interiorul acoladelor { } trebuie sa se termine cu punct si virgula (;). Daca uiti punct si virgula, acea regula si urmatoarea nu vor functiona!

📦 Cele 3 moduri de a adauga CSS

Metoda 1: CSS Inline (in atributul style)

Scrii CSS direct in tag-ul HTML, in atributul style="". Simplu dar nu recomandat pentru proiecte mari.

Inline CSS
<h1 style="color: purple; font-size: 2rem;">Titlu</h1> <p style="color: gray; margin: 10px;">Paragraf</p>
Metoda 2: CSS Intern (tag-ul <style> in <head>)

Scrii toate regulile CSS intr-un bloc <style> in <head>. Recomandat pentru exercitii - totul e intr-un singur fisier.

CSS Intern
<head> <style> h1 { color: purple; font-size: 2rem; } p { color: gray; margin: 10px; } </style> </head>
Metoda 3: CSS Extern (fisier .css separat)

CSS-ul sta intr-un fisier separat (ex: stil.css) si il legam cu <link>. Cel mai profesional - folosit in proiecte reale.

In fisierul HTML:
<head> <link rel="stylesheet" href="stil.css"> </head>
In fisierul stil.css:
h1 { color: purple; font-size: 2rem; } p { color: gray; margin: 10px; }
Comparatie: Cele 3 metode
Metoda Unde scrii CSS Cand o folosesti
Inline In atributul style="" Doar pentru 1-2 elemente. Rapid dar dezordonat.
Intern In <style> in <head> Pentru exercitii si pagini simple. Totul intr-un fisier.
Extern Fisier .css separat Pentru proiecte reale. Cel mai curat si organizat.
💡 Ce metoda sa folosesc la clasa?

In aceasta lectie vom folosi CSS intern (tag-ul <style> in <head>) pentru ca e cel mai usor de invatat - totul sta in acelasi fisier HTML.

🎯 Selectori: Cui ii spun sa se schimbe?

1. Selector de element (tag)

Selecteaza toate elementele de acel tip din pagina. Scrii doar numele tag-ului, fara < >.

Selector de element
/* TOATE paragrafele devin gri */ p { color: gray; } /* TOATE titlurile h1 devin violet */ h1 { color: purple; } /* TOATE listele neordonate primesc fundal */ ul { background-color: #f0f0f0; }
2. Selector de clasa (.numeClasa)

Selecteaza doar elementele care au atributul class="numeClasa". In CSS, scrii punct (.) inaintea numelui clasei.

O clasa poate fi folosita pe mai multe elemente - e ca o "eticheta" pe care o lipesti pe orice element vrei.

In CSS:
.important { color: red; font-weight: bold; } .evidential { background-color: yellow; padding: 5px; }
In HTML:
<p class="important">Acest text e rosu si bold!</p> <p>Acest paragraf e normal.</p> <span class="important">Si acesta e rosu!</span>
3. Selector de ID (#numeId)

Selecteaza un singur element unic care are atributul id="numeId". In CSS, scrii diez (#) inaintea numelui.

Un ID se foloseste o singura data in pagina - e ca un CNP: unic pentru fiecare element.

In CSS:
#header { background-color: #333; color: white; padding: 20px; text-align: center; }
In HTML:
<div id="header">Acesta este header-ul unic</div>
Comparatie rapida: Selectori
Tip selector Sintaxa CSS In HTML Selecteaza
Element p { } <p> TOATE paragrafele
Clasa .info { } class="info" Toate elementele cu acea clasa
ID #menu { } id="menu" UN singur element unic

🎨 Proprietati CSS comune

Culoare si text

Cele mai folosite proprietati pentru a controla cum arata textul pe pagina:

Proprietati de text
p { color: #333; /* culoarea textului */ background-color: #f0f0f0; /* culoarea fundalului */ font-size: 16px; /* marimea textului */ font-family: Arial, sans-serif; /* tipul de font */ font-weight: bold; /* grosimea: bold/normal */ text-align: center; /* aliniere: left/center/right */ text-decoration: underline; /* subliniere */ line-height: 1.6; /* distanta intre randuri */ }
Dimensiuni si spatiere

Cum controlam marimea elementelor si spatiul dintre ele:

Proprietati de spatiere
div { width: 300px; /* latimea */ height: 200px; /* inaltimea */ margin: 20px; /* spatiu IN AFARA elementului */ padding: 15px; /* spatiu IN INTERIORUL elementului */ border: 2px solid #333; /* chenar (bordura) */ border-radius: 10px; /* colturi rotunjite */ }

💡 Cum functioneaza codurile hex?

#RRGGBB = 3 perechi de caractere: RR (rosu), GG (verde), BB (albastru). Fiecare pereche merge de la 00 (nimic) la FF (maxim).

Exemple: #ff0000 = rosu maxim, verde 0, albastru 0 = rosu pur. #000000 = negru. #ffffff = alb.

📦 Modelul Box (margin, padding, border)

Fiecare element e o "cutie"

In CSS, fiecare element HTML este o cutie cu 4 straturi, de la interior la exterior:

Content (continutul) → Padding (spatiu interior) → Border (chenarul) → Margin (spatiu exterior)

Modelul Box - cele 4 straturi
MARGIN (spatiu exterior)
BORDER (chenar)
PADDING (spatiu interior)
CONTENT (textul tau)

Margin = distanta fata de alte elemente  |  Padding = distanta de la chenar la text

🏠 Analogie: Tabloul de pe perete

Imagineaza-ti un tablou inramat pe perete. Content = pictura in sine. Padding = passepartout-ul (cartonul alb dintre pictura si rama). Border = rama tabloului. Margin = distanta dintre tablou si alte obiecte de pe perete.

Exemplu practic Box Model
.card { padding: 20px; /* 20px spatiu in interior */ border: 2px solid #8b5cf6; /* bordura violet */ margin: 15px; /* 15px spatiu in afara */ border-radius: 10px; /* colturi rotunjite */ background-color: #1a1a2e; /* fundal inchis */ }

🛑 Greseli frecvente in CSS

⚠ Greseli pe care le fac toti incepatorii
Gresit ❌ De ce e gresit
p { color = red; } Foloseste = in loc de :. In CSS se scrie proprietate: valoare;, nu proprietate = valoare;
p { color: red } Lipseste punct si virgula (;) la sfarsit. Fara ea, urmatoarea proprietate nu va functiona!
<p> { color: red; } Nu pune < > in selector! Scrie doar numele tag-ului: p { ... }
p { colour: red; } Proprietatea se scrie color (ortografia americana), nu "colour" (ortografia britanica)
p { font size: 16px; } Proprietatile cu doua cuvinte se leaga cu cratima: font-size, nu font size
.Titlu { } cu class="titlu" CSS este case-sensitive la clase si ID-uri. .Titlu nu e acelasi lucru cu .titlu
Corect ✅
p { color: red; } /* doua puncte, nu egal */ p { color: red; } /* punct si virgula la sfarsit */ p { font-size: 16px; } /* cratima intre cuvinte */ .titlu { color: blue; } /* punct inainte de clasa */ #menu { color: white; } /* diez inainte de ID */

🔑 Ce face fiecare regula importanta?
  • body { background-color: #0a0a12; } — Fundalul intregii pagini devine inchis
  • h1 { color: #8b5cf6; } — Titlul principal devine violet
  • .card { border-left: 4px solid... } — Fiecare "card" are o linie violet in stanga
  • #footer { text-align: center; } — Footer-ul unic este centrat
  • border-radius: 12px; — Colturile card-urilor sunt rotunjite
