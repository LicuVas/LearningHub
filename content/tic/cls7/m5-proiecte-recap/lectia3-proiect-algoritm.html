Proiect: Algoritm Complet

Implementeaza un algoritm care rezolva o problema practica

Progres lectie:
0%
🎯

Obiectivul proiectului

"Vei crea un algoritm complet in pseudocod care rezolva o problema reala, demonstrand intelegerea structurilor de control!"

1

Alegerea problemei

Alege una din problemele de mai jos pentru proiectul tau:

  • Calculator de medie: Calculeaza media la mai multe materii
  • Verificator de an bisect: Determina daca un an este bisect
  • Convertor de unitati: Converteste intre km/mile, C/F, etc.
  • Joc ghiceste numarul: Utilizatorul ghiceste un numar
  • Calculator de varsta: Calculeaza varsta din data nasterii
Care este primul pas in rezolvarea unei probleme algoritmic?
A Scrierea codului imediat
B Intelegerea problemei si identificarea datelor
C Testarea programului
💡 Inainte de a scrie, trebuie sa intelegi ce trebuie rezolvat.
2

Analiza problemei

Pentru fiecare problema, identifica:

  • Date de intrare (INPUT): Ce informatii primeste algoritmul?
  • Date de iesire (OUTPUT): Ce rezultat trebuie sa afiseze?
  • Prelucrari: Ce operatii trebuie facute?

Exemplu - Calculator medie:

  • INPUT: notele la 3-5 materii
  • OUTPUT: media aritmetica
  • PRELUCRARE: suma notelor / numarul de note
Ce reprezinta datele de intrare intr-un algoritm?
A Rezultatul final
B Informatiile primite de la utilizator
C Variabilele temporare
💡 INPUT = ce primeste algoritmul.
3

Structuri de control necesare

Algoritmul tau trebuie sa foloseasca:

  • Citire/Afisare: CITESTE, SCRIE
  • Atribuire: variabila ← valoare
  • Decizie: DACA...ATUNCI...ALTFEL
  • Repetitie: CAT TIMP sau PENTRU
// Exemplu structura DACA DACA nota >= 5 ATUNCI SCRIE "Promovat!" ALTFEL SCRIE "Nepromovat" SFARSIT DACA
Ce structura folosesti cand trebuie sa alegi intre doua variante?
A Structura repetitiva (CAT TIMP)
B Structura alternativa (DACA-ATUNCI)
C Structura secventiala
💡 DACA conditia este adevarata ATUNCI...
4

Validarea datelor

Un algoritm bun verifica daca datele introduse sunt corecte:

SCRIE "Introdu nota (1-10):" CITESTE nota CAT TIMP nota < 1 SAU nota > 10 EXECUTA SCRIE "Nota invalida! Reintrodu:" CITESTE nota SFARSIT CAT TIMP

Aceasta bucla se repeta pana cand utilizatorul introduce o valoare valida.

De ce este importanta validarea datelor de intrare?
A Nu este importanta
B Pentru a evita erori cand utilizatorul introduce date gresite
C Pentru a face algoritmul mai lung
💡 Ce se intampla daca utilizatorul introduce -5 ca nota?
5

Cerinte proiect

📋 Cerinte obligatorii:

  1. Alege o problema din lista propusa
  2. Scrie analiza problemei (INPUT/OUTPUT/PRELUCRARE)
  3. Scrie algoritmul in pseudocod
  4. Foloseste minim o structura DACA
  5. Foloseste minim o structura repetitiva
  6. Include validarea datelor de intrare
  7. Testeaza algoritmul cu 3 seturi de date

⭐ Bonus pentru nota maxima:

  • Deseneaza schema logica
  • Adauga mesaje explicative pentru utilizator
  • Trateaza cazuri speciale (ex: impartire la 0)
  • Implementeaza in Scratch sau Python
Ce trebuie sa contina documentatia algoritmului?
A Doar codul
B Explicatii despre ce face fiecare parte
C Nimic, codul vorbeste singur

Realizare Proiect

Scrie algoritmul tau complet!

// ALGORITM: Calculator de medie // INPUT: n note // OUTPUT: media aritmetica INCEPUT SCRIE "Cate note vrei sa introduci?" CITESTE n // Validare CAT TIMP n <= 0 EXECUTA SCRIE "Numar invalid! Reintrodu:" CITESTE n SFARSIT CAT TIMP suma ← 0 PENTRU i ← 1, n EXECUTA SCRIE "Nota ", i, ": " CITESTE nota suma ← suma + nota SFARSIT PENTRU media ← suma / n SCRIE "Media ta este: ", media DACA media >= 5 ATUNCI SCRIE "Felicitari, ai promovat!" ALTFEL SCRIE "Trebuie sa mai inveti." SFARSIT DACA SFARSIT
