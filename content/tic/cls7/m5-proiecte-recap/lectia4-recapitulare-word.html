Obiectivul lectiei

"Vom recapitula toate conceptele importante din Microsoft Word pentru pregatirea evaluarii!"

1

Interfata Word

Elementele principale ale interfetei Word:

  • Ribbon: Bara cu toate instrumentele, organizata pe tab-uri
  • Tab-uri principale: Home, Insert, Design, Layout, References, View
  • Rigla: Pentru indentari si tab-uri
  • Bara de stare: Informatii despre document (pagini, cuvinte)
  • Zona de lucru: Unde scrii documentul

Fisierele Word au extensia .docx

Ce extensie au fisierele Word?
A .pptx
B .xlsx
C .docx
💡 DOCument X = .docx
2

Scurtaturi importante

Scurtatura Actiune
Ctrl+S Salveaza documentul
Ctrl+C Copiaza selectia
Ctrl+V Lipeste
Ctrl+X Decupeaza (cut)
Ctrl+Z Anuleaza ultima actiune
Ctrl+A Selecteaza tot
Ctrl+B Bold (ingrosare)
Ctrl+I Italic (inclinare)
Ctrl+U Underline (subliniere)
Ce combinatie selecteaza tot textul din document?
A Ctrl+S
B Ctrl+A
C Ctrl+C
💡 A = All (tot)
3

Formatarea textului

Formatare caractere:

  • Font (tipul literelor): Arial, Times New Roman, Calibri
  • Dimensiune: masurata in puncte (pt)
  • Stil: Bold, Italic, Underline
  • Culoare text si culoare fundal

Formatare paragraf:

  • Aliniere: stanga, centru, dreapta, justify
  • Indentare: prima linie, stanga, dreapta
  • Spatiere: inainte si dupa paragraf
  • Interliniere: spatiul dintre randuri
Ce este un paragraf in Word?
A O propozitie
B Textul dintre doua apasari de Enter
C O pagina
💡 Fiecare apasare de Enter creeaza un nou paragraf.
4

Tabele si liste

Tabele:

  • Insert → Table → selectezi numarul de randuri si coloane
  • Poti adauga/sterge randuri si coloane
  • Poti imbina celule (Merge Cells)
  • Poti formata bordurile si fundalul

Liste:

  • Liste cu marcatori (bullets): puncte, patrate, simboluri
  • Liste numerotate: 1, 2, 3 sau a, b, c sau I, II, III
  • Liste pe mai multe niveluri (sub-puncte)
De unde inserezi un tabel in Word?
A Tab-ul Home
B Tab-ul Insert
C Tab-ul View
💡 Insert = Inserare de elemente noi.
5

Imagini si verificare ortografica

Inserare imagini:

  • Insert → Pictures → din computer sau online
  • Redimensionare: trage de colturi (pastreaza proportiile)
  • Wrap text: cum se aseaza textul in jurul imaginii

Verificare ortografica:

  • Tasta F7 porneste spell check
  • Cuvintele gresite sunt subliniate cu rosu
  • Erorile gramaticale sunt subliniate cu albastru
  • Click dreapta pentru sugestii de corectare
Ce tasta porneste verificarea ortografica?
A F5
B F7
C F12
💡 F7 pentru spelling check.
6

Salvare si export

Tipuri de salvare:

  • Save (Ctrl+S): Salveaza in acelasi fisier
  • Save As (F12): Salveaza cu alt nume sau format
  • Export: Salveaza ca PDF sau alt format

Formate importante:

  • .docx - format Word standard (editabil)
  • .pdf - pentru partajare (nu se modifica)
  • .doc - format Word vechi (compatibilitate)
Ce optiune folosesti pentru a exporta documentul ca PDF?
A Save
B Save As / Export
C Print
💡 Save As permite alegerea formatului.
