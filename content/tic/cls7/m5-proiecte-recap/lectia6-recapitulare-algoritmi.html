Ce este un algoritm?

Un algoritm este o secventa finita si bine definita de pasi pentru rezolvarea unei probleme.

Caracteristici ale algoritmilor:

  • Finit: Se termina dupa un numar finit de pasi
  • Precis: Fiecare pas este clar definit
  • Date de intrare: Primeste date (INPUT)
  • Date de iesire: Produce rezultate (OUTPUT)
  • Eficient: Rezolva problema in timp rezonabil
Ce este un algoritm?
A Un limbaj de programare
B O secventa de pasi pentru rezolvarea unei probleme
C Un tip de variabila
💡 Algoritmul este ca o reteta - pasi ordonati.
2

Variabile si operatii de baza

Variabile: Locatii de memorie cu nume pentru stocarea valorilor.

Operatii de baza:

// Citire (INPUT) CITESTE variabila // Afisare (OUTPUT) SCRIE "text", variabila // Atribuire variabila ← valoare suma ← a + b

Operatori aritmetici: + (adunare), - (scadere), * (inmultire), / (impartire), % (rest)

Ce reprezinta simbolul atribuire in pseudocod?
A =
B ←
C ==
💡 Sageata arata ca valoarea merge in variabila.
3

Structura alternativa (DACA)

Permite executarea unor instructiuni doar daca o conditie este adevarata.

// Forma simpla DACA conditie ATUNCI instructiuni SFARSIT DACA // Forma completa DACA nota >= 5 ATUNCI SCRIE "Promovat" ALTFEL SCRIE "Nepromovat" SFARSIT DACA

Operatori de comparare: = (egal), ≠ (diferit), < (mai mic), > (mai mare), ≤, ≥

Operatori logici: SI (AND), SAU (OR), NU (NOT)

Ce structura folosesti cand ai de ales intre doua optiuni?
A PENTRU
B DACA-ATUNCI-ALTFEL
C CAT TIMP
💡 IF-THEN-ELSE in engleza.
4

Structuri repetitive

CAT TIMP (WHILE): Repeta cat timp conditia e adevarata.

CAT TIMP conditie EXECUTA instructiuni SFARSIT CAT TIMP // Exemplu: numara pana la 5 i ← 1 CAT TIMP i <= 5 EXECUTA SCRIE i i ← i + 1 SFARSIT CAT TIMP

PENTRU (FOR): Repeta de un numar cunoscut de ori.

PENTRU i ← 1, 5 EXECUTA SCRIE i SFARSIT PENTRU
Cand folosesti CAT TIMP vs PENTRU?
A Nu conteaza, sunt identice
B CAT TIMP cand nu stii numarul de repetari, PENTRU cand stii
C PENTRU doar pentru numere pare
💡 PENTRU = numar cunoscut, CAT TIMP = conditie.
5

Trace table (Urmarirea executiei)

Pentru a verifica un algoritm, urmaresti valorile variabilelor pas cu pas:

suma ← 0 PENTRU i ← 1, 3 EXECUTA suma ← suma + i SFARSIT PENTRU

Trace table:

Pasisuma
Initial-0
110+1=1
221+2=3
333+3=6

Rezultat final: suma = 6

Ce valoare va avea suma dupa executare: suma←0; PENTRU i←1,3 EXECUTA suma←suma+i?
A 3
B 6
C 9
💡 1+2+3 = ?
6

Schema logica

Simbolurile din schema logica:

  • Oval: START / STOP
  • Paralelogram: Citire / Afisare (INPUT/OUTPUT)
  • Dreptunghi: Instructiune / Calcul
  • Romb: Decizie (conditie) - are 2 iesiri: DA si NU
  • Sageti: Directia de executie

Schema logica ajuta la vizualizarea fluxului algoritmului.

Ce forma geometrica reprezinta o decizie in schema logica?
A Dreptunghi
B Romb
C Paralelogram
💡 Rombul are doua iesiri: DA si NU.
