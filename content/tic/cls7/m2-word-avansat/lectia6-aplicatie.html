1

Planificarea documentului

Inainte de a incepe sa scrii, planifica structura documentului:

Intrebari de pus:

  • Ce tip de document creez? (referat, CV, articol, brosura)
  • Cate sectiuni/capitole voi avea?
  • Am nevoie de coperta?
  • Ce imagini/diagrame voi include?
  • Care e audienta? (profesor, angajator, colegi)

Exemplu structura referat:

  1. Coperta (titlu, autor, data)
  2. Cuprins (generat automat)
  3. Introducere
  4. Capitolele principale (2-4)
  5. Concluzie
  6. Bibliografie
Care este primul pas in crearea unui document complex?
A Scrii tot textul
B Planifici structura documentului
C Inserezi imaginile
💡 Inainte de a scrie, trebuie sa stii CE vei scrie.
2

Proiect 1: Referatul perfect

Structura referat profesional
  1. Coperta - sectiune separata, fara numar de pagina
    • Titlul referatului (stilul Title)
    • Numele tau si clasa
    • Data
    • Numele scolii (optional: logo)
  2. Cuprins - pagina noua
    • References → Table of Contents
    • Se genereaza din stilurile Heading
  3. Continut - capitole cu Heading 1, subcapitole cu Heading 2
  4. Bibliografie - lista surselor

Checklist tehnic:

  • Margini: 2.5 cm (Normal)
  • Font text: Times New Roman 12pt sau Arial 11pt
  • Spatiere: 1.5 linii
  • Aliniere: Justified
De ce e important sa aplici stilurile Heading de la inceput?
A Arata mai bine
B Pentru cuprins automat si navigare
C Nu e important
💡 Stilurile permit functionalitati automate.
3

Proiect 2: CV-ul tau

Un CV (Curriculum Vitae) prezinta experienta, educatia si abilitatile tale.

Sectiuni standard CV
  • Date personale - nume, contact (email, telefon)
  • Profil - 2-3 propozitii despre tine
  • Educatie - scoli, ani, medii
  • Experienta - activitati, voluntariat
  • Abilitati - limbi straine, calculator, soft skills
  • Hobby-uri - activitati extrascolare

Sfaturi design CV:

  • O singura pagina (pentru elevi)
  • Design curat, usor de citit
  • Foloseste coloane pentru spatiu eficient
  • Adauga o poza profesionala (optional)
  • Foloseste liste pentru lizibilitate
Ce este un CV?
A O scrisoare de intentie
B Un document care prezinta experienta si abilitatile tale
C Un tip de referat
💡 CV = Curriculum Vitae = parcursul vietii.
4

Proiect 3: Fluturas informativ

Un fluturas (flyer) este un material promotional de o pagina.

Elemente fluturas
  • Titlu mare care atrage atentia
  • Imagine principala relevanta
  • Text scurt - maxim 100 cuvinte
  • Informatii esentiale - cand, unde, ce
  • Contact / Call to action

Tehnici Word pentru fluturas:

  • Orientare Landscape
  • Text pe coloane (2-3)
  • Text boxes pentru pozitionare libera
  • Shapes pentru decoratiuni
  • Culori contrastante pentru vizibilitate
Ce orientare folosesti de obicei pentru un fluturas?
A Portrait
B Landscape
C Nu conteaza
💡 Fluturasele sunt de obicei mai late decat inalte.
5

Salvarea si exportul

Dupa ce termini documentul, salveaza-l in formatul potrivit:

Formate disponibile:

  • .docx - format Word nativ (pentru editare ulterioara)
  • .pdf - format fix (pentru trimitere/tiparire)
  • .doc - format Word vechi (compatibilitate)
  • .rtf - Rich Text Format (universal)

Cum salvezi ca PDF:

  1. File → Save As (sau Export)
  2. Alege locatia
  3. La "Save as type" alege PDF
  4. Click Save

Sau: File → Export → Create PDF/XPS

Ce format este cel mai bun pentru a trimite un document care nu trebuie editat?
A .docx
B .pdf
C .txt
💡 PDF pastreaza formatarea si nu poate fi usor modificat.
6

Revizia finala - Checklist

Inainte de a trimite documentul, verifica:

Continut:

  • Ortografie si gramatica (F7 sau Review → Spelling)
  • Informatiile sunt corecte si complete
  • Numele si datele sunt exacte

Formatare:

  • Stilurile sunt aplicate consistent
  • Titlurile sunt corecte
  • Spatierile sunt uniforme
  • Imaginile sunt aliniate

Aspect:

  • Print Preview (Ctrl+P) - vezi cum va arata tiparit
  • Numerele de pagina sunt corecte
  • Cuprinsul e actualizat (click dreapta → Update Field)
Ce verifici inainte de a trimite un document?
A Doar ortografia
B Ortografia, formatarea si aspectul general
C Nimic, e gata
💡 Revizia finala include mai multe aspecte.
