Ce sunt listele multinivel?

O lista multinivel (multilevel list) este o lista care are mai multe niveluri de organizare. Gandeste-te la cuprinsul unei carti:

  • Capitolul 1
    • 1.1 Prima sectiune
    • 1.2 A doua sectiune
      • 1.2.1 Subsectiune

Listele multinivel sunt esentiale pentru referate , proiecte stiintifice si documente oficiale .

Ce tip de lista are mai multe niveluri de indentare?
A Lista simpla
B Lista multinivel
C Lista numerotata
💡 Gandeste-te la liste care au sub-puncte in interiorul punctelor principale.
2

Crearea nivelurilor cu Tab

Pentru a crea niveluri in liste folosim tastele:

  • Tab - muta elementul la un nivel mai adanc (sub-punct)
  • Shift+Tab - muta elementul la un nivel superior

Exemplu practic:

  1. Scrie primul element si apasa Enter
  2. Apasa Tab pentru a crea un sub-punct
  3. Apasa Shift+Tab pentru a reveni la nivelul principal
Ce combinatie de taste creste nivelul de indentare?
A Ctrl+Tab
B Tab
C Shift+Tab
💡 Este tasta folosita si pentru indentare in alte programe.
3

Butonul Multilevel List

In Word, gasesti butonul Multilevel List in:

Tab Home → Grupul Paragraph → Multilevel List

Cand apesi pe sageata de langa buton, vezi mai multe formate predefinite:

  • Numere: 1, 1.1, 1.1.1
  • Litere: A, a, i
  • Simboluri: ●, ○, ■
  • Mixt: combinatii de numere si litere
Unde gasesti optiunea Multilevel List in Word?
A Tab-ul Insert
B Tab-ul Home, grupul Paragraph
C Tab-ul View
💡 Listele fac parte din formatarea paragrafelor.
4

Marcatori personalizati (Custom Bullets)

Poti schimba cercul negru obisnuit cu orice simbol sau imagine!

Pasi pentru marcatori personalizati:

  1. Selecteaza lista sau pune cursorul in lista
  2. Click pe sageata de langa butonul Bullets
  3. Alege Define New Bullet...
  4. Optiuni disponibile:
    • Symbol - alege din sute de simboluri (★, ✓, ➤)
    • Picture - foloseste o imagine mica
    • Font - schimba fontul si culoarea
Ce optiune folosesti pentru a pune o imagine ca marcator?
A New Bullet
B Define New Bullet → Picture
C Symbol
💡 Trebuie mai intai sa definesti un marcator nou, apoi sa alegi o imagine.
5

Define New Multilevel List

Pentru control total asupra listelor multinivel, foloseste Define New Multilevel List :

Home → Multilevel List → Define New Multilevel List

Aici poti seta pentru fiecare nivel:

  • Number format - cum arata numerotarea (1, A, I, a, i)
  • Number style - cu punct, paranteza, etc.
  • Start at - de la ce numar incepe
  • Alignment - alinierea textului
  • Text indent - cat de mult e indentat textul
Ce optiune permite formatarea detaliata a fiecarui nivel?
A Bullets
B Numbering
C Define New Multilevel List
💡 Cauta optiunea care permite personalizarea pentru FIECARE nivel.
6

Scurtaturi utile pentru liste

Memoreaza aceste scurtaturi pentru a lucra mai rapid:

  • Ctrl+Shift+L - aplica/sterge lista cu marcatori
  • Tab - creste nivelul (in lista)
  • Shift+Tab - scade nivelul (in lista)
  • Enter - element nou pe acelasi nivel
  • Enter+Enter - iese din lista
  • Backspace - la inceputul elementului, scade nivelul
Ce scurtatura transforma textul selectat in lista numerotata?
A Ctrl+Shift+L
B Ctrl+Shift+N
C Ctrl+L
💡 L vine de la List.
7

Aplicatii practice

Cand folosesti fiecare tip de lista:

  • Liste cu marcatori (bullets) - pentru enumerari simple unde ordinea nu conteaza
    • Ingrediente reteta
    • Lista de cumparaturi
  • Liste numerotate simple - pentru pasi sau ordine importanta
    • Instructiuni de utilizare
    • Etapele unui experiment
  • Liste multinivel - pentru structuri complexe
    • Cuprinsul unui referat
    • Structura unui proiect
    • Plan de afaceri
Pentru cuprinsul unui referat, ce tip de lista este cel mai potrivit?
A Lista cu marcatori (bullets)
B Lista multinivel numerotata
C Lista simpla
💡 Cuprinsul are capitole, sectiuni si subsectiuni - deci mai multe niveluri cu numere.
