Inainte de multinivel — liste simple (recapitulare)

Listele multinivel se construiesc pe baza listelor simple. Asigura-te ca stii sa le creezi:

  • Lista cu marcatori (Bullets): Tab Home → grupul Paragraph → butonul Bullets (≡ cu punct). Folosita pentru enumerari unde ordinea nu conteaza.
  • Lista numerotata (Numbering): Tab Home → grupul Paragraph → butonul Numbering (1. 2. 3.). Folosita cand ordinea elementelor conteaza.

Cum creezi o lista simpla:

  1. Scrie textul si selecteaza-l (sau pune cursorul pe rand)
  2. Apasa butonul Bullets sau Numbering din tab-ul Home
  3. Apasa Enter dupa fiecare element pentru a trece la urmatorul
  4. Apasa Enter de doua ori la final pentru a iesi din lista
💡

Aceasta lectie se numeste Word Avansat si trece la pasul urmator — listele multinivel. Daca ai nevoie sa recapitulezi listele simple, revezi modulul anterior inainte de a continua.

Unde gasesti butoanele pentru lista cu marcatori si lista numerotata in Word?
A Tab Insert, grupul Lists
B Tab Home, grupul Paragraph
C Tab View, grupul Show
💡 Formatarea paragrafelor, inclusiv listele, se afla in tab-ul Home.

Ce sunt listele multinivel?

O lista multinivel (multilevel list) este o lista care are mai multe niveluri de organizare. Gandeste-te la cuprinsul unei carti:

  • Capitolul 1
    • 1.1 Prima sectiune
    • 1.2 A doua sectiune
      • 1.2.1 Subsectiune

Listele multinivel sunt esentiale pentru referate , proiecte stiintifice si documente oficiale .

Ce tip de lista are mai multe niveluri de indentare?
A Lista simpla
B Lista multinivel
C Lista numerotata
💡 Gandeste-te la liste care au sub-puncte in interiorul punctelor principale.
2

Crearea nivelurilor cu Tab

Pentru a crea niveluri in liste folosim tastele:

  • Tab - muta elementul la un nivel mai adanc (sub-punct)
  • Shift+Tab - muta elementul la un nivel superior

Exemplu practic:

  1. Scrie primul element si apasa Enter
  2. Apasa Tab pentru a crea un sub-punct
  3. Apasa Shift+Tab pentru a reveni la nivelul principal
Ce combinatie de taste creste nivelul de indentare?
A Ctrl+Tab
B Tab
C Shift+Tab
💡 Este tasta folosita si pentru indentare in alte programe.
3

Butonul Multilevel List

In Word, gasesti butonul Multilevel List in:

Tab Home → Grupul Paragraph → Multilevel List

Cand apesi pe sageata de langa buton, vezi mai multe formate predefinite:

  • Numere: 1, 1.1, 1.1.1
  • Litere: A, a, i
  • Simboluri: ●, ○, ■
  • Mixt: combinatii de numere si litere
Unde gasesti optiunea Multilevel List in Word?
A Tab-ul Insert
B Tab-ul Home, grupul Paragraph
C Tab-ul View
💡 Listele fac parte din formatarea paragrafelor.
4

Marcatori personalizati (Custom Bullets)

Poti schimba cercul negru obisnuit cu orice simbol sau imagine!

Pasi pentru marcatori personalizati:

  1. Selecteaza lista sau pune cursorul in lista
  2. Click pe sageata de langa butonul Bullets
  3. Alege Define New Bullet...
  4. Optiuni disponibile:
    • Symbol - alege din sute de simboluri (★, ✓, ➤)
    • Picture - foloseste o imagine mica
    • Font - schimba fontul si culoarea
Ce optiune folosesti pentru a pune o imagine ca marcator?
A New Bullet
B Define New Bullet → Picture
C Symbol
💡 Trebuie mai intai sa definesti un marcator nou, apoi sa alegi o imagine.
5

Define New Multilevel List

Pentru control total asupra listelor multinivel, foloseste Define New Multilevel List :

Home → Multilevel List → Define New Multilevel List

Aici poti seta pentru fiecare nivel:

  • Number format - cum arata numerotarea (1, A, I, a, i)
  • Number style - cu punct, paranteza, etc.
  • Start at - de la ce numar incepe
  • Alignment - alinierea textului
  • Text indent - cat de mult e indentat textul
Ce optiune permite formatarea detaliata a fiecarui nivel?
A Bullets
B Numbering
C Define New Multilevel List
💡 Cauta optiunea care permite personalizarea pentru FIECARE nivel.
6

Scurtaturi utile pentru liste

Memoreaza aceste scurtaturi pentru a lucra mai rapid:

  • Ctrl+Shift+L - aplica/sterge lista cu marcatori
  • Tab - creste nivelul (in lista)
  • Shift+Tab - scade nivelul (in lista)
  • Enter - element nou pe acelasi nivel
  • Enter+Enter - iese din lista
  • Backspace - la inceputul elementului, scade nivelul
Ce scurtatura aplica sau sterge rapid lista cu marcatori (bullets)?
A Ctrl+Shift+L
B Ctrl+Shift+N
C Ctrl+L
💡 L vine de la List Bullet — stilul de lista cu marcatori din Word.

Aplicatii practice

Cand folosesti fiecare tip de lista:

  • Liste cu marcatori (bullets) - pentru enumerari simple unde ordinea nu conteaza
    • Ingrediente reteta
    • Lista de cumparaturi
  • Liste numerotate simple - pentru pasi sau ordine importanta
    • Instructiuni de utilizare
    • Etapele unui experiment
  • Liste multinivel - pentru structuri complexe
    • Cuprinsul unui referat
    • Structura unui proiect
    • Programa unei excursii scolare
Pentru cuprinsul unui referat, ce tip de lista este cel mai potrivit?
A Lista cu marcatori (bullets)
B Lista multinivel numerotata
C Lista simpla
💡 Cuprinsul are capitole, sectiuni si subsectiuni - deci mai multe niveluri cu numere.

Exercitii practice

Exercitiul 1 (Nivel minim) - Analiza liste

Deschide un referat sau o carte digitala si analizeaza:

  1. Ce tip de liste sunt folosite in cuprins?
  2. Cate niveluri de indentare vezi?
  3. Ce marcatori sunt folositi pentru fiecare nivel?

Raspunde numerotat: 1. ... 2. ... 3. ...

Vezi rezolvarea

Model de raspuns (foloseste un referat despre un subiect la alegere, de exemplu "Sistemul Solar"):

  1. Tipul de lista din cuprins: lista multinivel numerotata (Capitolul 1, 1.1, 1.2, Capitolul 2...) - se potriveste pentru ca ordinea capitolelor conteaza.
  2. Niveluri de indentare: de obicei 2-3 niveluri - capitol (nivel 1), subcapitol (nivel 2), uneori un al treilea nivel pentru detalii.
  3. Marcatori: la nivelul 1 - numere (1, 2, 3), la nivelul 2 - numere compuse (1.1, 1.2), la nivelul 3 (daca exista) - litere (a, b) sau cifre romane.

Daca referatul analizat foloseste doar bullete simple in cuprins (fara numerotare), e semn ca autorul nu a folosit Multilevel List din Word, ci a scris manual - lucru nerecomandat pentru documente lungi.

Exercitiul 2 (Nivel standard) - Mini-proiect: Cuprins referat

Creeaza cuprinsul pentru un referat despre un subiect la alegere:

Cerinte obligatorii:

⭐ Bonus (pentru nota maxima):

  • Adauga si un al treilea nivel (1.1.1)
  • Personalizeaza fontul pentru titlurile de capitol
Vezi rezolvarea

Exemplu de cuprins pentru un referat despre "Reciclarea deseurilor" (foloseste Home → Multilevel List, apoi Tab/Shift+Tab pentru niveluri):

  1. 1. Introducere
  2. 1.1. Ce este reciclarea
  3. 1.2. De ce este importanta
  4. 2. Tipuri de deseuri reciclabile
  5. 2.1. Hartie si carton
  6. 2.2. Plastic
  7. 2.3. Sticla si metal
  8. 3. Reciclarea in scoala noastra
  9. 3.1. Colectarea selectiva
  10. 3.2. Rezultate si concluzii

Pasi: scrie fiecare linie si apasa Enter, apoi Tab pentru subcapitole. Aplica Multilevel List (Home → Paragraph) cu formatul 1, 1.1, 1.1.1. Bonus: adauga un al treilea nivel (ex. 2.1.1 - "Sticla transparenta", "Sticla colorata") si personalizeaza fontul titlurilor de capitol din Define New Multilevel List → Font.

Exercitiul 3 (Nivel performanta) - Compunere

Cerinta: Explica diferenta dintre listele cu marcatori si listele multinivel. Cand folosesti fiecare tip?

Indicii:

  • Cand conteaza ordinea?
  • Cand ai nevoie de sub-puncte?
  • Exemple din viata reala

Cuvinte cheie de folosit: marcatori, numerotare, multinivel, indentare, cuprins

Vezi rezolvarea

Schita compunerii (nu scrie textul integral - structureaza-l tu):

  1. Paragraf 1: defineste cele doua tipuri - bullets (ordine care NU conteaza) vs multinivel (structura ierarhica, ordine si niveluri).
  2. Paragraf 2: cand se foloseste fiecare - bullets pentru liste de cumparaturi/ingrediente; multinivel pentru cuprins de referat, structura de proiect.
  3. Paragraf 3: exemplu concret din viata (ex: cuprinsul unei carti vs lista de sarcini zilnice).
  4. Incheiere: o propozitie cu concluzia ta.

Foloseste obligatoriu cuvintele cheie: marcatori, numerotare, multinivel, indentare, cuprins - cate unul in fiecare paragraf.

Criterii de evaluare: diferenta explicata corect, minim 2 exemple concrete, toate cuvintele cheie folosite in context, text coerent de 6-8 randuri.
