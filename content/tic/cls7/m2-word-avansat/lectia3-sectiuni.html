Sectiuni si coloane

Invata sa imparti documentul in sectiuni cu formatari diferite

0%

Obiectivul lectiei

1

Ce sunt sectiunile?

O sectiune (Section) este o parte a documentului care poate avea formatare proprie, diferita de restul documentului.

De ce ai nevoie de sectiuni?

  • O pagina landscape in mijlocul unui document portrait
  • Prima pagina fara numar, restul cu numere
  • Antet diferit pentru fiecare capitol
  • O parte pe doua coloane, alta pe o coloana

Gandeste-te la sectiuni ca la "mini-documente" in interiorul documentului principal.

Ce permite o sectiune in Word?
A Sa stergi text
B Sa ai formatari diferite in acelasi document
C Sa inserezi imagini
💡 Sectiunile permit formatari DIFERITE.
2

Tipuri de Section Breaks

Gasesti Section Breaks in Layout → Breaks:

  • Next Page - sectiune noua pe pagina urmatoare
  • Continuous - sectiune noua pe aceeasi pagina (pentru coloane)
  • Even Page - sectiune noua pe urmatoarea pagina para
  • Odd Page - sectiune noua pe urmatoarea pagina impara

Cand le folosesti:

  • Next Page - pentru capitole noi, coperta
  • Continuous - pentru coloane, schimbari de format
  • Even/Odd Page - pentru carti tiparite
Ce break folosesti pentru a incepe o sectiune noua pe aceeasi pagina?
A Next Page
B Continuous
C Page Break
💡 Continuous = continuu, pe aceeasi pagina.
3

Page Break vs Section Break

Page Break (intrerupere de pagina) - muta textul pe pagina urmatoare, dar NU creeaza sectiune noua.

  • Scurtatura: Ctrl+Enter
  • Layout → Breaks → Page

Section Break (intrerupere de sectiune) - creeaza o sectiune noua cu formatare proprie.

  • Layout → Breaks → (tip de sectiune)

Diferenta importanta:

  • Page Break = doar pagina noua, aceeasi formatare
  • Section Break = pagina noua + formatare diferita posibila
Ce scurtatura insereaza un Page Break?
A Ctrl+Enter
B Ctrl+Shift+Enter
C Alt+Enter
💡 Este combinatia simpla Ctrl + Enter.
4

Text pe coloane

Coloanele sunt utile pentru ziare, brosuri, reviste sau fluturas.

Cum creezi coloane:

  1. Selecteaza textul (sau pune cursorul unde vrei)
  2. Du-te la Layout → Columns
  3. Alege: One, Two, Three, Left, Right

Optiuni avansate (More Columns...):

  • Numar personalizat de coloane
  • Latimea fiecarei coloane
  • Spatiul dintre coloane
  • Linie separatoare intre coloane
Unde gasesti optiunea pentru coloane?
A Home → Columns
B Layout → Columns
C Insert → Columns
💡 Coloanele tin de aspectul paginii (Layout).
5

Column Break

Cand ai text pe coloane, uneori vrei sa fortezi trecerea la coloana urmatoare.

Cum inserezi Column Break:

  • Layout → Breaks → Column
  • Sau: Ctrl+Shift+Enter

Exemplu practic: Ai o lista de ingrediente pe 2 coloane, dar vrei ca "Legume" sa inceapa in coloana 2 chiar daca coloana 1 nu e plina.

Sfat: Pentru a vedea unde sunt break-urile, activeaza Show/Hide ¶ (Ctrl+Shift+8).

Ce break folosesti pentru a trece la coloana urmatoare?
A Page Break
B Column Break
C Section Break
💡 Este break-ul specific pentru coloane.
6

Orientare diferita pe sectiuni

Un caz frecvent: vrei o pagina landscape (pentru un tabel mare) in mijlocul unui document portrait.

Pasi:

  1. Pune cursorul unde vrei pagina landscape
  2. Layout → Breaks → Next Page (sectiune noua)
  3. Cu cursorul in noua sectiune: Layout → Orientation → Landscape
  4. La sfarsitul paginii landscape: Layout → Breaks → Next Page
  5. In ultima sectiune: Layout → Orientation → Portrait

Acum ai: Portrait → Landscape → Portrait!

Cum faci o pagina landscape in mijlocul unui document portrait?
A Nu se poate
B Schimbi orientarea pentru tot documentul
C Creezi o sectiune noua si schimbi orientarea doar pentru ea
💡 Sectiunile permit formatari diferite in acelasi document.
7

Vizualizarea break-urilor

Pentru a vedea unde sunt break-urile in document:

Home → Show/Hide ¶ sau Ctrl+Shift+8

Vei vedea:

  • ¶ - sfarsit de paragraf
  • · - spatiu
  • → - Tab
  • ···Page Break··· - intrerupere de pagina
  • ===Section Break (Next Page)=== - intrerupere de sectiune

Sfat important: Sterge break-urile cu Delete cand cursorul e chiar in fata lor, sau cu Backspace cand e dupa.

Ce buton arata simbolurile invizibile (break-uri, spatii)?
A Show/Hide ¶
B View All
C Format
💡 Simbolul ¶ reprezinta paragraful.
