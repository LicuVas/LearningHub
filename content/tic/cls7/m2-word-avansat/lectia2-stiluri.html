1

Ce sunt stilurile?

Un stil (Style) este un set de formatari (font, marime, culoare, spatiere) salvat sub un nume. In loc sa formatezi manual fiecare titlu, aplici stilul "Heading 1" si gata!

Avantajele stilurilor:

  • Consistenta - toate titlurile arata la fel
  • Eficienta - schimbi formatarea cu un click
  • Cuprins automat - Word poate genera cuprinsul din titluri
  • Navigare usoara - poti sari la orice sectiune
Ce este un stil in Word?
A O culoare pentru text
B Un set de formatari salvate sub un nume
C O imagine de fundal
💡 Stilul grupeaza mai multe setari de formatare.
2

Stiluri predefinite importante

Word vine cu stiluri predefinite pe care le gasesti in Tab Home → Styles:

  • Normal - textul obisnuit al documentului
  • Heading 1 - titlu principal (capitol) - Ctrl+Alt+1
  • Heading 2 - subtitlu (sectiune) - Ctrl+Alt+2
  • Heading 3 - sub-subtitlu - Ctrl+Alt+3
  • Title - titlul documentului
  • Subtitle - subtitlul documentului
  • Quote - citat
Ce scurtatura aplica stilul Heading 1?
A Ctrl+Alt+1
B Ctrl+1
C Alt+1
💡 Combinatia foloseste trei taste: Ctrl, Alt si numarul.
3

Teme (Themes)

O tema este un set coordonat de culori, fonturi si efecte care schimba aspectul intregului document.

Gasesti temele in: Design → Themes

O tema include:

  • Theme Colors - paleta de culori (12 culori coordonate)
  • Theme Fonts - doua fonturi (unul pentru titluri, unul pentru text)
  • Theme Effects - stiluri pentru forme si grafice

Cand schimbi tema, TOT documentul se actualizeaza automat!

Ce contine o tema (Theme) in Word?
A Doar fonturi
B Doar culori
C Culori, fonturi si efecte
💡 Tema este un pachet complet de design.
4

Modificarea stilurilor

Poti modifica orice stil pentru a se potrivi nevoilor tale:

Metoda 1 - Click dreapta:

  1. Click dreapta pe stilul din galerie
  2. Alege Modify...
  3. Schimba fontul, marimea, culoarea, etc.
  4. Bifeaza "Automatically update" daca vrei

Metoda 2 - Update to Match Selection:

  1. Formateaza un paragraf cum doresti
  2. Click dreapta pe stil
  3. Alege Update [Stil] to Match Selection

Toate paragrafele cu acel stil se vor actualiza instant!

Cum modifici un stil existent?
A Il stergi si creezi altul
B Click dreapta pe stil → Modify
C Nu se poate modifica
💡 Click dreapta deschide meniul contextual cu optiuni.
5

Style Sets (Seturi de stiluri)

Un Style Set este o colectie de stiluri care lucreaza impreuna armonios.

Gasesti in: Design → Document Formatting

Exemple de Style Sets:

  • Basic (Elegant) - simplu, profesional
  • Basic (Stylish) - modern, cu accente
  • Centered - titluri centrate
  • Shaded - titluri cu fundal colorat
  • Lines (Distinctive) - linii decorative

Schimba Style Set-ul pentru a transforma complet aspectul documentului!

Unde gasesti Style Sets (seturi de stiluri)?
A Home → Styles
B Design → Document Formatting
C Insert → Styles
💡 Seturile de stiluri sunt legate de design-ul documentului.
6

Panoul Styles

Pentru acces la toate stilurile, deschide panoul Styles:

  • Click pe sageata din coltul grupului Styles (Home tab)
  • Sau foloseste Ctrl+Alt+Shift+S

In panou poti:

  • Vedea TOATE stilurile disponibile
  • Crea stiluri noi (butonul New Style)
  • Sterge stiluri
  • Importa/Exporta stiluri intre documente

Sfat: Bifeaza "Show Preview" pentru a vedea cum arata fiecare stil.

Ce buton deschide panoul complet de stiluri?
A Sageata din coltul grupului Styles
B Butonul Styles din Ribbon
C Tasta F1
💡 Cauta sageata mica din coltul din dreapta-jos al grupului.
7

De ce conteaza stilurile?

Stilurile nu sunt doar pentru aspect - au functionalitati importante:

1. Cuprins automat

  • References → Table of Contents
  • Word genereaza cuprinsul din Heading 1, 2, 3

2. Navigation Pane

  • View → Navigation Pane
  • Vezi structura documentului si sari la orice sectiune

3. Outline View

  • View → Outline
  • Reorganizeaza sectiunile prin drag-and-drop

4. Export profesional

  • La export in PDF, structura se pastreaza
  • Cititorii pot naviga dupa cuprins
Ce functionalitate permite generarea automata a cuprinsului?
A Folosirea stilurilor Heading
B Scrierea manuala
C Folosirea listelor
💡 Word recunoaste titlurile dupa stilurile aplicate.
