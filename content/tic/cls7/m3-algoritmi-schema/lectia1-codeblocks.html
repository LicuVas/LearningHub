IDE (Integrated Development Environment)

IDE (Integrated Development Environment)
Un IDE este un program care combina mai multe unelte pentru programatori:
  • Editor de cod - unde scriem programul
  • Compilator - transforma codul in program executabil
  • Debugger - ne ajuta sa gasim erori
De ce conteaza? Fara un IDE, ar trebui sa folosim 3 programe separate. Cu Code::Blocks, facem totul dintr-un singur loc!
2

De ce Code::Blocks?

De ce Code::Blocks?
  • ✅ Gratuit si open-source
  • ✅ Usor de folosit - interfata simpla
  • ✅ Cross-platform - merge pe Windows, Linux, Mac
  • ✅ Include MinGW - compilatorul vine inclus
3

💡 Erori frecvente la instalare

💡 Erori frecvente la instalare

"Compiler not found" - Ai descarcat versiunea fara mingw. Reinstaleaza cu versiunea corecta.

"Cannot run program" - Antivirusul poate bloca Code::Blocks. Roaga un adult (parinte sau profesor) sa adauge Code::Blocks la exceptiile antivirusului — modificarea setarilor de securitate trebuie facuta de un adult.

Consola dispare instant - Normal pentru programe simple. Adauga system("pause"); inainte de return 0;

4

Fluxul de lucru: pseudocod → schema logica → cod (comp. VII-2.2)

Programa OMEN 3393/2017 (competenta VII-2.2) cere sa construiesti algoritmul si sa-l reprezinti in pseudocod inainte de a-l implementa intr-un limbaj de programare. Fluxul corect are trei etape:

1. PSEUDOCOD — descrie algoritmul in cuvinte, independent de limbaj
↓
2. SCHEMA LOGICA — reprezinta algoritmul cu simboluri vizuale (oval, dreptunghi, romb)
↓
3. COD C++ — implementeaza algoritmul in limbajul ales

Exemplu rapid: Vrei un program care afiseaza un salut.

Pseudocod: AFISEAZA "Buna ziua!"

Cod C++: cout << "Buna ziua!";

In lectiile urmatoare vei invata sa scrii pseudocod complet pentru fiecare structura (secventiala, alternativa, repetitiva).

Exercitii practice

Exercitiul 1 (Nivel minim) - Programare

Cerinta: Creeaza un proiect nou in Code::Blocks si ruleaza programul implicit care afiseaza "Hello world!".

Vezi rezolvarea

Pasi:

  1. Deschide Code::Blocks si alege File > New > Project > Console Application, limbaj C++.
  2. Da un nume proiectului (ex: Ex1) si apasa Finish. Code::Blocks genereaza automat fisierul main.cpp cu codul implicit, care contine linia cout << "Hello world!";.
  3. Apasa F9 (Build and Run) pentru a compila si rula programul.
  4. Verifica in consola neagra ca apare exact textul Hello world!.

Daca apare eroare "Compiler not found", verifica ca ai instalat versiunea Code::Blocks cu MinGW inclus (vezi ATOM 3 din lectie).

Exercitiul 2 (Nivel standard) - Programare

Cerinta: Modifica programul astfel incat sa afiseze numele tau in loc de "Hello world!".

Vezi rezolvarea

Deschide fisierul main.cpp din proiectul anterior (sau creeaza unul nou de tip Console Application). In interiorul functiei main(), gaseste linia cout << "Hello world!"; si inlocuieste textul dintre ghilimele cu numele tau, de exemplu:

cout << "Maria Popescu";

Salveaza fisierul (Ctrl+S) si apasa F9 pentru a recompila si rula. In consola trebuie sa apara numele tau in loc de "Hello world!". Atentie: nu sterge punctul si virgula de la final, altfel compilatorul da eroare de sintaxa.

Exercitiul 3 (Nivel performanta) - Programare

Cerinta: Afiseaza pe linii separate: numele tau, clasa ta si scoala ta. Foloseste endl pentru linie noua.

Vezi rezolvarea

Structura solutiei (schita, nu cod integral):

  1. In main(), foloseste trei instructiuni cout separate, fiecare terminata cu << endl; pentru trecere la linie noua.
  2. Ordinea ceruta: intai numele, apoi clasa, apoi scoala - fiecare pe randul lui.
  3. Fiecare informatie e text fix scris intre ghilimele, legat de cout cu operatorul <<.

Capcana frecventa: uitarea lui endl pe o linie face ca urmatorul cout sa continue pe acelasi rand. Criteriu de evaluare: 3 informatii afisate, fiecare pe rand propriu, compilare fara erori cu F9.

Exercitiul 4 (Nivel performanta) - Programare

Cerinta: Creeaza un program care afiseaza o "carte de vizita" cu informatiile tale. Urmeaza pasii:

  1. Deschide Code::Blocks si creeaza un proiect nou de tip "Console Application".
  2. In functia main(), foloseste cout pentru a afisa pe randuri separate: Nume:, Clasa:, Scoala:, Materia preferata:.
  3. Intre fiecare rand foloseste endl pentru trecerea la linie noua.
  4. Adauga o linie de separare (ex: cout << "==================" << endl;) inainte si dupa datele tale.
  5. Compileaza si ruleaza cu F9. Verifica ca toate informatiile apar corect in consola.
Vezi rezolvarea

Structura solutiei (schita, nu cod integral):

  1. Creeaza un proiect nou Console Application.
  2. In main(), afiseaza intai o linie de separare, de exemplu cout << "==================" << endl;.
  3. Apoi cate un cout pe rand pentru Nume, Clasa, Scoala, Materia preferata, fiecare cu eticheta proprie si endl la sfarsit.
  4. Repeta linia de separare dupa ultima informatie.

Capcana: eticheta si valoarea trebuie legate cu <<, nu despartite prin virgula. Criteriu de evaluare: 4 informatii afisate corect, incadrate de doua linii de separare identice, compilare cu F9 fara erori.

Ce ai invatat astazi

  • Ce este un IDE si ce componente contine (editor, compilator, debugger)
  • De ce Code::Blocks este o optiune buna pentru inceput (gratuit, cross-platform, include MinGW)
  • Cum rezolvi erorile frecvente la instalare
  • Fluxul corect de lucru: pseudocod → schema logica → cod C++ (comp. VII-2.2)

Vrei mai mult?

Ai instalat Code::Blocks. Acum pune-l la treaba dincolo de exercitii.

  • Provocare: Scrie un program simplu (ex: afiseaza numele tau), apoi sterge intentionat un ; de undeva si apasa Compile. Citeste EXACT mesajul de eroare din fereastra de jos - noteaza numarul liniei si cuvantul cheie. Repara, apoi sterge o acolada } si compara eroarea. Compilatorul iti spune ceva precis, doar in engleza tehnica.
  • De ce? De ce trebuie sa proiectezi algoritmul in pseudocod INAINTE de a scrie cod C++, in loc sa scrii direct si sa corectezi din mers? Ce se pierde daca sari peste pasul de proiectare?
  • Mai departe: Orice IDE profesionist (Visual Studio, VS Code, IntelliJ) are aceleasi trei componente: editor, compilator, debugger. Cand vei invata Python sau Java, primul lucru pe care il vei instala e tot un IDE.
