1

Ce este Microsoft Word?

Microsoft Word este un procesor de texte - aplicatia profesionala pentru crearea documentelor. Cu Word poti scrie referate, CV-uri, scrisori oficiale, rapoarte si multe alte documente.

Extensia fisierelor Word este .docx (sau .doc pentru versiunile mai vechi). Word face parte din suita Microsoft Office, alaturi de Excel, PowerPoint si alte aplicatii.

Ce tip de aplicatie este Microsoft Word?
A Aplicatie pentru calcul tabelar
B Procesor de texte
C Editor de imagini
💡 Word este folosit pentru a crea si edita documente text.
2

Ribbon - Panglica cu instrumente

Ribbon-ul (Panglica) este bara larga situata in partea de sus a ferestrei Word. Aici gasesti toate instrumentele de editare, formatare si inserare, organizate logic pe tab-uri.

Ribbon-ul a fost introdus de Microsoft pentru a inlocui meniurile clasice, oferind acces vizual rapid la toate functiile. Poti ascunde sau afisa Ribbon-ul cu combinatia Ctrl+F1.

Ce este Ribbon-ul in Word?
A Zona unde scrii textul
B Bara cu instrumente organizate pe tab-uri
C Bara de stare din josul ecranului
💡 Ribbon vine de la englezescul panglica si contine toate instrumentele.
3

Tab-urile principale

Ribbon-ul este organizat pe tab-uri (file), fiecare cu instrumente specifice:

Home - formatare text, clipboard, stiluri de baza
Insert - inserare tabele, imagini, forme, simboluri
Design - teme, culori, chenare pagina
Layout - margini, orientare, dimensiune pagina
View - moduri de vizualizare, zoom, rigle

In ce tab gasesti optiunile de formatare a textului (Bold, Italic)?
A Insert
B Home
C View
💡 Tab-ul principal, primul din stanga, contine formatarea de baza.
4

Bara de acces rapid

Quick Access Toolbar (Bara de acces rapid) este o bara mica situata deasupra sau sub Ribbon, care contine butoane pentru comenzile folosite cel mai des.

Implicit contine butoanele: Save, Undo si Redo. Poti personaliza aceasta bara adaugand orice comanda doresti - click dreapta pe o comanda din Ribbon si alege "Add to Quick Access Toolbar".

La ce foloseste bara de acces rapid (Quick Access Toolbar)?
A Pentru a schimba tema documentului
B Pentru acces rapid la comenzile folosite frecvent
C Pentru a vizualiza documentul pe tot ecranul
💡 Quick Access = Acces Rapid la comenzile tale preferate.
5

Bara de stare

Status Bar (Bara de stare) este situata in partea de jos a ferestrei Word. Aici vezi informatii utile despre document:

- Numarul paginii curente si totalul de pagini
- Numarul de cuvinte din document
- Limba setata pentru verificarea ortografica
- Butoane pentru modurile de vizualizare
- Cursorul de Zoom pentru a mari sau micsora afisarea

Ce afiseaza bara de stare (Status Bar)?
A Lista cu fisierele recente
B Informatii despre document: pagina curenta, numar cuvinte, zoom
C Meniul principal al aplicatiei
💡 Bara de stare afiseaza informatii despre starea curenta a documentului.
6

Zona de lucru si scurtaturi esentiale

Zona de lucru este spatiul central, alb, unde scrii si editezi textul. Este reprezentarea paginii tale de document.

Scurtaturi de tastatura esentiale:
Ctrl+N - Document nou
Ctrl+O - Deschide document existent
Ctrl+S - Salveaza documentul
Ctrl+Z - Anuleaza ultima actiune (Undo)
Ctrl+Y - Reface actiunea anulata (Redo)

Ce combinatie de taste deschide un document nou?
A Ctrl+O
B Ctrl+N
C Ctrl+S
💡 N vine de la New (nou).
7

Moduri de vizualizare

Word ofera mai multe moduri de a vizualiza documentul (tab-ul View):

Print Layout - Modul standard, arata documentul asa cum va fi tiparit, cu margini si pagini distincte. Recomandat pentru editare.
Read Mode - Optimizat pentru citire, fara distractii.
Web Layout - Arata cum ar aparea documentul pe o pagina web.
Outline - Vizualizare structurata, pe capitole si subcapitole.

Ce vizualizare este recomandata pentru editarea documentelor?
A Read Mode
B Print Layout
C Web Layout
💡 Print Layout arata documentul asa cum va arata la tiparire.
