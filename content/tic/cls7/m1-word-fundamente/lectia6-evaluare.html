Obiectivul evaluarii

"Aceasta evaluare verifica cunostintele despre interfata Word, formatare text, paragrafe, liste si tabele. Succes!"

1

Interfata Word

Recapitulare: Microsoft Word este un procesor de texte profesional. Interfata include Ribbon-ul (panglica cu instrumente), bara de acces rapid, zona de lucru si bara de stare.

Scurtaturi importante: Ctrl+N (document nou), Ctrl+O (deschide), Ctrl+S (salveaza), Ctrl+Z (anuleaza).

Ce extensie au fisierele Microsoft Word moderne?
A .pptx
B .xlsx
C .docx
💡 doc + x = docx pentru documente Word.
2

Formatare Text

Recapitulare: Formatarea textului include stiluri (Bold, Italic, Underline), fonturi (Calibri, Times New Roman), dimensiuni (masurat in puncte) si culori.

Format Painter copiaza formatarea. Ctrl+Space sterge formatarea.

Ce combinatie de taste aplica Italic (text inclinat)?
A Ctrl+B
B Ctrl+I
C Ctrl+U
💡 I vine de la Italic.
3

Paragrafe si Aliniere

Recapitulare: Tipuri de aliniere: Left (Ctrl+L), Center (Ctrl+E), Right (Ctrl+R), Justify (Ctrl+J). Line Spacing controleaza spatiul dintre randuri.

Indentarea muta textul fata de margine. First Line Indent muta doar primul rand.

Ce tip de aliniere face textul sa se intinda de la marginea stanga pana la marginea dreapta?
A Left
B Center
C Justify
💡 Justify = aliniere completa pe ambele margini.
4

Spatiere

Recapitulare: Line Spacing: 1.0 (compact), 1.15 (implicit), 1.5 (referate), 2.0 (corectare). Paragraph Spacing: Before/After pentru spatiu intre paragrafe.

Scurtaturi: Ctrl+1 (spatiere 1.0), Ctrl+2 (spatiere 2.0), Ctrl+5 (spatiere 1.5).

Ce valoare de Line Spacing este recomandata pentru referate scolare?
A 1.0 (Single)
B 1.5
C 3.0
💡 1.5 ofera spatiu suficient pentru citire si eventuale corectii.
5

Liste

Recapitulare: Doua tipuri de liste: Bullets (marcatori, fara ordine) si Numbering (numerotate, cu ordine). Tab creeaza sub-niveluri, Shift+Tab revine la nivel.

Poti personaliza marcatorii si formatul numerotarii din meniul drop-down al butoanelor.

Ce tip de lista folosesti pentru instructiuni pas cu pas?
A Lista cu marcatori (bullets)
B Lista numerotata
C Ambele sunt la fel de potrivite
💡 Cand ordinea conteaza, foloseste numere.
6

Tabele - Inserare si Navigare

Recapitulare: Tabelele se insereaza din Insert > Table. Navigare: Tab (urmatoarea celula), Shift+Tab (celula anterioara), Enter (rand nou in celula).

Adaugi randuri/coloane din click dreapta > Insert sau din tab-ul Layout.

Ce se intampla daca apesi Tab in ultima celula a unui tabel?
A Se sterge tabelul
B Se creeaza un rand nou
C Nu se intampla nimic
💡 Tab in ultima celula = rand nou automat.
7

Tabele - Formatare

Recapitulare: Merge Cells uneste celule, Split Cells le divide. Tab-ul Table Design ofera stiluri predefinite, Shading si Borders.

AutoFit ajusteaza automat dimensiunile. Table Properties permite setari precise.

Ce optiune uneste mai multe celule intr-una singura?
A Split Cells
B Merge Cells
C Delete Cells
💡 Merge = a uni, a combina.
