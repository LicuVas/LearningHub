Obiectivul lectiei

"Dupa aceasta lectie vei sti sa calculezi suma si media aritmetica a elementelor dintr-un sir de numere!"

1

Ce este suma?

Suma elementelor unui sir este rezultatul adunarii tuturor valorilor din sir.

Exemplu: v = [5, 3, 8, 2]

[1]5
[2]3
[3]8
[4]2
Suma = 5 + 3 + 8 + 2
Suma = 18
Ce este suma elementelor unui sir?
A Primul element
B Totalul tuturor elementelor adunate
C Numarul de elemente
💡 Suma = adunarea tuturor valorilor.
2

Algoritmul pentru suma

Pentru a calcula suma, parcurgem sirul si adunam fiecare element:

suma = 0 // IMPORTANT: initializam cu 0
PENTRU i = 1, n EXECUTA
    suma = suma + v[i]
SFARSIT_PENTRU
SCRIE(suma)

Pas cu pas pentru v = [5, 3, 8, 2]:

Initial: suma = 0

i=1: suma = 0 + 5 = 5

i=2: suma = 5 + 3 = 8

i=3: suma = 8 + 8 = 16

i=4: suma = 16 + 2 = 18

Cu ce valoare initializam suma?
A 1
B 0
C Primul element
💡 0 este elementul neutru la adunare.
3

Ce este media aritmetica?

Media aritmetica este suma tuturor elementelor impartita la numarul de elemente.

Media = Suma / n

Exemplu: v = [5, 3, 8, 2] (n=4)

Suma = 18

Media = 18 / 4 = 4.5

Media ne arata valoarea "tipica" sau "de mijloc" din sir.

Ce este media aritmetica?
A Suma elementelor
B Suma impartita la numarul de elemente
C Elementul din mijloc
💡 Media = suma / n.
4

Algoritmul pentru media

Calculam intai suma, apoi impartim la n:

suma = 0
PENTRU i = 1, n EXECUTA
    suma = suma + v[i]
SFARSIT_PENTRU
media = suma / n // impartire reala
SCRIE(media)

⚠️ Atentie!

Folosim impartire reala (/) pentru a obtine rezultatul exact cu zecimale.

18 / 4 = 4.5 (corect)

18 DIV 4 = 4 (incorect - pierde zecimalele)

Ce tip de impartire folosim pentru media exacta?
A Impartire intreaga (DIV)
B Impartire reala (/)
C Nu conteaza
💡 Impartirea reala pastreaza zecimalele.
5

Suma cu conditie

Putem calcula suma doar pentru anumite elemente (de exemplu, numerele pare):

suma_pare = 0
PENTRU i = 1, n EXECUTA
    DACA v[i] MOD 2 = 0 ATUNCI
        suma_pare = suma_pare + v[i]
    SFARSIT_DACA
SFARSIT_PENTRU

v = [5, 8, 3, 12, 7]

Numere pare: 8, 12

Suma pare = 8 + 12 = 20

Pentru suma numerelor pare, ce conditie adaugam?
A v[i] > 0
B v[i] MOD 2 = 0
C i MOD 2 = 0
💡 Verificam daca elementul (v[i]) este par.
6

Media cu conditie

Pentru media elementelor care indeplinesc o conditie, trebuie sa numaram si cate sunt:

suma = 0
contor = 0
PENTRU i = 1, n EXECUTA
    DACA v[i] > 0 ATUNCI // pozitive
        suma = suma + v[i]
        contor = contor + 1
    SFARSIT_DACA
SFARSIT_PENTRU
DACA contor > 0 ATUNCI
    media = suma / contor
SFARSIT_DACA

⚠️ Verificam ca contor > 0 pentru a evita impartirea la 0!

La media cu conditie, impartim la:
A n (numarul total de elemente)
B contor (numarul de elemente care indeplinesc conditia)
C suma
💡 Impartim la cate elemente am adunat efectiv.
7

Exemplu practic: Media notelor

Sa calculam media notelor unui elev:

CITESTE n // cate note
suma = 0
PENTRU i = 1, n EXECUTA
    CITESTE nota[i]
    suma = suma + nota[i]
SFARSIT_PENTRU
media = suma / n
SCRIE("Media ta este: ", media)

Exemplu:

Note: 8, 9, 7, 10, 8

Suma = 42, n = 5

Media = 42 / 5 = 8.4
Care este formula pentru media notelor la scoala?
A suma_note * nr_note
B suma_note / nr_note
C suma_note - nr_note
💡 Media = suma impartita la numar.
