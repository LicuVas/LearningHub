Proiectul: Catalog de note

Vom crea un program care analizeaza notele unui elev la o materie si calculeaza:

📊 Cerinte proiect:
  • Citeste n note ale elevului
  • Calculeaza suma notelor
  • Calculeaza media aritmetica
  • Gaseste nota maxima si minima
  • Numara cate note sunt peste medie
  • Afiseaza daca elevul este promovat (media ≥ 5)
Ce facem prima data intr-un algoritm cu siruri?
A Calculam media
B Citim dimensiunea (n) si elementele
C Afisam rezultatele
💡 Intai citim datele, apoi le prelucram.
2

Pasul 1: Citirea datelor

Incepem prin a citi cate note are elevul si apoi fiecare nota:

SCRIE ("Cate note are elevul? ")
CITESTE n

SCRIE ("Introdu notele: ")
PENTRU i = 1 , n EXECUTA
CITESTE note [ i ]
SFARSIT_PENTRU

Exemplu: 5 note citite

[1] 8
[2] 6
[3] 9
[4] 7
[5] 10
Cand citim notele, ce structura folosim?
A DACA-ATUNCI
B FOR (bucla)
C Nu folosim nimic special
💡 FOR ne permite sa citim fiecare nota pe rand.
3

Pasul 2: Calculele principale

Calculam suma, maximul si minimul intr-o singura parcurgere (eficient!):

suma = 0
maxim = note [ 1 ]
minim = note [ 1 ]

PENTRU i = 1 , n EXECUTA
suma = suma + note [ i ]
DACA note [ i ] > maxim ATUNCI
maxim = note [ i ]
SFARSIT_DACA
DACA note [ i ] < minim ATUNCI
minim = note [ i ]
SFARSIT_DACA
SFARSIT_PENTRU
Putem calcula suma, maxim si minim in aceeasi parcurgere?
A Nu, trebuie parcurgeri separate
B Da, le calculam pe toate deodata
C Doar suma si media impreuna
💡 Eficient: facem totul intr-o singura parcurgere!
4

Pasul 3: Media si analiza

Calculam media si numaram notele peste medie:

media = suma / n

// Numaram notele peste medie
peste_medie = 0
PENTRU i = 1 , n EXECUTA
DACA note [ i ] > media ATUNCI
peste_medie = peste_medie + 1
SFARSIT_DACA
SFARSIT_PENTRU

Exemplu: note = [8, 6, 9, 7, 10], media = 8

Note peste medie: 9, 10 → 2 note

Pentru a numara notele peste medie, ce conditie verificam?
A note[i] > n
B note[i] > media
C note[i] > suma
💡 Comparam fiecare nota cu media calculata.
5

Pasul 4: Rezultatul final

Afisam toate rezultatele si verificam promovarea:

SCRIE ("===== REZULTATE =====")
SCRIE ("Suma notelor: ", suma )
SCRIE ("Media: ", media )
SCRIE ("Nota maxima: ", maxim )
SCRIE ("Nota minima: ", minim )
SCRIE ("Note peste medie: ", peste_medie )

DACA media >= 5 ATUNCI
SCRIE ("Elevul este PROMOVAT!")
ALTFEL
SCRIE ("Elevul este NEPROMOVAT.")
SFARSIT_DACA
Ce conditie verifica daca elevul este promovat?
A media > 10
B media >= 5
C media = 5
💡 Promovat inseamna media cel putin 5.

Exemplu complet

Sa vedem rezultatele pentru un set de note:

Note introduse: 8, 6, 9, 7, 10

[1] 8
[2] 6
[3] 9
[4] 7
[5] 10

Suma: 40

Media: 8.0

Nota minima: 6 (rosu)

A Suma=40, Media=8, Max=10, Min=6
B Suma=35, Media=7, Max=9, Min=6
C Suma=40, Media=10, Max=10, Min=8

Validarea datelor de intrare

Un program profesional nu presupune ca utilizatorul va introduce mereu date corecte. Ce se intampla daca cineva introduce o nota de 15 sau de -3? Sau daca scrie o litera in loc de un numar? Programul trebuie sa verifice ca datele sunt valide inainte de a le prelucra. Aceasta etapa se numeste validarea datelor de intrare si este esentiala in orice aplicatie reala.

Pentru catalogul nostru de note, o nota valida trebuie sa fie un numar intreg intre 1 si 10 (in sistemul romanesc de notare). Daca utilizatorul introduce o valoare in afara acestui interval, programul trebuie sa il avertizeze si sa ceara reintroducerea notei. Acest lucru se face cu o bucla do-while care repeta citirea pana cand valoarea este corecta.

PENTRU i = 1 , n EXECUTA
REPETA
SCRIE ("Nota ", i , ": ")
CITESTE nota
DACA nota < 1 SAU nota > 10 ATUNCI
SCRIE ("Nota invalida! Introduceti 1-10.")
SFARSIT_DACA
PANA_CAND nota >= 1 SI nota <= 10
note [ i ] = nota
SFARSIT_PENTRU

Observa cum bucla REPETA...PANA_CAND (echivalentul do-while din C++) garanteaza ca nota este citita cel putin o data, dar se repeta daca valoarea nu este in intervalul 1-10. Aceasta tehnica de validare este folosita in toate aplicatiile profesionale: formulare web, aplicatii bancare, jocuri. Fara validare, un elev ar putea introduce nota 100 si ar obtine o medie de 25, ceea ce evident nu are sens.

De ce validam datele de intrare intr-un program?
A Pentru ca programul sa arate mai bine
B Pentru a preveni erori si rezultate incorecte
C Nu este necesar sa validam datele
💡 Datele invalide cauzeaza rezultate gresite sau chiar blocarea programului.

Sortarea notelor (bonus)

Dupa ce am calculat suma, media, maximul si minimul, ar fi util sa afisam notele ordonate de la cea mai mica la cea mai mare. Acest proces se numeste sortare si este unul dintre cei mai importanti algoritmi din informatica. Exista multe metode de sortare, dar cea mai simpla de inteles este sortarea prin selectie (selection sort).

Algoritmul functioneaza astfel: parcurgem sirul si gasim elementul minim. Il punem pe prima pozitie (interschimbam cu elementul de pe pozitia 1). Apoi cautam minimul din restul sirului (pozitiile 2 la n) si il punem pe pozitia 2. Repetam pana cand tot sirul este sortat. Este ca si cum ai aranja cartile dintr-un joc: cauti mereu cea mai mica carte si o pui in ordine.

// Sortare prin selectie
PENTRU i = 1 , n - 1 EXECUTA
poz_min = i
PENTRU j = i + 1 , n EXECUTA
DACA note [ j ] < note [ poz_min ] ATUNCI
poz_min = j
SFARSIT_DACA
SFARSIT_PENTRU
// Interschimba note[i] cu note[poz_min]
aux = note [ i ]
note [ i ] = note [ poz_min ]
note [ poz_min ] = aux
SFARSIT_PENTRU

Exemplu: sortarea [8, 6, 9, 7, 10]

Pas 1: minim = 6 (poz 2) -> interschimba cu poz 1 -> [ 6 , 8, 9, 7, 10]

Pas 2: minim = 7 (poz 4) -> interschimba cu poz 2 -> [6, 7 , 9, 8, 10]

Pas 3: minim = 8 (poz 4) -> interschimba cu poz 3 -> [6, 7, 8 , 9, 10]

Pas 4: minim = 9 (poz 4) -> deja pe pozitie -> [6, 7, 8, 9 , 10]

Interschimbarea a doua variabile necesita o variabila auxiliara ( aux ). Fara ea, am pierde una dintre valori. Gandeste-te la doua pahare cu lichide diferite: ai nevoie de un al treilea pahar gol ca sa le interschimbi continuturile. Aceasta este o intrebare clasica la examenele de informatica.

In sortarea prin selectie, ce cautam la fiecare pas?
A Elementul cel mai mare din tot sirul
B Elementul minim din portiunea nesortata
C Un element aleatoriu
💡 La fiecare pas cautam minimul din zona care nu a fost inca sortata.

Numararea aparitiilor

O alta operatie utila cu siruri este numararea aparitiilor : de cate ori apare o anumita valoare in sir? De exemplu, de cate ori a luat elevul nota 10? Sau cate note de 5 (limita de promovare) are? Acest tip de analiza ofera informatii valoroase despre distributia notelor.

Algoritmul este simplu: initializam un contor cu 0, parcurgem sirul cu FOR, si de fiecare data cand gasim valoarea cautata, incrementam contorul. La final, contorul contine numarul de aparitii. Putem extinde ideea si numara cate note sunt intr-un anumit interval (de exemplu, cate note de 9 si 10 are elevul).

nr_zece = 0
nr_sub5 = 0
PENTRU i = 1 , n EXECUTA
DACA note [ i ] == 10 ATUNCI
nr_zece = nr_zece + 1
SFARSIT_DACA
DACA note [ i ] < 5 ATUNCI
nr_sub5 = nr_sub5 + 1
SFARSIT_DACA
SFARSIT_PENTRU

SCRIE ("Note de 10: ", nr_zece )
SCRIE ("Note sub 5: ", nr_sub5 )

Putem numara mai multe categorii simultan in aceeasi parcurgere - nu trebuie sa parcurgem sirul de mai multe ori. Acest lucru face programul mai eficient : o singura trecere prin date in loc de trei sau patru treceri separate. In programarea profesionala, eficienta este importanta cand lucram cu cantitati mari de date (mii sau milioane de elemente).

Exemplu: note = [8, 10, 6, 10, 9, 4, 10, 7]

Note de 10: 3 (pozitiile 2, 4 si 7)

Note sub 5: 1 (pozitia 6, nota 4)

Cum numaram de cate ori apare nota 10 in sir?
A Folosim maxim
B Parcurgem sirul si comparam fiecare element cu 10
C Nu se poate calcula
💡 Parcurgem sirul cu FOR si incrementam un contor cand gasim nota 10.

Exercitii practice

Exercitiul 1 (Nivel minim) - Analiza pas cu pas

Cerinta: Pentru sirul v = [15, 22, 8, 30, 12, 25, 18], executa manual algoritmii invatati si raspunde la intrebarile de mai jos. Arata fiecare pas al calculului, nu doar rezultatul final.

  1. Calculeaza suma elementelor pas cu pas: 15 + 22 = ?, apoi + 8 = ?, ... Scrie toate adunarea intermediare.
  2. Calculeaza media aritmetica. Rotunjeste la doua zecimale.
  3. Gaseste maximul si minimul. La ce pozitie (index) se afla fiecare?
  4. Cate elemente sunt mai mari decat media? Care sunt acele elemente?
  5. Daca aplicam sortarea prin selectie, care este sirul dupa primii 2 pasi? Arata interschimbarile.

Raspunde numerotat: 1. ... 2. ... 3. ... 4. ... 5. ...

Indicii:

  • Sirul are 7 elemente, deci media = suma / 7
  • Pentru sortare prin selectie: la pasul 1 cauti minimul din tot sirul si il interschimbi cu pozitia 1
  • La pasul 2 cauti minimul din pozitiile 2-7 si il interschimbi cu pozitia 2

Exercitiul 2 (Nivel standard) - Mini-proiect: Analizator de temperaturi

Adapteaza proiectul "Catalog de note" pentru a analiza temperaturile unei saptamani. Programul trebuie sa citeasca 7 temperaturi (cate una pentru fiecare zi: Luni, Marti, ..., Duminica) si sa ofere o analiza completa.

Cerinte obligatorii:

⭐ Bonus (pentru nota maxima):

  • Calculeaza amplitudinea termica (max - min) si interpreteaz-o
  • Afiseaza in ce zi a fost cel mai cald si cel mai frig (Luni/Marti/.../Duminica)
  • Sorteaza temperaturile crescator si afiseaza sirul ordonat
  • Afiseaza un grafic simplu cu asteriscuri (*) pentru fiecare temperatura

Criterii de evaluare:

  • Suficient (5-6): Citeste temperaturi, calculeaza media, gaseste max si min
  • Bine (7-8): Toate cerintele obligatorii implementate corect
  • Foarte bine (9-10): Include cel putin 2 bonusuri, validare date, cod comentat

Exercitiul 3 (Nivel performanta) - Compunere

Cerinta: Scrie un text de 10-15 randuri cu titlul "Algoritmii cu siruri in viata de zi cu zi". Explica ce sunt sirurile de date, de ce sunt importante si da cel putin 3 exemple concrete din viata reala unde se folosesc algoritmi cu siruri (note scolare, temperaturi meteo, preturi produse, scoruri sportive etc.).

Indicii pentru structurarea raspunsului:

  • Incepe prin a defini ce este un sir de date si de ce avem nevoie de el (o colectie ordonata de valori de acelasi tip)
  • Explica principalele operatii: citire, parcurgere, suma, media, maxim, minim, numarare, sortare
  • Da 3 exemple concrete din viata reala:
    • Aplicatie meteo: temperaturile pe 7 zile -> media, maxim, minim, tendinta
    • Magazin online: preturile produselor -> sortare crescator/descrescator, cel mai ieftin, medie de pret
    • Clasament sportiv: punctajele echipelor -> sortare, lider, diferente
  • Incheie cu o concluzie despre cum algoritmii cu siruri stau la baza multor aplicatii pe care le folosim zilnic

Cuvinte cheie de folosit: sir, element, index, parcurgere, suma, media, maxim, minim, sortare, contor, validare, eficient

Format: Scrie raspunsul pe foaie sau intr-un document Word, folosind paragrafe coerente (nu liste). Minim 10 randuri.
