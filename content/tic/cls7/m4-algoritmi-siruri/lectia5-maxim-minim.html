Maxim si minim - Gasim extremele!

Citeste fiecare concept, apoi raspunde la intrebari pentru a continua

Progres lectie:
0%
🎯

Obiectivul lectiei

"Dupa aceasta lectie vei sti sa gasesti valoarea maxima si minima dintr-un sir, precum si pozitia lor!"

1

Ce sunt maximul si minimul?

Maximul este cea mai mare valoare din sir.

Minimul este cea mai mica valoare din sir.

Exemplu: v = [7, 3, 12, 5, 9]

[1]7
[2]3
[3]12
[4]5
[5]9

Maxim = 12 | Minim = 3

Ce este maximul unui sir?
A Prima valoare
B Cea mai mare valoare
C Ultima valoare
💡 Maximul = valoarea cea mai mare din sir.
2

Strategia pentru gasirea maximului

Strategia este simpla:

  1. Presupunem ca primul element este maximul
  2. Parcurgem restul sirului
  3. Daca gasim un element mai mare, acela devine noul maxim

Ca in viata reala:

Imagineaza-ti ca cauti cel mai inalt elev din clasa. Incepi cu primul, apoi compari pe rand cu fiecare. Daca gasesti pe cineva mai inalt, acela devine "cel mai inalt" pana acum.

Cu ce initializam variabila maxim?
A Cu 0
B Cu primul element v[1]
C Cu ultimul element
💡 Presupunem initial ca primul element este maximul.
3

Algoritmul pentru maxim

maxim = v[1] // presupunem ca primul e maxim
PENTRU i = 2, n EXECUTA
    DACA v[i] > maxim ATUNCI
        maxim = v[i]
    SFARSIT_DACA
SFARSIT_PENTRU
SCRIE(maxim)

Pas cu pas pentru v = [7, 3, 12, 5]:

Initial: maxim = 7

i=2: 3 > 7? NU - maxim ramane 7

i=3: 12 > 7? DA - maxim = 12

i=4: 5 > 12? NU - maxim ramane 12

Maxim = 12
Cand actualizam maximul?
A Cand v[i] < maxim
B Cand v[i] > maxim
C La fiecare pas
💡 Actualizam doar daca gasim o valoare mai mare.
4

Algoritmul pentru minim

Pentru minim, schimbam doar conditia (folosim < in loc de >):

minim = v[1] // presupunem ca primul e minim
PENTRU i = 2, n EXECUTA
    DACA v[i] < minim ATUNCI
        minim = v[i]
    SFARSIT_DACA
SFARSIT_PENTRU
SCRIE(minim)

Pas cu pas pentru v = [7, 3, 12, 5]:

Initial: minim = 7

i=2: 3 < 7? DA - minim = 3

i=3: 12 < 3? NU

i=4: 5 < 3? NU

Minim = 3
Pentru minim, ce conditie folosim?
A v[i] > minim
B v[i] < minim
C v[i] = minim
💡 Cautam valori mai mici decat minimul curent.
5

Gasirea pozitiei maximului

Uneori vrem sa stim si unde se afla maximul, nu doar valoarea:

maxim = v[1]
poz_max = 1 // pozitia maximului
PENTRU i = 2, n EXECUTA
    DACA v[i] > maxim ATUNCI
        maxim = v[i]
        poz_max = i // retinem pozitia
    SFARSIT_DACA
SFARSIT_PENTRU
SCRIE("Maxim: ", maxim, " pe pozitia ", poz_max)

v = [7, 3, 12, 5]

Maxim = 12, Pozitia = 3

Ce variabila folosim pentru a retine pozitia maximului?
A maxim
B poz_max
C v[i]
💡 Avem nevoie de o variabila separata pentru pozitie.
6

Maxim si minim simultan

Putem gasi ambele valori intr-o singura parcurgere:

maxim = v[1]
minim = v[1]
PENTRU i = 2, n EXECUTA
    DACA v[i] > maxim ATUNCI
        maxim = v[i]
    SFARSIT_DACA
    DACA v[i] < minim ATUNCI
        minim = v[i]
    SFARSIT_DACA
SFARSIT_PENTRU

Eficient: o singura parcurgere pentru ambele!

Este posibil sa gasim maxim si minim in aceeasi parcurgere?
A Nu, trebuie 2 parcurgeri
B Da, cu 2 conditii in acelasi FOR
C Nu se poate niciodata
💡 Putem verifica ambele conditii la fiecare pas.
7

Aplicatie: Amplitudinea

Amplitudinea = diferenta dintre maxim si minim. Ne arata cat de "raspandite" sunt valorile.

// Dupa ce am gasit maxim si minim
amplitudine = maxim - minim
SCRIE("Amplitudinea: ", amplitudine)

Exemplu: Note elev

Note: [7, 9, 5, 10, 6]

Maxim = 10, Minim = 5

Amplitudine = 10 - 5 = 5

Notele variaza cu 5 puncte.

Ce aflam cu formula maxim - minim?
A Media
B Amplitudinea (diferenta intre extreme)
C Suma
💡 Diferenta dintre maxim si minim se numeste amplitudine.
