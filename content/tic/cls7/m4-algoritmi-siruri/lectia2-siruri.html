Siruri de numere - Colectii organizate!

Obiectivul lectiei

"Dupa aceasta lectie vei intelege ce este un sir de numere, cum se stocheaza in memorie si cum accesezi elementele folosind indecsi!"

1

Ce este un sir?

Un sir (sau vector/tablou) este o colectie de mai multe valori de acelasi tip, stocate impreuna sub un singur nume.

Imagineaza-ti un tren cu vagoane numerotate. Fiecare vagon poate contine o valoare, iar trenul intreg are un nume.

Exemplu: Sirul "note" cu 5 elemente

[1]8
[2]9
[3]7
[4]10
[5]8
Ce este un sir de numere?
A O singura variabila cu o valoare
B O colectie ordonata de mai multe valori
C O formula matematica
💡 Sirul este ca un tren cu vagoane - fiecare vagon contine o valoare.
2

Indexul - Adresa elementului

Fiecare element din sir are o pozitie numita index. Indexul ne ajuta sa gasim exact elementul dorit.

Este ca numarul apartamentului intr-un bloc - spui "apartamentul 3" si stii exact unde sa mergi.

Sir cu indexi de la 1 la 5:

index 115
index 223
index 37
index 442
index 511

Elementul de la indexul 2 are valoarea 23

Ce este un index intr-un sir?
A Valoarea stocata in sir
B Numarul de ordine al elementului
C Numele sirului
💡 Indexul este ca numarul apartamentului intr-un bloc.
3

Notatia elementelor

Pentru a accesa un element din sir, scriem numele sirului urmat de index in paranteze drepte:

v[1] // primul element din sirul v
v[3] // al treilea element
v[i] // elementul de pe pozitia i

Daca v = [10, 20, 30, 40, 50], atunci:

v[1] = 10, v[2] = 20, v[3] = 30, v[4] = 40, v[5] = 50

Cum scriem elementul de pe pozitia 3 din sirul v?
A v3
B v[3]
C v(3)
💡 Folosim paranteze drepte pentru a indica indexul.
4

Declararea sirului

Cand cream un sir, trebuie sa specificam cate elemente va avea:

CITESTE n // cate elemente are sirul
// Acum sirul are n pozitii disponibile
// de la v[1] pana la v[n]

Variabila n reprezinta dimensiunea sirului - numarul total de elemente pe care le poate stoca.

Daca n = 4, sirul are 4 pozitii:

[1]?
[2]?
[3]?
[4]?
Ce reprezinta n in declaratia unui sir cu n elemente?
A Primul element
B Dimensiunea (numarul de elemente)
C Ultimul element
💡 n ne spune cate elemente poate contine sirul.
5

Citirea elementelor

Pentru a citi valorile intr-un sir, folosim o bucla FOR:

CITESTE n // numarul de elemente
PENTRU i = 1, n EXECUTA
    CITESTE v[i]
SFARSIT_PENTRU

La fiecare pas, citim valoarea si o punem in pozitia curenta v[i].

Exemplu: Citim 3 numere: 5, 8, 12

i=1: citim 5 → v[1]=5

i=2: citim 8 → v[2]=8

i=3: citim 12 → v[3]=12

Cum citim elementele unui sir de n numere?
A Citim toate deodata
B Folosim FOR pentru a citi pe rand
C Nu se pot citi
💡 FOR ne ajuta sa citim fiecare element pe rand.
6

Modificarea elementelor

Putem modifica orice element din sir folosind indexul sau:

v[2] = 100 // schimbam elementul de pe pozitia 2
v[3] = v[1] + v[2] // v[3] devine suma primelor doua

Inainte: v = [10, 20, 30]

Dupa v[2] = 100: v = [10, 100, 30]

[1]10
[2]100
[3]30
Ce se intampla dupa v[2] = 100?
A Tot sirul devine 100
B Doar elementul de pe pozitia 2 devine 100
C Sirul este sters
💡 Modificam doar pozitia specificata, restul raman neschimbate.
7

De ce folosim siruri?

Avantajele sirurilor:

  • Organizare: Multe date sub un singur nume
  • Acces rapid: Gasim orice element instant prin index
  • Prelucrare usoara: Folosim FOR pentru a procesa toate elementele

Fara sir: nota1, nota2, nota3, nota4... (100 de variabile!)

Cu sir: note[1], note[2], ... note[100] (un singur sir!)

Sirurile sunt esentiale pentru a lucra cu liste de date: note, temperaturi, preturi, etc.

Care este avantajul principal al folosirii sirurilor?
A Ocupa mai putina memorie
B Organizeaza mai multe date sub un singur nume
C Sunt mai rapide de scris
💡 In loc de 100 de variabile separate, avem un singur sir.
