1. Functia SUM - Adunarea rapida

SUM aduna toate valorile dintr-un interval de celule. In loc sa scrii =A1+A2+A3+A4+A5, scrii simplu =SUM(A1:A5).

Functia ignora celulele goale si celulele cu text - aduna doar numerele.

🎯 Analogie: Telecomanda vs. Manual

Imagineaza-ti ca ai 100 de becuri de aprins. Fara SUM, apesi fiecare intrerupator individual (=A1+A2+A3+...+A100). Cu SUM, apesi un singur buton pe telecomanda si le aprinzi pe toate odata: =SUM(A1:A100). Acelasi rezultat, de 100 de ori mai rapid!

Sintaxa SUM
Forma de baza: =SUM(interval) Exemple: =SUM(A1:A10) Aduna A1 pana la A10 =SUM(A1:A5, C1:C5) Aduna DOUA intervale! =SUM(A1:D1) Aduna pe orizontala (un rand) =SUM(B2:D2)/3 Suma impartita la 3 = media

Visual: SUM in action

Vizualizare: SUM cu intervale multiple
ABCD
1 10 text 30
2 20 abc 40
3 30 50 =SUM(A1:A3, C1:C3)
4 SUM ignora textul si celulele goale 180
=SUM(A1:A3, C1:C3) → (10+20+30) + (30+40+50) = 60 + 120 = 180
💡 SUM cu mai multe intervale

Poti aduna pana la 255 de intervale separate prin virgula: =SUM(A1:A5, C1:C5, E1:E5). Util cand datele nu sunt in coloane consecutive!

2. Familia COUNT - Numararea celulelor

Excel are trei functii diferite pentru numarare. Fiecare numara altceva:

COUNT

Numara doar celulele care contin numere.

=COUNT(A1:A10)
COUNTA

Numara celulele care contin orice (numere, text, formule). Nu numara celulele goale.

=COUNTA(A1:A10)
COUNTBLANK

Numara doar celulele goale (fara niciun continut).

=COUNTBLANK(A1:A10)
🎓 Analogie: Diriginta face prezenta

COUNT = numara cati elevi au nota in catalog (doar cifre). COUNTA = numara toti elevii care au ceva scris in dreptul lor (si scutiri, si note, si "absent"). COUNTBLANK = numara cate locuri sunt necompletate (elevii fara nimic in dreptul lor).

Visual: COUNT comparison

Exemplu: Acelasi interval, trei rezultate diferite
ACe contine
1 10 numar
2 Ana text
3 (gol) gol
4 25 numar
5 OK text
Formula Rezultat De ce?
=COUNT(A1:A5) 2 Doar numerele: 10 si 25 (textul si golul nu se numara)
=COUNTA(A1:A5) 4 Orice non-gol: 10, "Ana", 25, "OK" (doar golul nu se numara)
=COUNTBLANK(A1:A5) 1 Doar celula goala: A3
Observa: COUNT(2) + COUNTBLANK(1) ≠ COUNTA(4). Dar COUNTA(4) + COUNTBLANK(1) = 5 (total celule)!
⚠ Greseala frecventa: COUNT vs COUNTA

Multi elevi folosesc COUNT cand vor sa numere "cate celule au ceva" - dar COUNT numara doar numere! Daca vrei sa numeri toate celulele care nu sunt goale (inclusiv cele cu text), foloseste COUNTA.

3. Functia IF - "Daca... atunci... altfel..."

Functia IF este cea mai importanta functie de decizie din Excel. Ea verifica o conditie si face lucruri diferite in functie de rezultat:

• Daca conditia este adevarata (TRUE) → face un lucru

• Daca conditia este falsa (FALSE) → face altceva

Sintaxa IF
=IF(test_logic, valoare_daca_da, valoare_daca_nu) Cele 3 parti ale IF-ului: 1. test_logic = conditia de verificat (ex: E2>=5) 2. valoare_daca_da = ce afiseaza daca conditia e ADEVARATA 3. valoare_daca_nu = ce afiseaza daca conditia e FALSA Exemplu simplu: =IF(E2>=5, "Promovat", "Nepromovat") E2>=5 → verifica daca media e cel putin 5 "Promovat" → daca DA, afiseaza acest text "Nepromovat" → daca NU, afiseaza acest text
🎲 Analogie: Jocul video

IF este ca un checkpoint in joc. Jocul verifica: "Ai destule puncte?" Daca DA, treci la nivelul urmator. Daca NU, te trimite inapoi. Excel face exact la fel cu datele tale: verifica o conditie si ia o decizie automata.

IF flow diagram

4. IF in IF - Cand ai mai mult de 2 optiuni

Un IF simplu are doar 2 rezultate posibile: DA sau NU. Dar ce faci cand ai 3, 4 sau mai multe categorii?

Solutia: pui un alt IF in locul rezultatului "NU". Asa creezi o "cascada" de verificari.

🎫 Analogie: Sistemul de note la scoala

E ca si cum profesorul ar evalua asa: "Media e peste 9? Atunci Excelent. Nu? OK, e peste 7? Atunci Bine. Nu? E peste 5? Atunci Suficient. Nu? Atunci Insuficient." Fiecare "Nu?" deschide o noua intrebare - exact ca un IF imbricat!

IF imbricat - pas cu pas
IF simplu (2 optiuni): =IF(E2>=5, "Promovat", "Nepromovat") IF imbricat (3 optiuni): =IF(E2>=9, "Excelent", IF(E2>=5, "Promovat", "Nepromovat")) IF imbricat (4 optiuni): =IF(E2>=9, "Excelent", IF(E2>=7, "Bine", IF(E2>=5, "Suficient", "Insuficient"))) Structura vizuala: =IF(E2>=9, ← Prima verificare "Excelent", ← Daca DA IF(E2>=7, ← Daca NU, verifica asta "Bine", ← Daca DA IF(E2>=5, ← Daca NU, verifica asta "Suficient", ← Daca DA "Insuficient" ← Daca NU (ultimul) ) ← Inchide IF-ul 3 ) ← Inchide IF-ul 2 ) ← Inchide IF-ul 1

Trace: Nested IF evaluation

Vizualizare: Cum evalueaza Excel un IF imbricat (E2 = 7.5)
E2 = 7.5
↓
Pasul 1: E2 >= 9? → 7.5 >= 9? → FALSE
↓
Pasul 2: E2 >= 7? → 7.5 >= 7? → TRUE
↓
Rezultat: "Bine"
Excel verifica conditiile de sus in jos. La prima conditie TRUE, se opreste si afiseaza rezultatul.

Another trace with different value

Vizualizare: IF imbricat cu E2 = 4.0
E2 = 4.0
↓
Pasul 1: 4.0 >= 9? → FALSE (trece mai departe)
↓
Pasul 2: 4.0 >= 7? → FALSE (trece mai departe)
↓
Pasul 3: 4.0 >= 5? → FALSE (trece la ultimul)
↓
Rezultat: "Insuficient" (ultima optiune)
Nicio conditie nu a fost TRUE, deci se afiseaza ultimul argument: "Insuficient"
🔴 Regula de aur la IF imbricat: Ordinea conteaza!

Verifica mereu de la cea mai mare valoare la cea mai mica. Daca inversi ordinea, rezultatele vor fi gresite!

Gresit ❌ Corect ✅
=IF(E2>=5, "Suficient", IF(E2>=7, "Bine", ...)) =IF(E2>=9, "Excelent", IF(E2>=7, "Bine", ...))
Un elev cu 9.5 ar primi "Suficient" (pentru ca 9.5>=5 e TRUE, deci se opreste acolo!) Un elev cu 9.5 primeste "Excelent" (prima verificare corecta)
💡 Trucul parantezelor la IF imbricat

Cate IF-uri ai, atatea paranteze ) trebuie sa ai la sfarsit:

  • 1 IF → 1 paranteza la sfarsit: =IF(...)
  • 2 IF-uri → 2 paranteze: =IF(..., IF(..., ...))
  • 3 IF-uri → 3 paranteze: =IF(..., IF(..., IF(..., ...)))

Exercitii practice

Exercitiul 1 (Nivel minim) - Catalogul clasei tale (Creativ)

Cerinta: Creeaza in Excel sau Google Sheets un catalog complet cu minim 8 elevi (poti folosi nume fictive). Fiecare elev trebuie sa aiba:

  1. 3 note la materii diferite (Matematica, Romana, Engleza) in coloanele B, C, D
  2. Formula pentru media in coloana E folosind =SUM(B2:D2)/COUNT(B2:D2)
  3. Formula IF imbricata in coloana F cu 4 statusuri: Excelent (>=9), Bine (>=7), Suficient (>=5), Insuficient (<5)
  4. O sectiune de statistici: total note introduse (COUNT), suma notelor (SUM), cate celule goale (COUNTBLANK)
  5. Adauga un elev cu o nota lipsa (celula goala) si verifica daca formulele functioneaza corect

Indicii:

  • Incepe cu antetul tabelului in randul 1: Nume | Mat | Rom | Eng | Media | Status
  • Scrie formula doar in randul 2, apoi copiaz-o cu drag (trage de coltul celulei) in jos
  • Testeaza cu note extreme: 10, 10, 10 (Excelent?) si 2, 3, 1 (Insuficient?)

Trimite un screenshot cu tabelul completat sau descrie formulele folosite.

Exercitiul 2 (Nivel standard) - Sistemul de burse (Practic)

Cerinta: Construieste un tabel care decide automat ce bursa primeste fiecare elev:

Reguli burse:

Media >= 9.50 → "Bursa de merit" (100 lei)
Media >= 8.00 → "Bursa de studiu" (70 lei)
Media >= 5.00 → "Fara bursa" (0 lei)
Media < 5.00 → "Corigent" (0 lei)

Pasi:

  1. Creeaza tabelul cu coloanele: Nume | Nota1 | Nota2 | Nota3 | Media | Tip Bursa | Suma Bursa
  2. Coloana Media: =SUM(B2:D2)/COUNT(B2:D2)
  3. Coloana Tip Bursa: formula IF imbricata cu cele 4 categorii de mai sus
  4. Coloana Suma Bursa: o alta formula IF imbricata care returneaza 100, 70 sau 0
  5. La final, calculeaza =SUM(G2:G9) pentru totalul de burse platite
  6. Calculeaza =COUNT(G2:G9) - de ce acest numar nu e egal cu numarul de elevi?

Indicii:

  • Formula Tip Bursa: =IF(E2>=9.5, "Bursa de merit", IF(E2>=8, "Bursa de studiu", IF(E2>=5, "Fara bursa", "Corigent")))
  • Formula Suma Bursa: =IF(E2>=9.5, 100, IF(E2>=8, 70, 0))
  • COUNT(G2:G9) nu e egal cu numarul de elevi daca unele celule cu Suma au valoarea 0 - COUNT numara si 0 ca numar!

Exercitiul 3 (Nivel performanta) - Analiza comparativa (Analitic)

Cerinta: Compara si explica diferentele intre urmatoarele formule. Pentru fiecare pereche, da un exemplu concret in care dau rezultate diferite si explica DE CE.

  1. =SUM(B2:D2)/3 vs =SUM(B2:D2)/COUNT(B2:D2) - Cand dau rezultate diferite? Care este mai sigura?
  2. =COUNT(A1:A10) vs =COUNTA(A1:A10) - Daca intervalul contine 5 numere, 3 texte si 2 celule goale, ce returneaza fiecare?
  3. =IF(E2>=5, "Suficient", IF(E2>=7, "Bine", "Excelent")) vs =IF(E2>=9, "Excelent", IF(E2>=7, "Bine", IF(E2>=5, "Suficient", "Insuficient"))) - Ce rezultat da prima formula pentru un elev cu media 9.5? De ce este gresita?

Indicii:

  • Gandeste-te la cazul in care o celula din B2:D2 este goala
  • COUNT numara doar numere, COUNTA numara orice continut non-gol
  • In IF-ul imbricat, ordinea conditiilor conteaza enorm - testeaza cu mai multe valori

Cuvinte cheie de folosit: SUM, COUNT, COUNTA, COUNTBLANK, IF, IF imbricat, conditie, TRUE, FALSE, interval, celula goala, ordine
