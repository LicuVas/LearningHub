1

Ce sunt functiile logice?

Functiile logice permit Excel sa ia decizii automate pe baza unor conditii. O conditie poate fi doar TRUE (Adevarat) sau FALSE (Fals).

Exemple de conditii:

- Nota este mai mare sau egala cu 5? (A1>=5)

- Cantitatea este 0? (B1=0)

- Pretul depaseste bugetul? (C1>D1)

A1>=5 -> TRUE daca nota e de trecere
B1=0 -> TRUE daca stocul e gol
Ce tip de rezultat poate avea o conditie logica?
A Orice numar
B TRUE sau FALSE
C Doar text
💡 Gandeste-te la raspunsul unei intrebari de tip DA/NU.
2

Functia IF (Daca)

Functia IF este cea mai importanta functie logica. Verifica o conditie si returneaza o valoare daca e TRUE si alta daca e FALSE.

Sintaxa: =IF(conditie, valoare_daca_true, valoare_daca_false)

=IF(A1>=5, "Admis", "Respins")
Daca nota >= 5, afiseaza "Admis"
Altfel, afiseaza "Respins"

Citeste asa: DACA conditia este adevarata, ATUNCI fa asta, ALTFEL fa asta.

Care este sintaxa corecta pentru functia IF?
A =IF(conditie; da; nu)
B =IF(conditie, valoare_true, valoare_false)
C =IF(da, nu, conditie)
💡 IF are 3 argumente: conditia, ce se intampla daca e TRUE, ce se intampla daca e FALSE.
3

Functia AND (Si)

Functia AND verifica daca TOATE conditiile sunt adevarate. Returneaza TRUE doar daca fiecare conditie este TRUE.

Sintaxa: =AND(conditie1, conditie2, ...)

=AND(A1>=5, B1>=5)
TRUE doar daca AMBELE note sunt >= 5

=IF(AND(A1>=5, B1>=5), "Promovat", "Nepromovat")

Exemplu real: Elevul e promovat daca nota la romana SI nota la matematica sunt >= 5.

Cand returneaza AND rezultatul TRUE?
A Cand cel putin o conditie e TRUE
B Cand TOATE conditiile sunt TRUE
C Cand prima conditie e TRUE
💡 AND = SI - toate trebuie sa fie adevarate.
4

Functia OR (Sau)

Functia OR verifica daca CEL PUTIN UNA dintre conditii este adevarata. Returneaza TRUE daca macar o conditie este TRUE.

Sintaxa: =OR(conditie1, conditie2, ...)

=OR(A1="Director", A1="Manager")
TRUE daca persoana e Director SAU Manager

=IF(OR(B1=0, C1<10), "Comanda", "OK")

Exemplu real: Trimite alerta daca stocul e 0 SAU sub nivelul minim.

Cand returneaza OR rezultatul TRUE?
A Cand cel putin o conditie e TRUE
B Cand TOATE conditiile sunt TRUE
C Cand nicio conditie nu e TRUE
💡 OR = SAU - e suficient ca una sa fie adevarata.
5

IF-uri Imbricate (Nested IF)

Un IF imbricat este un IF in interiorul altui IF. Se foloseste cand ai mai mult de 2 rezultate posibile.

Exemplu: Calificativ pe baza notei:

=IF(A1>=9, "Foarte Bine",
IF(A1>=7, "Bine",
IF(A1>=5, "Satisfacator", "Nesatisfacator")))

Nota 10 -> Foarte Bine
Nota 8 -> Bine
Nota 6 -> Satisfacator
Nota 3 -> Nesatisfacator

Atentie: Verifica conditiile de la cea mai restrictiva la cea mai permisiva!

Ce inseamna un IF imbricat (nested IF)?
A Un IF cu multe conditii AND
B Un IF in interiorul altui IF
C Un IF care returneaza numere
💡 Imbricat = unul in interiorul altuia, ca papusile rusesti.
6

Exemplu Practic: Calcul Comision

Situatie: Vanzatorii primesc comision diferit in functie de vanzari:

- Vanzari >= 10.000 lei: comision 10%

- Vanzari < 10.000 lei: comision 5%

=IF(A1>=10000, A1*0.1, A1*0.05)

Vanzari 15.000 -> Comision 1.500 lei (10%)
Vanzari 8.000 -> Comision 400 lei (5%)

Varianta cu 3 niveluri:

=IF(A1>=20000, A1*0.15,
IF(A1>=10000, A1*0.1, A1*0.05))
Ce formula calculeaza comisionul: 10% daca vanzari>=10000, altfel 5%?
A =IF(A1>=10000, A1*10%, A1*5%)
B =IF(A1>=10000, A1*0.1, A1*0.05)
C Ambele sunt corecte
💡 10% = 0.1 si 10% sunt echivalente in Excel.
7

Combinarea IF cu AND/OR

Puterea reala vine din combinarea functiilor! IF decide ce sa faca, AND/OR definesc conditiile complexe.

Exemplu: Promovare elev

Conditii: Media >= 5 SI Absente < 20

=IF(AND(A1>=5, B1<20), "Promovat", "Nepromovat")

Media 7, Absente 15 -> Promovat
Media 7, Absente 25 -> Nepromovat (prea multe absente)
Media 4, Absente 10 -> Nepromovat (media mica)

Cu OR: Alerta daca media<5 SAU absente>=20

=IF(OR(A1<5, B1>=20), "ATENTIE!", "OK")
Un elev e promovat daca: media>=5 SI absente<20. Ce formula folosesti?
A =IF(OR(A1>=5, B1<20), "Promovat", "Nepromovat")
B =IF(AND(A1>=5, B1<20), "Promovat", "Nepromovat")
C =IF(A1>=5, IF(B1<20, "Promovat"))
💡 Ambele conditii trebuie indeplinite = AND.
