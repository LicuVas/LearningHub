Referinte la Celule in Excel

Invata diferenta dintre referinte relative, absolute si mixte

Progres lectie:
0%
🎯

Obiectivul lectiei

"Dupa aceasta lectie, vei sti sa folosesti referinte relative (A1), absolute ($A$1) si mixte ($A1, A$1) pentru a copia formule eficient."

1

Ce este o referinta?

O referinta este adresa unei celule folosita intr-o formula. In loc sa scriem numere direct (=5+3), folosim referinte (=A1+B1) pentru ca:

- Valorile se actualizeaza automat cand modifici datele

- Poti copia formula in alte celule

- Este mai usor de inteles si verificat

=A1+B1 (aduna valorile din A1 si B1)
Ce este o referinta la o celula in Excel?
A Un comentariu atasat celulei
B Adresa celulei folosita intr-o formula
C Culoarea de fundal a celulei
💡 Gandeste-te la cum identificam o celula in formule.
2

Referinte Relative

O referinta relativa (ex: A1, B2) se ajusteaza automat cand copiezi formula. Este ca si cum ai spune "celula de deasupra" in loc de "celula A1".

Exemplu: Daca in C1 ai formula =A1+B1 si o copiezi in C2, formula devine automat =A2+B2.

C1: =A1+B1
C2: =A2+B2 (copiata din C1)

Referintele relative sunt implicite - nu trebuie sa faci nimic special, asa functioneaza Excel in mod normal.

Ce se intampla cu referinta A1 cand copiezi formula o coloana mai jos?
A Ramane A1
B Devine A2
C Devine B1
💡 Referintele relative se ajusteaza la noua pozitie.
3

Referinte Absolute

O referinta absoluta (ex: $A$1) NU se schimba cand copiezi formula. Folosim simbolul $ (dolar) inainte de coloana si rand.

Cand folosim? Cand avem o valoare fixa (TVA, curs valutar, pret unitar) pe care vrem sa o folosim in mai multe calcule.

TVA in celula E1 = 19%
=A1*$E$1 (pretul din A1 inmultit cu TVA fix)

Shortcut: Apasa F4 dupa ce scrii referinta pentru a adauga automat simbolurile $.

Ce simbol folosim pentru a face o referinta absoluta?
A #
B $
C &
💡 Este simbolul dolar.
4

Referinte Mixte

O referinta mixta are doar coloana SAU doar randul fix:

$A1 - coloana A este fixa, randul se schimba

A$1 - randul 1 este fix, coloana se schimba

$A1 - coloana blocata
A$1 - rand blocat

Exemplu practic: Tabel de inmultire - folosim $A1 pentru a bloca coloana cu primul numar si A$1 pentru a bloca randul cu al doilea numar.

In referinta $A1, ce ramane fix cand copiezi formula?
A Randul (1)
B Coloana (A)
C Ambele
💡 $ apare doar inaintea literei A.
5

Shortcut-ul F4

Tasta F4 este cel mai util shortcut pentru referinte! Cand editezi o formula si cursorul este pe o referinta:

- Apasa F4 o data: A1 devine $A$1 (absoluta)

- Apasa F4 de doua ori: devine A$1 (rand fix)

- Apasa F4 de trei ori: devine $A1 (coloana fixa)

- Apasa F4 de patru ori: revine la A1 (relativa)

A1 -> $A$1 -> A$1 -> $A1 -> A1
Ce tasta apesi pentru a cicla intre tipurile de referinte?
A F2
B F4
C F5
💡 Este o tasta function din randul de sus.
6

Exemplu Practic: Calcul TVA

Situatie: Ai o lista de preturi in coloana A si TVA (19%) in celula D1. Vrei sa calculezi pretul final cu TVA pentru toate produsele.

Solutie: In B1 scrii: =A1*(1+$D$1)

- A1 este relativa (se schimba pentru fiecare produs)

- $D$1 este absoluta (TVA ramane mereu acelasi)

B1: =A1*(1+$D$1) -> 100*(1+0.19) = 119
B2: =A2*(1+$D$1) -> 200*(1+0.19) = 238
Ai preturi in coloana A si TVA=19% in celula D1. Ce formula folosesti pentru a calcula pretul cu TVA?
A =A1+D1
B =A1*(1+$D$1)
C =A1*D1
💡 TVA trebuie sa fie referinta absoluta pentru a o copia.
7

Rezumat: Cand folosim fiecare tip?

Referinta RELATIVA (A1): Pentru date care se schimba cu fiecare rand (note elevi, preturi produse)

Referinta ABSOLUTA ($A$1): Pentru constante fixe (TVA, curs valutar, nota de trecere)

Referinta MIXTA ($A1 sau A$1): Pentru tabele de inmultire, matrice de calcul

Relativa: note elevi -> A1, A2, A3...
Absoluta: TVA 19% -> $E$1
Mixta: tabel inmultire -> $A1*B$1
Ce tip de referinta folosesti pentru o valoare care nu trebuie sa se schimbe niciodata?
A Relativa (A1)
B Absoluta ($A$1)
C Mixta ($A1)
💡 Gandeste-te la constante precum TVA sau curs valutar.
