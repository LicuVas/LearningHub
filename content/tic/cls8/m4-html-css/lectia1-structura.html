HTML = HyperText Markup Language

HTML nu e programare - e o limba de marcare. Ii spui browserului: "asta e titlu", "asta e paragraf", "asta e imagine".

Orice pagina HTML are doua sectiuni principale:

<head> - contine informatii invizibile: titlul paginii (ce apare in tab), setari, link-uri catre CSS

<body> - contine tot ce vede utilizatorul: texte, imagini, butoane

<html>
  <head>
    <title>Pagina mea</title>
  </head>
  <body>
    <h1>Salut!</h1>
  </body>
</html>
Ce conține <head>?
A Textul vizibil pe pagină
B Informații invizibile (titlu, setări)
C Imaginile și linkurile

2

📦 <head> vs <body>

Fiecare element HTML are un tag de deschidere si un tag de inchidere:

<p>Acesta este un paragraf</p>
 ^                        ^
 |                        |
tag deschidere      tag inchidere (cu /)

Tag-ul de inchidere are slash / inainte de nume: </p>, </h1>, </div>

Fara tag de inchidere corect, browserul nu stie unde se termina elementul!

Cum arată un tag de închidere corect?
A <p>
B <p/>
C </p>
💡 Recitește secțiunea pentru a găsi răspunsul.
3

🏷️ Tag-uri = etichete

Prima linie din ORICE pagina HTML trebuie sa fie <!DOCTYPE html>

Aceasta declaratie ii spune browserului: "Aceasta pagina foloseste HTML5" (versiunea moderna de HTML).

<!DOCTYPE html>
<html>
  <head>...</head>
  <body>...</body>
</html>

Fara DOCTYPE, browserul poate afisa pagina incorect sau in "quirks mode" (mod de compatibilitate vechi).

Ce spune <!DOCTYPE html>?
A Că pagina folosește HTML5
B Că pagina are erori
C Numele autorului
💡 Recitește secțiunea pentru a găsi răspunsul.
4

Continutul vizibil in body

Tot ce vrei sa apara pe pagina (texte, imagini, butoane) trebuie scris in sectiunea <body>.

Sectiunea <head> contine doar informatii pentru browser, nu continut vizibil!

<body>
  <h1>Bine ai venit!</h1>
  <p>Aceasta este pagina mea.</p>
  <img src="poza.jpg" alt="O poza">
</body>

<title> din <head> apare doar in tab-ul browserului, nu pe pagina!

Unde scrii conținutul vizibil al paginii?
A În <head>
B În <body>
C În <title>
