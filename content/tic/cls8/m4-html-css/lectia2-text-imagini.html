1

h1 - h6: Niveluri de titluri

HTML are 6 niveluri de titluri, de la <h1> (cel mai mare) la <h6> (cel mai mic):

<h1>Titlu Principal (cel mai mare)</h1>
<h2>Subtitlu</h2>
<h3>Sectiune</h3>
<h4>Subsectiune</h4>
<h5>Detaliu</h5>
<h6>Cel mai mic titlu</h6>

Foloseste <h1> o singura data pe pagina - e titlul principal!

Care este cel mai mare titlu in HTML?
A <h1>
B <h6>
C <title>

2

p - Paragraf

Tag-ul <p> creeaza un paragraf. Browserul adauga automat spatiu inainte si dupa.

<p>Acesta este primul paragraf.</p>
<p>Acesta este al doilea paragraf.</p>

Pentru imagini, folosim tag-ul <img> cu doua atribute importante:

src - contine adresa (calea) imaginii

alt - text alternativ (pentru accesibilitate)

<img src="poza.jpg" alt="Descrierea pozei">
Ce atribut contine adresa imaginii?
A alt
B src
C href
💡 Recitește secțiunea pentru a găsi răspunsul.
3

br si hr - Intreruperi

<br> face o linie noua, <hr> adauga o linie orizontala.

HTML are doua tipuri de liste:

<ul> - lista neordonata (cu buline)

<ol> - lista ordonata (cu numere: 1, 2, 3...)

Elementele din lista se pun in <li>:

<ol>
  <li>Primul element</li>
  <li>Al doilea element</li>
</ol>
Ce tag creeaza o lista numerotata?
A <ul>
B <li>
C <ol>
💡 Recitește secțiunea pentru a găsi răspunsul.
4

ul si ol - Liste

<ul> = lista neordonata (buline), <ol> = lista ordonata (numere)

Tag-ul <br> forteaza o linie noua (break). E util cand vrei sa treci pe rand nou fara a incepe un paragraf nou:

<p>Prima linie<br>A doua linie</p>

<br> este un tag "self-closing" - nu are tag de inchidere!

Ce face tag-ul <br>?
A Creeaza o linie noua
B Face textul bold
C Adauga o imagine
💡 Recitește secțiunea pentru a găsi răspunsul.
5

img - Imagini

Tag-ul <img> afiseaza imagini. Are doua atribute importante:

src - calea catre imagine (URL sau fisier local)

alt - text alternativ (afisat daca imaginea nu se incarca)

<img src="pisica.jpg" alt="O pisica draguta">

Daca imaginea nu se incarca (fisier lipsa, eroare), browserul afiseaza textul din alt!

Alt e important si pentru accesibilitate - cititorii de ecran il citesc persoanelor nevazatoare.

Ce se afiseaza daca imaginea nu se incarca?
A Nimic
B Textul din atributul alt
C Un X rosu
💡 Gandeste-te la rolul atributului alt.
