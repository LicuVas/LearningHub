1

Hosting = Gazduire Web

Ca site-ul tau sa fie vizibil pe internet, fisierele (HTML, CSS, imagini) trebuie sa stea pe un server - un computer care e mereu pornit si conectat la internet.

Deploy = a publica site-ul pe internet, facandu-l accesibil oricui.

Procesul de deploy:

1. Scrii codul HTML/CSS local
2. Incarci fisierele pe server (hosting)
3. Serverul le face disponibile pe internet
4. Oricine poate accesa site-ul prin URL

OneCompiler face hosting-ul automat cand dai Deploy!

2

Ce inseamna fiecare parte?

Un server de hosting este un computer puternic care:

  • Stocheaza fisierele site-ului tau (HTML, CSS, imagini)
  • Este mereu pornit si conectat la internet (24/7)
  • Serveste paginile vizitatorilor cand acceseaza URL-ul

Un URL complet arata asa:

https://www.exemplu.com/pagina.html
  |         |        |       |
  |         |        |       └── Calea fisierului
  |         |        └── Extensia domeniului (.com, .ro)
  |         └── Numele domeniului
  └── Protocol (https = securizat)
Ce este un server de hosting?
A Un program de editare HTML
B Un computer care stocheaza si serveste site-ul tau pe internet
C Un browser web

3

Procesul complet

Structura unui URL si componentele sale:

https://www.magazin.com/produse/laptop.html

.com = extensia domeniului (TLD - Top Level Domain)

Alte extensii comune:

  • .ro - pentru site-uri din Romania
  • .org - pentru organizatii
  • .net - pentru retele/servicii
  • .edu - pentru institutii educationale
Ce reprezinta ".com" intr-un URL?
A Extensia domeniului
B Numele fisierului
C Protocolul de securitate

4

Pentru viitor

Dupa deploy, fisierele site-ului tau "locuiesc" pe un server conectat la internet.

Cand cineva acceseaza URL-ul tau:

Vizitator -> Scrie URL in browser
         -> Browser contacteaza serverul
         -> Serverul trimite fisierele HTML/CSS
         -> Browserul afiseaza pagina

Pentru viitor, cand vei vrea mai mult control, poti folosi:

  • GitHub Pages - gratuit, pentru proiecte
  • Netlify - gratuit, cu deploy automat
  • Vercel - gratuit, foarte rapid
