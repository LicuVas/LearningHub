CSS = Cascading Style Sheets

CSS controleaza cum arata pagina: culori, fonturi, dimensiuni, pozitii. HTML = structura, CSS = design!

💡 Gandeste-te: HTML e scheletul, CSS e pielea si hainele!

Proprietati CSS de baza:
• color - culoarea textului (ex: color: red;)
• background-color - culoarea fundalului
• font-size - marimea textului (ex: font-size: 16px;)
• font-family - tipul fontului (ex: font-family: Arial;)
Ce proprietate CSS schimba culoarea textului?
A background-color
B text-color
C color
💡 Recitește secțiunea pentru a găsi răspunsul.
2

Atributul style (CSS inline)

Cel mai simplu mod de a adauga CSS: atributul style="" direct pe element.

Exemplu:
<p style="color: red; font-size: 20px;">Text rosu</p>

Dezavantaj: trebuie sa scrii style="" pe fiecare element in parte.

Cum adaugi CSS direct pe un element HTML?
A Cu atributul css=""
B Cu atributul style=""
C Cu tagul <css>
💡 Citeste despre atributul style.
3

Selectorul pentru Clasa (.)

In loc de style="" pe fiecare element, poti pune CSS in <style> in <head> si folosi selectori.

Pentru a selecta elemente dupa class, folosesti punctul (.)

Exemplu:
.special { color: blue; } - selecteaza toate elementele cu class="special"
<p class="special">Acest text e albastru</p>

Avantaj: poti aplica acelasi stil pe mai multe elemente!

Cum selectezi elementele cu class="special"?
A #special { }
B .special { }
C special { }
💡 Clasa se selecteaza cu punct (.)
4

Selectorul pentru ID (#)

Pentru a selecta un element dupa id folosesti simbolul # (diez).

ID-ul este unic pe pagina - doar un singur element poate avea un anumit id.

Exemplu:
#header { background: black; } - selecteaza elementul cu id="header"
<div id="header">Antet</div>
Cum selectezi elementul cu id="header"?
A .header { }
B header { }
C #header { }
💡 ID-ul se selecteaza cu diez (#)
5

Sintaxa CSS

Regula CSS are formatul: proprietate: valoare;

Sintaxa corecta:
• : (doua puncte) separa proprietatea de valoare
• ; (punct-virgula) incheie fiecare regula
Exemplu: color: red; ✓
Gresit: color = red ✗
Care e sintaxa CSS corecta?
A color: red;
B color = red
C color: red
💡 Sintaxa CSS: proprietate: valoare; (cu doua puncte si punct-virgula)
