1

Fiecare element e o cutie!

In CSS, fiecare element are 4 straturi: content, padding, border, margin.

Ce e padding?
A Spatiul din afara elementului
B Spatiul din interiorul elementului, intre content si border
C Chenarul elementului
💡 Recitește secțiunea pentru a găsi răspunsul.
2

Margin vs Padding

Padding = spatiu interior (intre continut si border)

Margin = spatiu exterior (intre element si vecinii sai)

Exemplu:
padding: 20px; - adauga 20px in interior
margin: 10px; - adauga 10px in exterior
Care e diferenta intre padding si margin?
A Padding = spatiu exterior, Margin = spatiu interior
B Padding = spatiu interior, Margin = spatiu exterior
C Sunt acelasi lucru
💡 Padding e interior (langa continut), Margin e exterior (langa vecini).
3

Border si Border-radius

border = chenarul elementului (linia din jurul cutiei)

border-radius = face colturile rotunjite

Exemplu:
border: 2px solid black; - chenar negru de 2px
border-radius: 10px; - colturi rotunjite cu raza 10px
border-radius: 50%; - face un cerc!
Cum faci colturi rotunjite?
A border: round;
B corners: 10px;
C border-radius: 10px;
💡 Proprietatea pentru colturi rotunjite e border-radius.
4

display: flex (Flexbox)

Flexbox e cel mai usor mod de a aranja elemente pe orizontala sau verticala!

Se activeaza cu: display: flex;

Cum functioneaza:
• Axa principala (implicit orizontal) - elementele se aseaza pe rand
• Axa secundara (implicit vertical) - pentru aliniere verticala
Ce activeaza Flexbox?
A display: flex;
B flexbox: on;
C layout: flex;
💡 Flexbox se activeaza cu display: flex;
5

Centrarea cu Flexbox

In Flexbox, justify-content controleaza alinierea pe axa principala (implicit orizontala).

align-items controleaza alinierea pe axa secundara (implicit verticala).

Pentru a centra complet:
justify-content: center; - centreaza orizontal
align-items: center; - centreaza vertical
Ce face justify-content: center; in Flexbox?
A Centreaza vertical
B Centreaza orizontal
C Schimba culoarea
💡 justify-content controleaza axa principala (implicit orizontal).
