Ce sunt Tag-urile HTML?

Un tag (eticheta) este un cuvant cheie incadrat intre paranteze unghiulare: <tag>

Structura unui element HTML:
<tag> continut </tag>

- Tag de deschidere: <p>
- Continut: textul sau elementele din interior
- Tag de inchidere: </p> (cu slash /)

Majoritatea tag-urilor vin in pereche: deschidere + inchidere!

Ce este un tag HTML?
A O imagine
B O eticheta care defineste un element
C Un fisier
💡 Tag = eticheta care spune browserului ce tip de element urmeaza.
2

Structura unui Document HTML

Orice pagina HTML are aceeasi structura de baza:

<!DOCTYPE html> <html> <head> <title>Titlul Paginii</title> </head> <body> Continutul vizibil aici </body> </html>
Explicatie:
- <!DOCTYPE html> - declara ca este HTML5
- <html> - elementul radacina
- <head> - informatii despre pagina (nu se vad)
- <body> - continutul vizibil al paginii
Care este structura de baza a oricarui document HTML?
A head si body
B html, head si body
C doar body
💡 Orice pagina HTML are 3 elemente principale: html, head, body.
3

Titluri (Headings)

HTML are 6 nivele de titluri, de la <h1> (cel mai mare) la <h6> (cel mai mic):

<h1>Titlu Principal</h1> <h2>Subtitlu</h2> <h3>Sectiune</h3> <h4>Subsectiune</h4> <h5>Detaliu</h5> <h6>Detaliu mic</h6>

Foloseste <h1> doar pentru titlul principal al paginii, apoi <h2> pentru sectiuni, <h3> pentru subsectiuni, etc.

Care tag creaza cel mai mare titlu?
A <h6>
B <h1>
C <title>
💡 h1 = heading 1 = cel mai important/mare titlu.
4

Paragrafe

Tag-ul <p> (paragraph) creaza un paragraf de text:

<p>Acesta este primul paragraf.</p> <p>Acesta este al doilea paragraf.</p>
Important:
- Browserul adauga automat spatiu inainte si dupa fiecare paragraf
- Enter in cod NU creaza rand nou - trebuie sa folosesti <p> sau <br>
- <br> = line break (rand nou fara spatiu)
Cu ce tag creezi un paragraf?
A <paragraph>
B <p>
C <text>
💡 p vine de la paragraph.
5

Liste

HTML are doua tipuri de liste:

<!-- Lista neordonata (cu puncte) --> <ul> <li>Element 1</li> <li>Element 2</li> </ul> <!-- Lista ordonata (cu numere) --> <ol> <li>Primul pas</li> <li>Al doilea pas</li> </ol>
Explicatie:
- <ul> = unordered list (lista cu puncte)
- <ol> = ordered list (lista cu numere)
- <li> = list item (element din lista)
Ce tag folosesti pentru o lista cu puncte (neordonata)?
A <ol>
B <ul>
C <list>
💡 ul = unordered list (lista neordonata, cu puncte).
6

Link-uri (Legaturi)

Tag-ul <a> (anchor) creaza un link pe care poti da click:

<a href="https://www.google.com">Viziteaza Google</a> <a href="pagina2.html">Mergi la pagina 2</a> <a href="mailto:email@exemplu.ro">Trimite email</a>
Atributul href:
- href = hypertext reference = adresa destinatie
- Poate fi URL complet, fisier local, sau email
- Textul dintre tag-uri este ce se afiseaza pe pagina
Ce tag creaza un link (legatura) catre alta pagina?
A <link>
B <a>
C <href>
💡 a vine de la anchor (ancora).
7

Imagini

Tag-ul <img> adauga o imagine. Este un tag auto-inchis (nu are tag de inchidere):

<img src="poza.jpg" alt="Descriere poza"> <img src="imagini/logo.png" alt="Logo scoala" width="200">
Atribute importante:
- src = sursa (calea catre imagine)
- alt = text alternativ (afisat daca imaginea nu se incarca)
- width/height = dimensiuni (optional)

Atributul alt este obligatoriu pentru accesibilitate!

Ce atribut folosesti pentru a specifica sursa unei imagini?
A href
B src
C link
💡 src = source = sursa imaginii.
