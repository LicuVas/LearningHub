Creare si Formatare Grafice

Invata sa creezi grafice pas cu pas si sa le personalizezi frumos

Progres lectie:
0%
🎯

Obiectivul lectiei

"Dupa aceasta lectie, vei sti sa creezi un grafic de la zero si sa il formatezi profesional: titlu, legenda, culori si etichete."

1

Pasul 1: Selectarea datelor

Primul pas pentru a crea un grafic este sa selectezi datele pe care vrei sa le reprezinti vizual. Include intotdeauna:

Ce trebuie selectat:
- Titlurile coloanelor (ex: "Luna", "Vanzari")
- Etichetele (ex: "Ianuarie", "Februarie"...)
- Valorile numerice (datele propriu-zise)

Selecteaza tragand mouse-ul peste celule sau foloseste Ctrl+Click pentru selectii multiple nesuccesive.

Care este primul pas pentru a crea un grafic in Excel?
A Alegem tipul de grafic
B Selectam datele sursa
C Adaugam titlul
💡 Inainte de orice, Excel trebuie sa stie CE date sa reprezinte grafic.
2

Pasul 2: Inserarea graficului

Dupa ce ai selectat datele, mergi la tab-ul Insert (Inserare) si gasesti sectiunea Charts (Grafice).

Calea completa:
Insert > Charts > [Alege tipul dorit]

Tipuri disponibile: Column, Line, Pie, Bar, Area, Scatter

Click pe tipul de grafic dorit si Excel va genera automat graficul bazat pe datele selectate!

Unde gasesti optiunea de inserare grafic in Excel?
A Home > Charts
B Insert > Charts
C View > Charts
💡 Insert (Inserare) este tab-ul pentru a adauga elemente noi.
3

Pasul 3: Editarea graficului

Cand selectezi (click pe) un grafic, apar doua tab-uri noi in ribbon:

Tab-uri Chart Tools:
- Design - schimba tipul graficului, stilul, layout-ul
- Format - modifica culorile, fonturile, efectele

Aceste tab-uri apar DOAR cand graficul este selectat. Click in afara graficului si dispar!

Ce apare cand selectezi un grafic in Excel?
A Meniul File
B Tab-uri noi: Design si Format
C Fereastra Print
💡 Excel afiseaza unelte speciale pentru editarea graficului.
4

Adaugarea titlului

Un grafic fara titlu este ca o carte fara coperta - nu stii despre ce e vorba!

Pentru a adauga titlu:
1. Selecteaza graficul
2. Design > Add Chart Element > Chart Title
3. Alege pozitia: Above Chart (deasupra) sau Centered Overlay
4. Click pe casuta de titlu si scrie textul dorit

Titlul trebuie sa fie scurt si descriptiv: "Vanzari pe luni 2024", nu "Graficul meu"!

Cum adaugi un titlu la grafic?
A Scrii direct pe grafic
B Design > Add Chart Element > Chart Title
C Format > Title
💡 Titlul este un element al graficului, deci il adaugi din Add Chart Element.
5

Legenda graficului

Legenda (Legend) explica ce reprezinta fiecare culoare sau serie de date din grafic.

Gestionarea legendei:
- Design > Add Chart Element > Legend
- Pozitii: Right (dreapta), Bottom (jos), Top (sus), Left (stanga)
- None = ascunde legenda (util cand ai o singura serie)

Daca graficul are mai multe serii de date (ex: Vanzari si Cheltuieli), legenda este esentiala!

Ce este legenda intr-un grafic?
A Titlul graficului
B Explicatia culorilor/seriilor de date
C Valorile de pe axe
💡 Legenda explica ce reprezinta fiecare culoare sau serie.
6

Etichete de date (Data Labels)

Data Labels (Etichete de date) afiseaza valorile exacte direct pe grafic - pe fiecare bara, punct sau felie.

Pentru a adauga etichete:
Design > Add Chart Element > Data Labels

Pozitii disponibile:
- Center (centru), Inside End (interior), Outside End (exterior)
- Pentru Pie: Best Fit (pozitie optima automata)

Etichetele sunt utile pentru prezentari - cititorii vad valorile fara sa estimeze din grafic!

Ce sunt Data Labels (Etichete de date)?
A Numele axelor
B Valorile afisate direct pe grafic
C Culorile graficului
💡 Etichetele arata valorile exacte pe fiecare bara sau felie.
7

Schimbarea culorilor

Culorile implicite ale graficului pot fi schimbate pentru a se potrivi cu tema documentului sau prezentarii.

Metode de schimbare culori:
1. Design > Change Colors - paleta rapida de culori
2. Format > Shape Fill - culoare individuala pentru un element
3. Double-click pe element > Format Data Series > Fill

Sfat: Foloseste culori contrastante pentru a face graficul usor de citit!

Cum schimbi culorile unui grafic rapid?
A Redesenezi graficul
B Design > Change Colors
C File > Options
💡 Tab-ul Design contine optiuni rapide pentru aspect.
