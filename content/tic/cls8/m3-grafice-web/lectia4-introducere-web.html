1

Internet vs. Web

Multi confunda Internetul cu Web-ul, dar sunt lucruri diferite!

Diferenta:
- Internet = reteaua globala de calculatoare conectate (infrastructura fizica: cabluri, routere, servere)
- Web (World Wide Web) = colectia de pagini si site-uri accesibile prin Internet

Pe Internet mai exista si email, jocuri online, streaming video - nu doar Web!

Care este diferenta intre Internet si Web?
A Sunt acelasi lucru
B Internetul este infrastructura, Web-ul sunt paginile/site-urile
C Web-ul este mai vechi decat Internetul
💡 Internetul = autostrada, Web-ul = masinile care circula pe ea.
2

Ce este un Browser?

Un browser (navigator web) este programul care iti permite sa accesezi si sa vizualizezi pagini web.

Browsere populare:
- Google Chrome - cel mai folosit (peste 60%)
- Mozilla Firefox - open source, axat pe confidentialitate
- Microsoft Edge - vine cu Windows
- Safari - pentru Mac si iPhone
- Opera - cu VPN integrat

Browserul "traduce" codul HTML intr-o pagina vizuala pe care o poti citi si folosi.

Ce este un browser?
A Un server de internet
B Un program care afiseaza pagini web
C Un limbaj de programare
💡 Browser = program pe calculatorul tau pentru a naviga pe web.
3

Ce este un Server?

Un server web este un calculator special care stocheaza paginile web si le trimite cand sunt cerute.

Cum functioneaza:
1. Tu scrii www.google.com in browser
2. Browserul trimite o cerere catre serverul Google
3. Serverul trimite inapoi codul HTML al paginii
4. Browserul afiseaza pagina pe ecranul tau

Acest proces se numeste Client-Server: tu (clientul) ceri, serverul raspunde.

Ce este un server web?
A Calculatorul tau personal
B Un calculator care stocheaza si trimite pagini web
C O aplicatie de email
💡 Serverul este calculatorul care gazduieste site-ul.
4

Ce este un URL?

URL (Uniform Resource Locator) este adresa unica a fiecarei pagini de pe web.

https://www.exemplu.ro/pagina/articol.html
Partile unui URL:
- https:// = protocolul (securizat)
- www. = subdomeniu (optional)
- exemplu.ro = domeniul (numele site-ului)
- /pagina/ = calea catre fisier
- articol.html = numele paginii
Ce inseamna URL?
A Un tip de fisier
B Adresa unica a unei pagini web
C Un browser
💡 URL = Uniform Resource Locator = adresa web.
5

HTTP vs. HTTPS

HTTP (HyperText Transfer Protocol) este protocolul de comunicare intre browser si server.

HTTP vs HTTPS:
- HTTP = comunicare necriptata (poate fi interceptata)
- HTTPS = comunicare criptata (securizata cu SSL/TLS)

Cauta lacatul in browser! Daca e acolo, conexiunea e securizata.

HTTPS este obligatoriu pentru site-uri cu date sensibile: banci, magazine online, social media.

Care este diferenta intre HTTP si HTTPS?
A Nu exista diferenta
B HTTPS este criptat (securizat)
C HTTP este mai rapid
💡 S-ul de la HTTPS vine de la Secure.
6

HTML - Limbajul Paginilor Web

Paginile web sunt scrise in HTML (HyperText Markup Language) - un limbaj de marcare.

<html> <head> <title>Pagina Mea</title> </head> <body> <h1>Bine ai venit!</h1> <p>Aceasta este o pagina simpla.</p> </body> </html>

HTML foloseste tag-uri (etichete) pentru a defini elementele: titluri, paragrafe, imagini, link-uri.

Ce limbaj defineste structura unei pagini web?
A Python
B HTML
C Excel
💡 HTML = HyperText Markup Language.
7

CSS si JavaScript

Pe langa HTML, paginile web moderne folosesc si alte tehnologii:

Trioul Web:
- HTML = structura (scheletul paginii)
- CSS = stil (culori, fonturi, pozitionare)
- JavaScript = interactivitate (butoane, animatii, formulare)

Gandeste-te la o casa: HTML = caramizile, CSS = vopseaua si decoratiunile, JavaScript = instalatia electrica!

Ce rol are CSS in paginile web?
A Defineste structura
B Stilizeaza aspectul (culori, fonturi)
C Adauga interactivitate
💡 CSS = Cascading Style Sheets = stiluri.
