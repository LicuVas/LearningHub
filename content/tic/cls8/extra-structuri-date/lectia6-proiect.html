⚠ Greseli frecvente la proiecte
Greseala De ce e gresit si cum corectezi
Sortezi INAINTE de a calcula media Media nu se schimba (suma ramane aceeasi), dar daca vrei sa afisezi notele in ordine originala cu numarul elevului, nu mai poti dupa sortare
Folosesti suma / n fara cast int / int = int, deci 58/8 = 7 (nu 7.25). Scrie (float)suma / n pentru a obtine zecimale
Initializezi maxim = 0 Daca toate notele sunt negative (in alte contexte), 0 ar ramane maxim gresit. Initializeaza mereu cu note[0]
Uiti sa verifici n > 0 Daca utilizatorul introduce 0 note, note[0] nu exista si programul se blocheaza
