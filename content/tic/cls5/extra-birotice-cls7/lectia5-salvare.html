De ce trebuie sa salvezi? Scurtatura magica!

Cand lucrezi la un document, modificarile sunt tinute temporar in memoria calculatorului (numita RAM). Aceasta memorie este volatila - asta inseamna ca tot ce se afla in ea dispare cand inchizi programul sau calculatorul.

Salvarea inseamna sa scrii documentul pe hard disk (sau SSD), unde ramane in siguranta chiar si dupa ce inchizi calculatorul. Gandeste-te la asta ca la un caiet: daca scrii cu creionul pe o foaie (RAM), cineva poate sterge. Dar daca scrii cu pixul in caiet (hard disk), ramane acolo.

💡 Scurtatura magica: Ctrl + S

Apasa Ctrl + S des in timp ce lucrezi! E cea mai importanta scurtatura pe care trebuie s-o retii. Profesorii iti vor repeta mereu: "Ai salvat?" - cu Ctrl + S nu mai trebuie sa-ti faci griji!

Scurtaturi importante de memorat:

  • Ctrl + S = S ave (Salveaza) - cea mai folosita!
  • Ctrl + C = C opy (Copiaza)
  • Ctrl + V = Paste (Lipeste)
  • Ctrl + Z = Undo (Anuleaza ultima actiune)

Sfat practic: Obiseanuieste-te sa apesi Ctrl + S dupa fiecare paragraf pe care il scrii. Asa nu vei pierde niciodata mai mult de cateva randuri de text!

Ce scurtatura folosesti pentru salvare rapida?
A Ctrl + C (copiaza)
B Ctrl + S (salveaza)
C Ctrl + V (lipeste)
💡 S vine de la Save (salveaza in engleza). Ctrl + C copiaza, Ctrl + V lipeste.

Save vs Save As - Care e diferenta?

Exista doua moduri de a salva un document, si e important sa le cunosti pe amandoua. Fiecare are rolul lui:

Save (Ctrl + S) Save As (F12)
Salveaza peste fisierul existent Creeaza o copie cu alt nume/locatie
Prima data cere nume si locatie Mereu cere nume si locatie
Rapid - un singur click sau Ctrl+S Util pentru versiuni diferite ale aceluiasi document

Cand folosesti Save As? De exemplu, ai un referat la Romana si vrei sa-l adaptezi pentru Istorie. Deschizi referatul, apesi F12 (Save As), schimbi numele in "Referat_Istorie" si ai doua fisiere separate, fara sa pierzi originalul.

Un truc important: Cand deschizi un document pentru prima data si apesi Ctrl + S, Word va deschide automat fereastra "Save As" pentru ca fisierul nu are inca un nume. Dupa prima salvare, Ctrl + S va salva direct, fara sa mai intrebe.

💡 Exercitiu practic:

  1. Deschide Word si scrie: "Test de salvare"
  2. Apasa Ctrl + S - observa ca se deschide fereastra Save As
  3. Alege locatia "Desktop" si numele "test-salvare"
  4. Apasa Save, apoi modifica textul si apasa iar Ctrl + S - de data asta salveaza instant!
Cand folosesti Save As (F12) in loc de Save (Ctrl+S)?
A Cand vrei sa stergi fisierul
B Cand vrei sa creezi o copie cu alt nume sau in alta locatie
C Cand vrei sa inchizi documentul
💡 Save As creeaza o copie noua - poti schimba numele, formatul sau locatia fisierului.

Extensii - Cum recunoaste calculatorul fisierele

Extensia este terminatia numelui unui fisier, dupa punct. Ea spune calculatorului ce tip de fisier este si cu ce program sa-l deschida. De exemplu, cand dai dublu-click pe un fisier ".docx", Windows stie sa-l deschida cu Word.

De ce conteaza extensiile? Daca schimbi extensia unui fisier (de exemplu, din .docx in .txt), calculatorul il va deschide cu alt program si s-ar putea sa nu mai arate corect. De aceea, de obicei Windows ascunde extensiile - ca sa nu le schimbi din greseala.

Extensie Tip fisier Programul asociat
.docx Document Word Microsoft Word
.xlsx Tabel Excel Microsoft Excel
.pptx Prezentare PowerPoint Microsoft PowerPoint
.pdf Document PDF (nu se editeaza usor) Adobe Reader / Browser
.jpg / .png Imagini Photos / Paint
.mp3 / .mp4 Audio / Video Media Player

Sfat: Cand salvezi un document Word ca PDF (File > Save As > PDF), altii il pot citi dar nu il pot modifica usor. E perfect pentru cand trimiti teme sau referate!

Ce extensie are un document Word?
A .jpg (imagine)
B .docx (document Word)
C .mp3 (muzica)
💡 Extensia .docx vine de la DOCument XML - formatul modern al Word.

Crearea si organizarea folderelor

Ca sa gasesti usor fisierele, trebuie sa le organizezi in foldere (dosare). Gandeste-te la un dulap: daca arunci toate hainele gramada, nu gasesti nimic. Dar daca ai sertare etichetate (tricouri, pantaloni, sosete), totul e la locul lui.

Cum creezi un folder nou:

  1. Deschide File Explorer (sau mergi pe Desktop)
  2. Click dreapta intr-un loc gol
  3. Alege New (Nou) > Folder
  4. Scrie un nume descriptiv pentru folder (de exemplu: "TIC_Clasa5")

Ce sunt subfolderele? Un subfolder este un folder pus in interiorul altui folder. Asa creezi o structura organizata, ca un arbore cu ramuri.

Sugestie de organizare pentru scoala:

  • Scoala (folder principal)
    • Romana (subfolder)
    • Matematica (subfolder)
    • TIC (subfolder)
    • Istorie (subfolder)

💡 Exercitiu practic:

Creeaza pe Desktop un folder "Scoala" cu subfoldere pentru 3 materii! Apoi muta un fisier existent in folderul potrivit (drag and drop sau Cut/Paste).

Scurtatura utila: In File Explorer, poti folosi Ctrl + Shift + N pentru a crea rapid un folder nou, fara click dreapta!

Cum creezi un folder nou?
A Apesi Ctrl + S
B Click dreapta > New > Folder
C Inchizi calculatorul
💡 Click dreapta in orice loc (Desktop, File Explorer) si alegi New > Folder pentru a crea un dosar nou.

Reguli pentru denumirea fisierelor

Un nume bun de fisier te ajuta sa gasesti documentul rapid, chiar si dupa luni de zile. Imaginea-ti ca ai 50 de fisiere numite "Document1", "Document2", "Document3" - cum gasesti referatul la Romana?

Reguli pentru un nume bun:

  • Fii descriptiv: "Referat_Romana_Toamna.docx" e mult mai bun decat "Document1.docx"
  • Foloseste underscore (_) sau cratima (-): in loc de spatii, care pot cauza probleme
  • Include data daca e important: "Tema_TIC_20ianuarie.docx" sau "Proiect_2026-01-20.docx"
  • Pastreaza numele scurt: nu scrie un roman in numele fisierului!

⚠ Caractere interzise in nume de fisiere:

Windows nu permite aceste caractere in numele fisierelor: \ / : * ? " < > |

Daca incerci sa le folosesti, vei primi un mesaj de eroare.

Exemple bune vs rele:

Nume rau ❌ Nume bun ✅
Document1.docx Referat_Romana_Eminescu.docx
tema.docx Tema_TIC_Lectia5.docx
aaa.docx Proiect_Stiinte_Ecosisteme.docx
Ce regula trebuie sa respecti cand numesti un fisier?
A Sa folosesti cat mai multe spatii si caractere speciale
B Sa folosesti un nume scurt, clar si fara caractere speciale
C Sa nu dai niciun nume - lasi Document1
💡 Numele bune sunt scurte, clare si descriu continutul. Evita caractere speciale ca: ? * : < > |

AutoSave si AutoRecover - Plase de siguranta

Word are doua functii care te ajuta sa nu pierzi munca, chiar daca uiti sa salvezi manual. Sunt ca niste plase de siguranta - te prind daca cazi, dar e tot mai bine sa nu cazi!

AutoSave (Salvare automata):

  • Disponibil pentru fisiere salvate in OneDrive sau SharePoint
  • Salveaza automat la fiecare cateva secunde
  • Apare ca un comutator (buton) in coltul stanga-sus al ferestrei Word
  • Cand este activat (verde), fiecare modificare se salveaza instant

AutoRecover (Recuperare automata):

  • Word salveaza o copie de siguranta la fiecare 10 minute (implicit)
  • Daca Word se inchide neasteptat (crash, pana de curent), iti ofera sa recuperezi documentul
  • Poti modifica intervalul: File > Options > Save > "Save AutoRecover information every X minutes"
  • Recomandat: seteaza la 5 minute pentru siguranta maxima

⚠ Important:

AutoRecover NU inlocuieste salvarea manuala! Poate recupera cel mult ce ai lucrat in ultimele 10 minute. Tot ce ai lucrat inainte si nu ai salvat cu Ctrl + S se poate pierde. Apasa Ctrl + S des!

Ce este AutoSave (Salvare automata)?
A O functie care sterge fisierele automat
B O functie care salveaza documentul automat la cateva secunde
C Un virus de calculator
💡 AutoSave te protejeaza - salveaza automat documentul ca sa nu pierzi nimic daca se inchide Word.

Gasirea fisierelor salvate

Uneori uitam unde am salvat un fisier. Nu intra in panica! Exista mai multe metode de a-l gasi:

Metoda 1: File Explorer

  1. Deschide File Explorer (iconita cu folder galben din bara de activitati, sau apasa Win + E )
  2. Mergi in locatia unde crezi ca ai salvat (Desktop, Documents, Downloads)
  3. Cauta fisierul dupa nume sau tip

Metoda 2: Cautare Windows

  1. Apasa tasta Windows sau click pe bara de cautare din Taskbar
  2. Scrie numele fisierului (sau o parte din el)
  3. Windows va gasi toate fisierele care contin acel text
  4. Rezultatele apar instant - click pe fisier pentru a-l deschide

Metoda 3: Recent files in Word

  • Deschide Word > File > Open > Recent
  • Vezi lista cu ultimele documente deschise, in ordine cronologica
  • Poti fixa (pin) un document important ca sa ramana mereu in lista

💡 Sfat avansat:

In File Explorer, poti folosi bara de cautare din coltul dreapta-sus. Scrie " *.docx " pentru a gasi TOATE documentele Word de pe calculator. Semnul * inseamna "orice nume".

Cum gasesti un fisier pe care l-ai salvat dar nu mai stii unde?
A Il cauti la gunoi
B Folosesti File Explorer sau bara de cautare Windows
C Trebuie sa-l creezi din nou
💡 File Explorer si bara de cautare din Windows te ajuta sa gasesti orice fisier de pe calculator.

Recycle Bin - Cosul de gunoi si recuperarea fisierelor

Ai sters un fisier din greseala? Nu intra in panica! Windows are un Recycle Bin (Cos de gunoi) care pastreaza fisierele sterse temporar, exact ca un cos de gunoi real - poti scoate lucrurile inapoi daca te razgandesti.

Cum functioneaza Recycle Bin:

  • Cand stergi un fisier (tasta Delete sau click dreapta > Delete), el merge in Recycle Bin
  • Fisierul ramane acolo pana cand golesti cosul sau pana cand cosul se umple
  • Poti recupera orice fisier din Recycle Bin oricand

Cum recuperezi un fisier sters:

  1. Deschide Recycle Bin (iconita de pe Desktop)
  2. Gaseste fisierul pe care vrei sa-l recuperezi
  3. Click dreapta pe fisier > Restore
  4. Fisierul revine in locatia originala!

⚠ Atentie la Shift + Delete!

Daca stergi un fisier cu Shift + Delete , acesta este sters definitiv , fara a trece prin Recycle Bin! Foloseste aceasta combinatie doar cand esti absolut sigur ca nu mai ai nevoie de fisier.

Golirea cosului de gunoi: Click dreapta pe iconita Recycle Bin > "Empty Recycle Bin". Dupa golire, fisierele nu mai pot fi recuperate usor! Fa asta doar cand esti sigur ca nu ai nevoie de nimic din cos.

Ce se intampla cand stergi un fisier de pe Desktop?
A Dispare definitiv si nu mai poate fi recuperat
B Merge in Recycle Bin (Cosul de gunoi) de unde poate fi recuperat
C Se muta automat in Documents
💡 Cand stergi un fisier, el merge in Recycle Bin. Il poti recupera de acolo daca te razgandesti!

Exportul ca PDF - Trimite documente profesionale

Cand vrei sa trimiti un document cuiva (profesorului, unui coleg), de multe ori e mai bine sa-l trimiti ca PDF decat ca fisier Word. PDF-ul are cateva avantaje importante:

  • Pastreaza formatarea: documentul arata identic pe orice calculator, telefon sau tableta
  • Nu poate fi modificat usor: destinatarul nu poate schimba textul din greseala
  • Se deschide oriunde: toate browserele si telefoanele pot deschide PDF-uri, chiar daca nu au Word instalat

Cum exporti ca PDF din Word:

  1. Deschide documentul Word
  2. Mergi la File > Save As (sau apasa F12)
  3. In casuta "Save as type", alege PDF (*.pdf)
  4. Alege locatia si numele, apoi apasa Save

Metoda rapida: File > Export > Create PDF/XPS Document > Publish. Aceasta metoda e putin mai rapida si ofera optiuni suplimentare.

💡 Cand sa folosesti PDF:

  • Cand trimiti teme sau referate profesorului
  • Cand vrei sa pui un document online
  • Cand vrei sa te asiguri ca formatarea nu se strica
De ce e util sa exporti un document Word ca PDF?
A Pentru ca PDF-ul e mai mic ca dimensiune
B Pentru ca destinatarul poate citi documentul fara sa-l poata modifica usor
C Pentru ca PDF-ul arata mai frumos decat Word
💡 PDF-ul pastreaza formatarea exacta si nu poate fi modificat usor - perfect pentru trimiteri oficiale.

Recapitulare: Cele 3 reguli de aur

Hai sa recapitulam cele mai importante lucruri despre salvare! Daca respecti aceste 3 reguli, nu vei pierde niciodata un document important:

🏆 CELE 3 REGULI DE AUR:

  1. Salveaza DES - Apasa Ctrl + S la fiecare cateva minute. E mai bine sa salvezi de 10 ori decat sa pierzi tot! Dupa fiecare paragraf scris, apasa Ctrl + S.
  2. Organizeaza in FOLDERE - Creeaza foldere pentru fiecare materie sau proiect. Nu lasa fisierele raspandite pe Desktop! Un Desktop curat = un elev organizat.
  3. Foloseste NUME CLARE - Numeste fisierele descriptiv: "Referat_Romana_Toamna.docx" in loc de "Document1.docx". Foloseste underscore (_) sau cratima (-) in loc de spatii.

Lista completa de scurtaturi din aceasta lectie:

Scurtatura Ce face
Ctrl + S Salveaza documentul
F12 Save As (salveaza cu alt nume/locatie)
Win + E Deschide File Explorer
Ctrl + Shift + N Creeaza folder nou (in File Explorer)
Delete Sterge fisierul (merge in Recycle Bin)

Aminteste-ti: AutoSave si AutoRecover sunt plase de siguranta, dar nu inlocuiesc salvarea manuala. Ctrl + S este cel mai bun prieten al tau cand lucrezi la calculator!

Care este regula de aur pentru salvare?
A Salvezi doar la sfarsit
B Salvezi des, cu Ctrl + S, in foldere organizate, cu nume clare
C Nu salvezi niciodata, ca are AutoSave
💡 Regula de aur combina 3 elemente: Ctrl + S des, foldere organizate si nume clare pentru fisiere!
