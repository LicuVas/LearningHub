Obiectivul lectiei

"Vei invata sa lucrezi cu aplicatii audio si audio-video: interfata, fisiere, inregistrare, mixare, tranzitii, generice si specificatii."

Competente vizate (OMEN 3393/2017, cls VII):

  • VII-1.2 - Documentarea pe diferite teme prin utilizarea aplicatiilor audio respectiv audio-video
  • VII-3.2 - Elaborarea unor produse audio respectiv audio-video pentru a ilustra o tema data
1

Ce sunt aplicatiile audio si audio-video?

Aplicatii audio - programe pentru inregistrarea, redarea si editarea sunetelor. Exemplu: Audacity (gratuit, open-source).

Aplicatii audio-video - programe pentru crearea si editarea clipurilor video. Exemple: Clipchamp (inclus in Windows 11), Windows Movie Maker.

Analogie: aplicatia audio = casetofon digital; aplicatia audio-video = studio TV de buzunar.

Conform OMEN 3393/2017, domeniul cuprinde: interfata, gestionare fisiere, inregistrare/redare, mixare, selectie secvente, tranzitii, suprapuneri audio/text, generice si lucrul dupa specificatii.

Ce este o aplicatie audio?
AUn program pentru desenat
BUn program pentru inregistrat si editat sunete
CUn program pentru scris texte
💡 Aplicatiile audio prelucreaza sunete: inregistrare, redare, mixare.
2

Interfata si gestionarea fisierelor

Interfata contine: bara de instrumente (redare/inregistrare), timeline (linia de timp cu piste) si panoul de proprietati (volum, efecte).

Gestionarea fisierelor:

  • Creare - File > New Project
  • Deschidere - File > Open (.mp3, .wav, .mp4)
  • Salvare proiect - File > Save Project (format nativ editabil)
  • Export - File > Export (fisier final .mp3 sau .mp4)
Care este diferenta intre salvarea proiectului si export?
ANu exista diferenta
BProiectul pastreaza editarile; exportul produce fisierul final
CExportul salveaza proiectul editabil
💡 Proiectul pastreaza pistele; exportul produce fisierul final (.mp3, .mp4).
3

Inregistrare, redare si mixare

Inregistrare - captezi sunet de la microfon; pe timeline apare forma de unda.

Redare - asculti sunetul cu Play/Pause/Stop.

Mixare - combini mai multe piste (voce, muzica de fond, efecte); fiecare pista are volum reglabil independent.

Analogie: mixajul este ca un cor - mai multe voci canta simultan; dirijorul (tu) regleaza echilibrul.

Ce inseamna mixarea in editarea audio?
AStergerea unui sunet
BCombinarea mai multor piste intr-un singur rezultat
CSchimbarea culorii formei de unda
💡 Mixarea combina mai multe piste intr-un singur fisier audio final.
4

Selectie secvente, tranzitii, suprapuneri si generice

Selectia secventelor - alegi din clipul original doar portiunile utile.

Tranzitii - efecte la trecerea intre secvente: Fade (estompar), Dissolve (dizolvare), Slide (glisare).

Suprapuneri audio/text - adaugi muzica sau voce off si text (titluri, subtitrari) suprapus peste imagine.

Generice - ecranul de inceput (titlu, autor) si ecranul de sfarsit (credite).

Ce este o tranzitie intr-un editor video?
AUn tip de fisier
BUn efect vizual la trecerea intre doua secvente
CUn buton de salvare
💡 Tranzitia face trecerea fluenta intre doua clipuri (ex: Fade, Dissolve).
5

Lucrul dupa specificatii

Lucrul dupa specificatii inseamna ca respecti o lista de cerinte precise. Exemplu pentru un clip documentar:

  • Durata totala: 1-2 minute
  • Generic de inceput cu titlul si autorul
  • Cel putin 3 secvente legate prin tranzitii Fade
  • Muzica de fundal la volum redus
  • Export in format .mp4

In viata reala, produsul trebuie sa respecte cerintele beneficiarului. Verifica fiecare cerinta inainte de predare.

Ce inseamna lucrul dupa specificatii?
ASa faci orice iti place
BSa respecti cerintele date: durata, format, efecte obligatorii
CSa copiezi de pe internet
💡 Specificatiile sunt cerintele precise pe care trebuie sa le respecti inainte de predare.
