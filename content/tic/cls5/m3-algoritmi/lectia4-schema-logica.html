Schema logica (Flowchart)

Obiectivul lectiei

"Dupa aceasta lectie vei sti ce este o schema logica, vei recunoaste simbolurile de baza (START, STOP, proces, decizie) si vei putea citi un flowchart simplu!"

1

Ce este o schema logica?

O schema logica (sau flowchart in engleza) este o metoda de a reprezenta un algoritm folosind desene si simboluri in loc de cuvinte.

Este ca o harta care iti arata drumul de la START la STOP, cu toate actiunile pe parcurs!

Avantaje:
• E mai usor de inteles dintr-o privire
• Arata clar ordinea pasilor
• E universala - toata lumea intelege aceleasi simboluri
• Ajuta sa vezi "imaginea de ansamblu"

Ce este o schema logica (flowchart)?
A Un text cu pasi numerotati
B O reprezentare grafica a algoritmului cu simboluri si sageti
C O lista de ingrediente
💡 Flow = flux, chart = diagrama. O diagrama care arata cum curge algoritmul.
2

Simbolul START si STOP

Primul simbol pe care trebuie sa-l cunosti este OVAL-ul (sau elipsa).

START STOP

Acest simbol se foloseste pentru:

• START - inceputul algoritmului (unde pornim)
• STOP - sfarsitul algoritmului (unde ne oprim)

Fiecare schema logica are EXACT un START si cel putin un STOP. Algoritmul "curge" de la START spre STOP.

Ce forma are simbolul pentru START si STOP?
A Dreptunghi
B Romb (diamant)
C Oval (elipsa)
💡 START si STOP au forma rotunjita, ca o capsula.
3

Simbolul PROCES (Dreptunghi)

Dreptunghiul reprezinta un proces - adica o actiune, o operatie, un calcul.

Calculeaza suma

Exemple de ce punem in dreptunghi:

• "Aduna A + B"
• "Inmulteste cu 2"
• "Pune zaharul in bol"
• "Scrie mesajul"

Orice actiune simpla care NU este o intrebare se pune in dreptunghi!

Ce simbolizam cu dreptunghiul in schema logica?
A Inceputul si sfarsitul
B O actiune sau proces (calcul, operatie)
C O intrebare cu DA sau NU
💡 Dreptunghiul = casuta in care scriem CE FACEM.
4

Simbolul DECIZIE (Romb)

Rombul (sau diamantul) reprezinta o decizie - o intrebare la care raspunsul este DA sau NU.

A > B?

Rombul are o intrare (de sus) si DOUA iesiri:
• Una pentru raspunsul DA (de obicei in dreapta sau jos)
• Una pentru raspunsul NU (de obicei in stanga sau jos)

Exemple: "Este A mai mare ca B?", "Ai terminat?", "Ploua afara?"

Cand folosim rombul (diamantul) in schema logica?
A Pentru actiuni de calcul
B Pentru intrebari/decizii cu raspuns DA sau NU
C Pentru inceputul algoritmului
💡 Rombul are doua iesiri - una pentru DA, una pentru NU.
5

Simbolul INPUT/OUTPUT (Paralelogram)

Paralelogramul reprezinta operatiile de intrare/iesire - cand citim date sau afisam rezultate.

Citeste A Afiseaza suma

INPUT (intrare) - cand cerem utilizatorului sa introduca date:
"Citeste numarul A", "Introdu varsta"

OUTPUT (iesire) - cand afisam ceva:
"Afiseaza rezultatul", "Scrie mesajul pe ecran"

Ce simbolizam cu paralelogramul in schema logica?
A Decizii importante
B Citirea sau afisarea datelor (INPUT/OUTPUT)
C Sfarsitul algoritmului
💡 Paralelogramul = comunicarea cu utilizatorul (citeste de la el sau afiseaza-i ceva).
6

Sagetile (Conexiuni)

Sagetile conecteaza simbolurile si arata directia in care se executa algoritmul.

Regulile sagetilor:

• Fiecare simbol (in afara de romb) are o intrare si o iesire
• Rombul are o intrare si doua iesiri (DA si NU)
• Sagetile merg de obicei de sus in jos si de la stanga la dreapta
• Urmaresti sagetile ca pe un drum pe harta!

Fara sageti, n-am sti in ce ordine sa citim simbolurile.

La ce folosesc sagetile in schema logica?
A La decorare
B Sa arate directia si ordinea pasilor
C Sa marcheze erorile
💡 Sagetile sunt ca drumul pe care il urmezi pe o harta.
7

Recapitulare - Toate simbolurile

Hai sa punem totul cap la cap! Cele 4 simboluri de baza:

OVAL = START / STOP

DREPTUNGHI = Proces / Actiune / Calcul

ROMB = Decizie (intrebare DA/NU)

PARALELOGRAM = Input / Output (citire/afisare)

Plus SAGETI care leaga totul si arata directia!

Care este ordinea corecta a simbolurilor pentru a aduna doua numere?
A START - Citeste - Calculeaza - Afiseaza - STOP
B Calculeaza - START - STOP - Afiseaza
C STOP - Citeste - START - Calculeaza
💡 Intai pornesti, citesti datele, faci calculul, afisezi rezultatul, te opresti.
