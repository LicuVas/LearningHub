Software - Programe si Aplicatii

❌ FARA SOFTWARE

Ai un telefon nou, dar fara aplicatii instalate. Poti doar sa suni si sa trimiti SMS-uri. Nu poti vedea YouTube, nu poti juca jocuri, nu poti naviga pe internet, nu poti face teme pe Word. E ca si cum ai avea o masina fara motor!

✓ CU SOFTWARE POTRIVIT

Telefonul tau are toate aplicatiile de care ai nevoie: YouTube pentru invatat, browser pentru cautari, Word pentru teme, WhatsApp pentru prieteni, jocuri pentru relaxare. Calculatorul devine o unealta puternica care te ajuta in fiecare zi!

  • Vei intelege diferenta dintre hardware (parti fizice) si software (programe)
  • Vei recunoaste tipurile de software: sistem de operare, aplicatii, utilitare
  • Vei identifica exemple de sisteme de operare (Windows, Android, iOS, Linux, macOS)
  • Vei sti cum se instaleaza si dezinstaleaza programe
  • Vei intelege extensiile fisierelor si ce programe le deschid

Incearca - Exploreaza Software-ul Calculatorului Tau

5 minute de explorare practica

🎯 Provocare: Descopera ce ruleaza pe calculatorul tau!

Deschide Task Manager si vezi programele care ruleaza chiar acum pe calculatorul tau. Vei identifica ce tip de software este fiecare.

  1. Deschide Task Manager
    Apasa Ctrl + Alt + Delete (sau Ctrl + Shift + Esc pe Windows 10/11) si selecteaza "Task Manager" / "Gestionar activitati".
  2. Observa tab-ul "Processes" / "Procese"
    Vei vedea o lista cu toate programele care ruleaza. Fiecare linie reprezinta un program (software) care foloseste resursele calculatorului (hardware).
  3. Identifica tipurile de software
    Cauta in lista: aplicatii (Chrome, Word), procese de sistem (Windows Explorer), utilitare (Antivirus). Noteaza-le intr-un fisier.
  4. Fa un screenshot
    Apasa Print Screen si lipeste in Paint (Ctrl+V). Salveaza imaginea ca "task_manager.png".
  5. Numara programele
    Cate programe ruleaza in total? Cate sunt aplicatii pe care le-ai deschis tu, si cate sunt procese de sistem?
  6. Clasifica software-ul
    Creeaza 3 categorii: "Sistem de operare" (Windows, procese de sistem), "Aplicatii" (browser, Word, Paint), "Utilitare" (antivirus, update-uri). 
Pasi pentru Task Manager:
1. Ctrl + Alt + Delete
2. Selecteaza "Task Manager"
3. Priveste tab-ul "Processes"
4. Identifica software: aplicatii, sistem, utilitare
5. Screenshot: Print Screen → Paint → Salveaza

Nu ai acces la un calculator? Poti explora online:

🌐 Exploreaza Windows online
💡 Hint 1: Nu gasesti Task Manager? ▶
Pe Windows 10/11, cea mai rapida metoda este Ctrl + Shift + Esc. Sau click dreapta pe bara de taskuri (bara de jos) si selecteaza "Task Manager".
💡 Hint 2: Cum identific tipul de software? ▶
Aplicatii: Programe pe care le-ai deschis tu (Chrome, Word, Paint).
Sistem: Procese care au "Windows" in nume sau sunt grupate sub "Windows processes".
Utilitare: Antivirus, programe de update, backup.
💡 Hint 3: Ce vad in Task Manager? ▶
Vei vedea coloane: Name (numele programului), CPU (cat procesor foloseste), Memory (cata RAM consuma). Programele care consuma mult sunt "grele" pentru hardware.
🏆 Bonus Challenge

Provocare avansata: Inchide un program din Task Manager! Selecteaza un program pe care l-ai deschis tu (nu sistem!), click dreapta → "End Task". Observa cum dispare din lista. Software-ul se opreste, dar hardware-ul ramane functional.

Invata - Concepte Fundamentale

5-7 minute de lectie structurata

🧠
Software vs Hardware
Software = programe si instructiuni pentru calculator (nu le poti atinge).
Hardware = partile fizice ale calculatorului (le poti atinge: monitor, tastatura, procesor).
💭 Analogie din viata ta

Gandeste-te la un robot:

  • Hardware = corpul robotului (brate, roti, senzori) - partile fizice
  • Software = programul care ii spune ce sa faca (mergi inainte, ridica obiect, evita obstacole)

Fara software, hardware-ul este doar o cutie de metal. Fara hardware, software-ul nu are unde sa ruleze. Au nevoie unul de celalalt!

ℹ️ De retinut

Atunci cand spui "calculatorul meu este lent", de obicei problema e la hardware (procesor slab, RAM putina). Dar daca spui "programul nu functioneaza", problema e la software (bug, versiune veche).

Relatia Hardware ↔ Software

🎛️
Sistem de Operare (OS)
Sistemul de operare este cel mai important software de pe calculator. El face legatura intre hardware si celelalte programe. Fara sistem de operare, calculatorul nu poate functiona!
💭 Analogie din viata ta

Sistemul de operare = Directorul scolii

  • Coordoneaza toate activitatile (ca directorul coordoneaza profesorii, elevii, salile)
  • Aloca resurse (ca directorul aloca sali, ore, profesori)
  • Rezolva conflicte (cand doua programe vor acelasi lucru)
  • Comunica cu tine prin interfata (desktop, meniuri, iconite)
💻 Sistem de Operare Dispozitiv Exemplu
Windows PC, Laptop Windows 10, Windows 11
macOS Mac (Apple) macOS Monterey, Ventura
Linux PC, Servere Ubuntu, Fedora
Android Telefon, Tableta Android 12, 13
iOS iPhone, iPad iOS 16, iPadOS 16
💡 Sfat

La scoala si acasa cel mai des folosesti Windows. Pe telefon probabil folosesti Android (Samsung, Xiaomi) sau iOS (iPhone). Toate fac acelasi lucru: coordoneaza calculatorul!

1️⃣ Software de Sistem

Programele care fac calculatorul sa functioneze. Cel mai important: sistemul de operare.

  • Windows Explorer (gestioneaza fisierele)
  • Device drivers (pentru imprimanta, placa video)
  • Firmware (software in hardware - BIOS)

2️⃣ Software Aplicativ (Aplicatii)

Programele pe care le folosesti pentru activitati specifice.

Categorie Exemple
Browsere Web Google Chrome, Mozilla Firefox, Microsoft Edge
Editoare de text Microsoft Word, Google Docs, Notepad
Spreadsheets Microsoft Excel, Google Sheets
Grafica Paint, Photoshop, Canva
Jocuri Minecraft, Roblox, Fortnite
Social Media WhatsApp, Instagram, TikTok (aplicatii telefon)

3️⃣ Software Utilitar (Utilitare)

Programe care ajuta la mentenanta si protectia calculatorului.

  • Antivirus - Avast, Norton, Windows Defender (protejeaza de virusuri)
  • Cleanup tools - CCleaner (sterge fisiere inutile)
  • Backup - Google Drive, OneDrive (copii de siguranta)
  • Arhivare - WinRAR, 7-Zip (comprima fisiere)
  • Disc diagnostic - verificari hard disk, defragmentare
💭 Analogie din viata ta

Tipurile de software = Roluri intr-o echipa de fotbal:

  • Sistem de operare = Antrenorul (coordoneaza echipa, face strategia)
  • Aplicatii = Jucatorii (atacanti, aparatori - fiecare cu rolul sau)
  • Utilitare = Fizioterapeutul si doctorii (tin echipa sanatoasa, rezolva probleme)
⬇️
Instalare si Dezinstalare Programe
Pentru a folosi un program nou, trebuie sa-l instalezi. Cand nu-l mai vrei, trebuie sa-l dezinstalezi corect (nu doar sa stergi scurtatura!).

📥 Cum INSTALEZI un program?

  1. Descarci fisierul de instalare
    De obicei un fisier .exe (Windows) sau .msi. Exemplu: chrome_installer.exe
  2. Rulezi installerul
    Dublu-click pe fisier. Apare un wizard (asistent) cu pasi.
  3. Accepti termenii si conditiile
    Citeste (sau macar parcurge rapid) ce permisiuni cere programul.
  4. Alegi locatia de instalare
    De obicei: C:\Program Files\NumeProgram
  5. Astepti instalarea
    Programul copiaza fisiere, creeaza scurtaturi, configureaza setarile.
  6. Finish!
    Programul e gata de folosit. Apare o iconica pe desktop sau in meniul Start.

🗑️ Cum DEZINSTALEZI un program?

  1. Deschide Settings (Setari)
    Windows: Start → Settings → Apps → Apps & features
  2. Gaseste programul
    Cauta in lista sau foloseste search.
  3. Click pe "Uninstall"
    Confirma alegerea. Programul va rula propriul uninstaller.
  4. Urmeaza pasii
    Uneori programul te intreaba de ce dezinstalezi (optional).
⚠️ Atentie!

NU sterge direct folderul din C:\Program Files! Daca faci asta, programul inca va avea intrari in registry, scurtaturi, fisiere ramase. Foloseste MEREU optiunea "Uninstall" oficiala.

❌ Greseala frecventa

Elevii sterg iconica de pe desktop si cred ca au dezinstalat programul. Fals! Ai sters doar scurtatura (shortcut-ul). Programul inca ocupa spatiu pe hard disk. Dezinstaleaza corect prin Settings → Apps.

💡 Sfat de siguranta

Descarca programe DOAR din surse oficiale: site-ul producatorului, Microsoft Store, Google Play. Nu descarca din surse necunoscute - risc de virusuri!

📄
Extensii Fisiere si Asocieri
Extensia fisierului sunt ultimele 3-4 litere dupa punct in numele fisierului. Extensia ii spune calculatorului ce tip de fisier este si cu ce program sa-l deschida.
💭 Analogie din viata ta

Extensia fisierului = Uniforma unei echipe sportive

Daca vezi pe cineva cu tricou de fotbal, stii ca e fotbalist. Daca vezi extensia .docx, stii ca e document Word. Daca vezi .mp3, stii ca e melodie. Extensia este "uniforma" fisierului - iti arata ce este inainte sa-l deschizi!

Extensie Tip Fisier Program asociat
.docx Document text Microsoft Word, Google Docs
.xlsx Spreadsheet (tabel) Microsoft Excel, Google Sheets
.pdf Document citire (portabil) Adobe Reader, Browser
.txt Text simplu Notepad, Notepad++
.jpg / .png Imagine Photos, Paint, Photoshop
.mp3 / .wav Audio (muzica) Windows Media Player, VLC
.mp4 / .avi Video (film) VLC, Windows Media Player
.exe Program executabil Se ruleaza direct (Windows)
.zip / .rar Arhiva comprimata WinRAR, 7-Zip
ℹ️ Cum functioneaza asocierile?

Cand faci dublu-click pe tema.docx, Windows stie ca .docx = Word, deci deschide fisierul in Word. Daca nu ai Word instalat, Windows te intreaba: "Cu ce program vrei sa deschizi?"

💡 Schimba programul asociat

Click dreapta pe fisier → "Open with" → "Choose another app" → Selecteaza programul → Bifează "Always use this app". Acum toate fisierele cu acea extensie se vor deschide cu programul ales.

⚠️ Nu redenumi extensia!

Daca schimbi imagine.jpg in imagine.txt, fisierul nu devine text - ramane o imagine! Doar calculatorul se va incurca si nu va stii cum sa-l deschida. Extensia reflecta continutul, nu il schimba!
