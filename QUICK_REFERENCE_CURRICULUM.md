## Grade-by-Grade Summary

### Grade 5 - Foundations
**Focus:** Computer systems, Scratch basics, safety
- Hardware & software components
- Scratch programming (sequential structures)
- Workplace ergonomics and safety
- Basic algorithmic thinking
- Constants, variables, expressions

### Grade 6 - Building Skills
**Focus:** Advanced Scratch, animations, conditionals
- Graphic animations
- Alternative structures (if-then-else)
- Advanced Scratch projects
- Digital content for audiences
- Operators (arithmetic, relational, logical)

### Grade 7 - Text Programming
**Focus:** Real programming languages, loops
- Python/C++/Pascal introduction
- String processing
- Iterative structures (loops)
- Advanced algorithms
- Code editing and debugging

### Grade 8 - Spreadsheets, Web & Algorithms
**Focus:** Excel, HTML/CSS, arrays, integration
- **D1: Calcul tabelar** - Excel interface, formulas, functions (SUM/IF/MAX/MIN), charts
- **D2: Pagini web** - HTML structure, content editing, CSS formatting
- **D3: Algoritmi** - Siruri de valori: parcurgere, cautare, numarare, minim/maxim
- Integration projects and portfolio
- Preparation for high school (liceu)

## Assessment Standards

### Lesson Observation (OMEC 6106/2020)
**Criteria:**
- a) Student-centered teaching strategies
- b) Individualized tasks and learning
- c) Cross-curricular connections
- d) Appropriate resources
- e) Student work display

**Ratings:** FB (Very Good) | B (Good) | A (Acceptable) | S (Weak)

### Bacalaureat Digital Test 2026
- **Proba D** - Digital Competencies
- **Dates:** June 15-17, 2026
- **Format:** Practical tasks in real applications
- **Areas:** Documents, spreadsheets, presentations, online tools, safe use
- **Alternative:** ICDL PROFIL BAC certification (160,000+ students)

## Critical Context

### Challenge: Romania's Digital Skills Gap
- **EU Ranking:** Last place for digital competencies
- **ICILS 2023:** Poor performance in international study
- **Opportunity:** LearningHub addresses massive need

### Time Constraint
- **1 hour/week = 36 hours/year** is insufficient
- Supplementary platform essential for competency development
- Self-paced learning fills gaps between classes

### 2026 Assessment Shift
- New practical test (Proba D) requires hands-on skills
- Transition from theory to practice assessment
- Students need practical preparation tools
